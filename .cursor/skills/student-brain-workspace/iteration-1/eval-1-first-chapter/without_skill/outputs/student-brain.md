### 2-1. `### c언어의 특징` (첫 문단)

읽은 문장(요지):
C는 컴퓨터에게 일을 시키는 방법을 기초부터 배우기 좋다.
다른 언어보다 **메모리·주소·데이터가 저장되는 방식**처럼 컴퓨터 내부 동작을 직접 다룬다.
처음엔 부담될 수 있지만 익히면 실력이 단단해진다.

#### 여기서 멈춤

내가 이해한 것:
- C = 컴퓨터에게 시키는 말을 배우는 언어 중 하나
- 처음엔 어려울 수 있다

내가 **모르는 것 / 막히는 것**:
1. **메모리**가 정확히 뭔가?
   - 사람 기억력? 컴퓨터 부품? 파일 저장 공간?
   - 문서가 “직접 다룬다”고만 하고, 초보에게 한 줄 정의가 없다.
2. **주소**가 뭔가?
   - 집 주소? 인터넷 주소? 컴퓨터 안 위치?
   - “메모리·주소”가 같이 나오는데 둘 다 설명이 없음.
3. “데이터가 저장되는 방식”도, 데이터가 뭔지·어디에 저장되는지 그림이 안 그려진다.

왜 학습을 멈추는가:
- 이 문단의 핵심 주장(“C는 컴퓨터 내부를 직접 다룬다”)을 이해하려면 **메모리/주소**가 무엇인지 최소한 감이 있어야 한다.
- 문서가 “부담될 수 있다”고만 하고, 부담의 대상인 단어를 풀어주지 않는다.
- 생초보인 나는 “대충 넘어가자”고 하면 뒤 문장(“기초 체력”, “동작 원리”)도 모래 위에 집을 짓는 느낌이 든다.
- 그래서 **이 문단에서 학습을 즉시 중단**한다.

멈춘 위치:
- 파일: `docs/c/01-intro.md`
- 소절: `### c언어의 특징`
- 대략 첫 본문 문단 (학습 목표 바로 다음)

아직 읽지 못한 뒤쪽(참고용으로만 표시, 학습 완료 아님):
- 컴파일이란
- 탄생 배경
- Visual Studio / `cl`
- 개발환경 세팅 STEP
- 첫 소스 / 컴파일·실행
- 연습문제

## 4. 막힌 질문 (선생님/문서에 묻고 싶은 것)

1. 여기서 말하는 **메모리**는 무엇인가? (RAM? 저장 공간? 다른 것?)
2. **주소**는 메모리와 어떻게 다른가?
3. “데이터를 저장한다”는 게, 파일로 저장하는 것과 같은 말인가 다른 말인가?
4. 초보가 지금 이 단어를 몰라도 다음 소절(컴파일)로 넘어가도 되는가? 된다면 문서에 “지금은 이름만 듣고 넘어가도 된다”고 써 주면 좋겠다.
