- Visual Studio는 Microsoft가 만든 프로그래밍용 **IDE**(통합 개발 환경)로, 코드 쓰기·빌드·실행·오류 확인을 한곳에서 하게 해 준다고 한다.
- `cl`은 Visual Studio에 들어 있는 MSVC 컴파일러를 명령줄에서 쓸 때의 이름이라고 한다.
- 이 문서는 Windows + Visual Studio + `cl` 기준이다.
- 설치할 때 Desktop development with C++ 워크로드를 체크해야 `cl`이 잡힌다고 한다.
- Developer PowerShell for VS 2022를 써야 `cl` 경로가 잡히는 경우가 많다고 한다.
