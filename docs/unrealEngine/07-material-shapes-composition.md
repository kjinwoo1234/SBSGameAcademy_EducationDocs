# Chapter 07 머티리얼 — 도형과 합성

## 학습 목표

- Step 노드로 그레이디언트를 원하는 기준에서 흑백으로 나눌 수 있다.
- Max와 Min으로 두 흑백 영역의 교집합·합집합·차집합을 만들 수 있다.
- 사각형과 원을 그리는 머티리얼 함수를 만들어 재사용할 수 있다.
- 명명된 경유 노드와 코멘트로 복잡한 그래프를 정리할 수 있다.

## 본문

### 07-1 Step 노드

Chapter 06에서 `Round`는 `0.5`를 기준으로 그레이디언트를 검정과 흰색으로 나눴습니다. 기준이 `0.5`로 고정되어 있어서 화면의 30% 지점에서 나누는 일은 할 수 없었습니다.

**`Step`** 노드는 나누는 기준을 직접 정할 수 있는 노드입니다. 입력 핀이 두 개입니다.

| 핀 | 넣는 것 |
|---|---|
| Y | 기준이 되는 값 |
| X | 검사할 값. 보통 그레이디언트 |

X가 Y보다 작으면 `0`, 크거나 같으면 `1`을 내보냅니다.

1. `TexCoord`에서 `ComponentMask`로 R만 꺼내 가로 그레이디언트를 만든다.
2. `Step` 노드를 만들어 X에 그레이디언트를, Y에 상수 `0.3`을 연결한다.
3. 최종 색에 연결한다.

화면 왼쪽 30%는 검정, 나머지는 흰색이 됩니다. Y에 상수 대신 Chapter 06에서 만든 `MF_TimeFlow`의 `PingPong`을 연결하면 경계선이 좌우로 움직입니다.

### 07-2 검정을 도형으로 정한다

흑백으로 나뉜 영역을 **마스크**라고 부릅니다. 마스크로 도형을 그리려면 검정과 흰색 중 어느 쪽을 도형으로 볼지 먼저 정해야 합니다. 뒤에서 영역을 합칠 때 계산 방법이 달라지기 때문입니다.

이 과정에서는 **검정 영역을 도형**으로 정합니다. 값으로 말하면 `0`인 곳이 도형 안쪽이고 `1`인 곳이 바깥입니다.

### 07-3 세로 띠 만들기

화면의 30% 지점부터 70% 지점까지 검정인 세로 띠를 만듭니다. 마스크 두 장을 만들어 겹칩니다.

첫 번째 마스크입니다.

1. `Step`의 Y에 `0.3`, X에 가로 그레이디언트를 연결한다. 왼쪽이 검정, 오른쪽이 흰색이다.
2. `1-x` 노드로 뒤집는다. 왼쪽 30%가 흰색, 나머지가 검정이 된다.

두 번째 마스크입니다.

3. `Step`을 하나 더 만들어 Y에 `0.7`, X에 같은 그레이디언트를 연결한다. 왼쪽 70%가 검정, 나머지가 흰색이다.

두 마스크에서 **둘 다 검정인 곳**만 남기면 30%에서 70% 사이의 띠가 됩니다.

4. `Max` 노드에 두 마스크를 연결한다.

`Max`는 두 값 중 큰 쪽을 고릅니다. 둘 중 하나라도 `1`이면 결과가 `1`이고, 둘 다 `0`일 때만 `0`이 남습니다. 그래서 검정이 겹친 부분만 검정으로 남습니다.

![세로 띠 그래프: 1 - Step(0.3) 과 Step(0.7) 을 Max 로 합친 노드와 가운데 검정 띠 미리보기](./img/07-vertical-band-graph.png)

### 07-4 교집합, 합집합, 차집합

같은 노드 묶음을 복사하고 `ComponentMask`를 G로 바꾸면 세로 그레이디언트를 쓰게 되어 가로 띠가 만들어집니다. 세로 띠를 A, 가로 띠를 B라고 하면 두 띠를 합치는 방법은 세 가지입니다.

| 이름 | 남는 검정 영역 | 노드 | 결과 모양 |
|---|---|---|---|
| 교집합 | A와 B가 겹친 곳 | `Max(A, B)` | 가운데 사각형 |
| 합집합 | A이거나 B인 곳 | `Min(A, B)` | 십자 모양 |
| 차집합 | A에서 B를 뺀 곳 | `Max(A, 1-B)` | 가운데가 끊긴 세로 띠 |

`Min`은 두 값 중 작은 쪽을 고르므로 둘 중 하나라도 `0`이면 `0`이 됩니다. 그래서 검정이 한쪽에만 있어도 검정으로 남습니다.

차집합은 B를 `1-x`로 뒤집은 뒤 A와 교집합을 구하는 것입니다. B가 아닌 곳과 A가 겹치는 부분만 남습니다.

세로 띠와 가로 띠의 교집합이 **사각형**입니다.

### 07-5 사각형 머티리얼 함수

사각형을 쓸 때마다 띠 두 개를 만들 수는 없으므로 머티리얼 함수로 묶습니다. 이름은 `MF_Rectangle`입니다.

| 구분 | 이름 | 종류 | 기본값 |
|---|---|---|---|
| 입력 0 | `UV` | 2차원 벡터 | `TexCoord` 노드 |
| 입력 1 | `Center` | 2차원 벡터 | `(0.5, 0.5)` |
| 입력 2 | `Size` | 2차원 벡터 | `(0.6, 0.4)` |
| 출력 0 | `Mask` | 스칼라 | 사각형 마스크 |

중심과 크기를 받아 띠의 시작과 끝을 계산합니다.

1. `Size`에 `0.5`를 곱해 절반 크기를 구한다.
2. `Center`에서 절반 크기를 빼면 시작 좌표이고, 더하면 끝 좌표이다.
3. `BreakOutFloat2Components` 노드로 `UV`, 시작 좌표, 끝 좌표를 각각 가로 값과 세로 값으로 나눈다.
4. 가로 값끼리 07-3의 세로 띠를 만든다. `Step`의 Y에 `0.3` 대신 시작 좌표의 가로 값을, `0.7` 대신 끝 좌표의 가로 값을 넣는다.
5. 세로 값끼리 같은 방법으로 가로 띠를 만든다.
6. 두 띠를 `Max`로 합쳐 `Mask` 출력에 연결한다.
7. 입력 노드 세 개의 **정렬 우선순위**를 `0`, `1`, `2`로 정하고, 각각 기본값 노드를 **Preview**에 연결해 **프리뷰 값을 디폴트로 사용**에 체크한다.
8. **라이브러리에 노출**에 체크하고 저장한다.

### 07-6 그래프 정리하기

`MF_Rectangle`은 선이 많이 얽혀서 흐름을 한눈에 보기 어렵습니다. 머티리얼 에디터에는 그래프를 정리하는 기능이 두 가지 있습니다.

**명명된 경유 노드**는 값에 이름표를 붙여 두었다가 멀리 떨어진 곳에서 그 이름으로 다시 꺼내 쓰는 노드입니다. 선을 길게 끌지 않아도 됩니다.

1. 이름을 붙일 출력 핀을 드래그한 뒤 `named`로 검색해 **명명된 경유 선언 노드 추가**를 고른다.
2. 이름을 정한다. `MF_Rectangle`에서는 `UGradient`, `VGradient`, `MinU`, `MinV`, `MaxU`, `MaxV` 여섯 개를 만든다.
3. 값을 쓸 곳에서 우클릭해 그 이름을 검색하면 같은 값을 내보내는 노드가 만들어진다.

**코멘트**는 노드 여러 개를 상자로 묶고 제목을 붙이는 기능입니다. 노드를 드래그로 여러 개 선택한 뒤 `C`를 누르면 만들어집니다. 세로 띠 묶음과 가로 띠 묶음에 각각 코멘트를 달아 두면 나중에 다시 열었을 때 알아보기 쉽습니다.

![명명된 경유 노드와 코멘트 상자로 세로선·가로선 영역을 정리한 MF_Rectangle 그래프](./img/07-named-reroute-comment.png)

### 07-7 합성 머티리얼 함수

07-4의 세 가지 합성도 함수로 묶어 둡니다. 이름은 `MF_Composition`입니다.

| 구분 | 이름 | 종류 | 내용 |
|---|---|---|---|
| 입력 0 | `Mask A` | 스칼라 | 첫 번째 마스크 |
| 입력 1 | `Mask B` | 스칼라 | 두 번째 마스크 |
| 출력 0 | `Union` | 스칼라 | 합집합. `Min(A, B)` |
| 출력 1 | `Intersection` | 스칼라 | 교집합. `Max(A, B)` |
| 출력 2 | `Difference` | 스칼라 | 차집합. `Max(A, 1-B)` |

입력의 기본값으로는 크기가 다른 `MF_Rectangle` 두 개를 연결해 두면 함수 안에서 결과를 바로 확인할 수 있습니다.

### 07-8 원 그리기

원은 중심에서 같은 거리에 있는 점들의 모임입니다. 그리는 점이 중심에서 얼마나 떨어져 있는지 알면 원 안쪽인지 바깥쪽인지 나눌 수 있습니다.

**`Distance`** 노드는 두 좌표 사이의 거리를 내보냅니다. `TexCoord`와 중심 좌표 `(0.5, 0.5)`를 연결해 최종 색에 넣으면 중심은 검정이고 멀어질수록 밝아지는 둥근 그레이디언트가 보입니다. 이 거리 값을 `Step`으로 나누면 원이 됩니다.

머티리얼 함수 `MF_Circle`로 만듭니다.

| 구분 | 이름 | 종류 | 기본값 |
|---|---|---|---|
| 입력 0 | `UV` | 2차원 벡터 | `TexCoord` 노드 |
| 입력 1 | `Center` | 2차원 벡터 | `(0.5, 0.5)` |
| 입력 2 | `Radius` | 스칼라 | `0.25` |
| 출력 0 | `Mask` | 스칼라 | 원 마스크 |

1. `Distance` 노드에 `UV`와 `Center`를 연결한다.
2. `Step`의 X에 거리 값을, Y에 `Radius`를 연결한다.
3. 결과를 `Mask`에 연결한다.

거리가 반지름보다 작은 안쪽은 `0`으로 검정, 바깥쪽은 `1`로 흰색이 됩니다.

`Distance`는 내부에서 제곱근을 계산하는데, 제곱근은 계산량이 큰 편입니다. 거리 대신 거리의 제곱을 반지름의 제곱과 비교해도 결과는 같습니다. `UV`에서 `Center`를 뺀 벡터를 `DotProduct` 노드의 두 입력에 똑같이 연결하면 거리의 제곱이 나옵니다. 이 값을 `Radius`에 `Radius`를 곱한 값과 `Step`으로 비교합니다. 화면의 모든 점마다 계산이 반복되므로 이런 작은 차이가 쌓여 성능 차이가 됩니다.

### 07-9 도형으로 얼굴 그리기

두 도형과 합성 함수로 사람 얼굴을 그려 봅니다.

1. `MF_Circle` 두 개로 두 눈을 만든다. `Center`를 `(0.3, 0.35)`와 `(0.7, 0.35)`로, `Radius`를 `0.1`로 한다.
2. `MF_Rectangle`로 코를 만든다. `Center` `(0.5, 0.55)`, `Size` `(0.06, 0.2)`.
3. `MF_Rectangle`로 입을 만든다. `Center` `(0.5, 0.8)`, `Size` `(0.4, 0.06)`.
4. 네 마스크를 `Min`으로 차례로 합친다. 합집합이므로 검정 도형이 모두 남는다.

얼굴을 여러 개 반복하려면 도형 함수에 넣는 좌표를 반복시킵니다. Chapter 06에서 그레이디언트를 반복시킨 방법과 같습니다.

5. `TexCoord`에 `(3, 3)`을 곱하고 `Frac`을 거친 값을 `TilingUV`라는 명명된 경유 노드로 만든다.
6. 네 도형 함수의 `UV` 입력에 `TilingUV`를 연결한다.

![원 두 개와 사각형 두 개로 만든 얼굴 마스크가 3×3으로 반복된 미리보기](./img/07-face-tiling.png)

얼굴 아홉 개가 나타납니다. `Frac`을 거치기 전 값에 `Floor`와 `Fmod`로 체크 패턴을 만들어 얼굴 마스크와 `Min`으로 합치면 체크의 검은 칸이 얼굴을 덮어 절반의 칸에만 얼굴이 남습니다.

### 07-10 따라하기 — 도형 머티리얼

1. `Step`으로 30% 지점에서 나뉘는 마스크를 만들고, 기준에 `PingPong`을 연결해 경계를 움직인다.
2. 세로 띠와 가로 띠를 만들어 교집합, 합집합, 차집합 결과를 각각 확인한다.
3. `MF_Rectangle`, `MF_Composition`, `MF_Circle`을 만들고 라이브러리에 노출한다.
4. `MF_Rectangle`을 명명된 경유 노드와 코멘트로 정리한다.
5. 원과 사각형으로 얼굴을 그리고 3×3으로 반복시킨다.
6. 체크 패턴과 합쳐 절반의 칸에만 얼굴이 나오게 한다.

지금까지 만든 것은 모두 흑백입니다. Chapter 08에서 마스크에 색을 입힙니다.

### 연습문제

1. 문제: `Step` 노드의 Y에 `0.8`, X에 가로 그레이디언트를 넣으면 화면이 어떻게 나뉘는지 쓰세요.  
   - 조건: 검정 영역과 흰색 영역의 비율을 쓸 것
2. 문제: 검정을 도형으로 정했을 때 두 마스크의 교집합에 `Max`를 쓰는 이유를 한 문장으로 쓰세요.  
   - 조건: 값 `0`과 `1`로 설명할 것
3. 문제: 원을 그릴 때 `Distance` 대신 `DotProduct`를 쓰는 방법의 장점을 한 문장으로 쓰세요.

### 정답 포인트

- 왼쪽 80% 검정, 오른쪽 20% 흰색. `Max`는 둘 다 `0`일 때만 `0`이 남으므로 검정이 겹친 곳만 남는다. 제곱근 계산을 피해 계산량이 줄어든다.
