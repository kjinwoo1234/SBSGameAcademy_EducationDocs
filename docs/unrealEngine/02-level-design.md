# Chapter 02 레벨 디자인

## 학습 목표

- 뷰포트 카메라를 마우스와 키보드로 자유롭게 움직일 수 있다.
- 새 레벨을 만들고 액터를 배치·이동·회전·크기 조절할 수 있다.
- 디테일 패널에서 액터의 프로퍼티를 바꿔 레벨을 꾸밀 수 있다.
- 라이팅 빌드가 무엇을 하는지 설명하고, 외부 에셋을 프로젝트에 가져올 수 있다.

## 본문

### 02-1 프로젝트 준비

이 장에서는 빈 공간에 바닥, 빛, 가구를 놓아 작은 방을 만듭니다. 캐릭터가 돌아다니는 게임 세상 하나를 언리얼에서는 **레벨**이라고 부릅니다. 다른 게임에서 맵이라고 부르는 것과 같습니다.

1. 런처에서 엔진을 실행해 프로젝트 브라우저를 연다.
2. **게임 → 기본**을 고른다.
3. 프로젝트 디폴트에서 **블루프린트**를 고르고 **시작용 콘텐츠**에 체크한다.
4. 위치와 이름을 정하고 **생성**을 누른다.

**시작용 콘텐츠**는 의자, 탁자, 벽, 바닥 같은 기본 재료 묶음입니다. 체크하지 않으면 이 장에서 쓸 가구가 프로젝트에 들어오지 않습니다.

### 02-2 뷰포트 탐색

**뷰포트**는 레벨을 들여다보는 창입니다. 뷰포트 안의 카메라를 움직여야 원하는 곳을 보고 꾸밀 수 있습니다.

마우스만 쓰는 방법입니다.

| 조작 | 카메라 동작 |
|---|---|
| 왼쪽 버튼 드래그 | 앞뒤로 이동하고 좌우로 회전 |
| 오른쪽 버튼 드래그 | 제자리에서 둘러보기 |
| 양쪽 버튼 동시 드래그 | 상하좌우로 평행 이동 |
| 휠 | 앞뒤로 이동 |

오른쪽 버튼을 누른 채 키보드를 함께 쓰는 방법입니다. 게임에서 캐릭터를 움직이는 방식과 같아 가장 많이 씁니다.

| 조작 | 카메라 동작 |
|---|---|
| 오른쪽 버튼 + `W` `S` | 앞뒤 이동 |
| 오른쪽 버튼 + `A` `D` | 좌우 이동 |
| 오른쪽 버튼 + `E` `Q` | 위아래 이동 |
| 오른쪽 버튼 + 휠 | 이동 속도 조절 |

`Alt` 키를 누른 채 쓰는 방법도 있습니다. 3D 모델링 프로그램 Maya와 같은 조작입니다.

| 조작 | 카메라 동작 |
|---|---|
| `Alt` + 왼쪽 버튼 드래그 | 한 점을 중심으로 돌아보기 |
| `Alt` + 오른쪽 버튼 드래그 | 가까이·멀리 |
| `Alt` + 가운데 버튼 드래그 | 상하좌우로 평행 이동 |

물체를 클릭해 선택한 뒤 `F`를 누르면 카메라가 그 물체 앞으로 이동합니다. 카메라가 엉뚱한 곳으로 가 버렸을 때 유용합니다.

뷰포트 왼쪽 위의 **원근** 버튼을 누르면 보는 방식을 바꿀 수 있습니다. **원근**은 가까운 것이 크게 보이는 보통 화면이고, **상단·정면·좌측** 같은 직교 뷰는 설계도처럼 거리감 없이 보여 줍니다. 물체의 줄을 정확히 맞출 때 직교 뷰를 씁니다.

![뷰포트 왼쪽 위 원근 버튼을 눌러 상단·정면·좌측 뷰 목록이 펼쳐진 화면](./img/02-viewport-perspective-menu.png)

### 02-3 새 레벨 만들기

새 레벨을 만드는 방법은 두 가지입니다.

첫째, 콘텐츠 브라우저의 빈 곳을 우클릭하고 **레벨**을 누릅니다. 그 폴더에 빈 레벨 파일이 생기고, 더블클릭하면 열립니다.

둘째, 메뉴 바에서 **파일 → 새 레벨**을 누릅니다. 어떤 모양으로 시작할지 고르는 창이 나옵니다.

| 종류 | 처음 들어 있는 것 |
|---|---|
| 오픈 월드 | 넓은 지형과 하늘, 빛 |
| 빈 오픈 월드 | 넓은 맵용 설정만 있고 내용은 비어 있음 |
| 기본 | 바닥 하나와 하늘, 빛 |
| 빈 레벨 | 아무것도 없음 |

이 장에서는 **빈 레벨**을 골라 처음부터 채웁니다. 만든 뒤 `Ctrl + S`로 저장하고 이름을 정합니다. 빈 레벨은 빛이 없어서 화면이 까맣게 보이는 것이 정상입니다.

### 02-4 액터 배치

레벨에 놓을 수 있는 모든 물체를 **액터**라고 합니다. 언리얼은 게임 세상을 연극 무대에 비유했고, 액터는 무대에 올라온 배우라는 뜻입니다. 바닥, 의자, 빛, 플레이어 시작 위치가 모두 액터입니다.

툴바의 **추가** 버튼을 누르고 **액터 배치 패널**을 열면 자주 쓰는 액터 목록이 나옵니다. 툴바의 모드가 **선택 모드**인지 먼저 확인합니다.

![툴바의 추가 버튼을 눌러 액터 배치 패널을 연 화면과 셰이프 분류의 큐브 항목](./img/02-place-actors-panel.png)

바닥부터 만듭니다.

1. 액터 배치 패널의 **셰이프**에서 **큐브**를 뷰포트로 끌어다 놓는다.
2. 큐브를 선택한 상태로 디테일 패널의 **트랜스폼**을 본다.
3. 위치를 `0, 0, 0`, 회전을 `0, 0, 0`, 스케일을 `4, 4, 0.1`로 입력한다.

**트랜스폼**은 액터의 위치, 회전, 스케일 세 가지를 묶어 부르는 말입니다. 스케일 `1`은 원래 크기이고, 다른 숫자를 넣으면 그 배수로 커지거나 작아집니다. 높이 방향만 `0.1`로 줄였기 때문에 정육면체가 납작한 판이 됩니다.

뷰포트에서 직접 움직일 수도 있습니다. 액터를 선택하면 나타나는 화살표를 **기즈모**라고 하고, 아래 키로 종류를 바꿉니다.

| 키 | 기즈모 |
|---|---|
| `W` | 이동 |
| `E` | 회전 |
| `R` | 스케일 |

이어서 빛과 하늘, 시작 위치를 놓습니다.

1. **라이트**에서 **디렉셔널 라이트**를 끌어다 놓는다. 화면이 밝아진다. 바닥에 붙어 있으면 위로 조금 띄운다.
2. **비주얼 이펙트**에서 **스카이 애트머스피어**를 놓는다. 하늘에 색이 생긴다.
3. 같은 분류에서 **볼류메트릭 클라우드**를 놓는다. 구름이 생긴다.
4. **기본**에서 **플레이어 스타트**를 바닥 위에 놓는다.

**플레이어 스타트**는 게임을 시작할 때 플레이어가 나타나는 위치를 정하는 액터입니다. 이 액터가 없으면 뷰포트 카메라가 있던 자리에서 게임이 시작됩니다. 재생 버튼을 눌러 플레이어 스타트 위치에서 시작하는지 확인합니다.

### 02-5 콘텐츠 브라우저로 배치

액터 배치 패널에 없는 물체는 콘텐츠 브라우저에서 끌어옵니다.

1. 콘텐츠 브라우저에서 `콘텐츠/StarterContent/Props` 폴더를 연다.
2. `SM_TableRound`를 뷰포트의 바닥 위로 끌어다 놓는다.
3. `SM_Chair`를 탁자 옆에 놓고 `E`를 눌러 탁자를 향하도록 돌린다.
4. `콘텐츠/StarterContent/Architecture` 폴더에서 벽과 바닥 조각을 가져와 방 모양을 만든다.

이름 앞에 `SM_`이 붙은 파일은 **스태틱 메시**입니다. 스태틱 메시는 3D 모델링 프로그램에서 만들어 온 입체 모형으로, 모양이 변하지 않는 물체에 씁니다.

같은 액터를 여러 개 놓을 때는 `Alt` 키를 누른 채 이동 기즈모를 끌면 복사됩니다. 벽을 이어 붙일 때 편합니다.

![시작용 콘텐츠의 탁자·의자·벽을 배치해 만든 작은 방의 완성 예시](./img/02-room-example.png)

### 02-6 배치된 액터 편집

액터의 옵션을 바꾸는 일을 **프로퍼티 편집**이라고 합니다. 프로퍼티는 액터가 가진 설정값 하나하나를 가리키는 말입니다.

먼저 태양의 위치를 바꿔 봅니다.

1. 아웃라이너에서 `DirectionalLight`를 선택한다.
2. 디테일 패널에서 **애트머스피어 선 라이트**가 켜져 있는지 확인한다.
3. `E`를 눌러 라이트를 회전시킨다.

이 옵션이 켜진 디렉셔널 라이트를 돌리면 하늘의 태양 위치가 함께 움직입니다. 낮, 해 질 녘, 밤의 분위기를 라이트 회전만으로 만들 수 있습니다. `Ctrl + L`을 누른 채 마우스를 움직여도 같은 회전이 됩니다.

다음으로 벽의 겉모습을 바꿉니다.

1. 벽 액터를 선택한다.
2. 디테일 패널의 **머티리얼** 항목에서 현재 값 `M_Basic_Wall`을 누른다.
3. 목록에서 `M_Brick_Clay_New`를 고른다.

**머티리얼**은 물체 겉면의 색과 질감을 정하는 재료입니다. 같은 벽 모형이라도 머티리얼을 바꾸면 벽돌 벽이 됩니다. 머티리얼을 직접 만드는 방법은 Chapter 04부터 다룹니다.

### 02-7 라이팅 빌드

뷰포트에서 보는 빛과 그림자는 작업 중에 빨리 보여 주기 위한 대략적인 결과입니다. 빛이 벽 아래로 새거나 그림자가 어색하게 생길 수 있습니다.

**라이팅 빌드**는 움직이지 않는 빛과 물체에 대해 빛과 그림자를 미리 정밀하게 계산해 저장해 두는 작업입니다. 계산 결과를 저장해 두기 때문에 게임 중에는 다시 계산하지 않아 가볍습니다.

1. 액터 배치 패널의 **볼륨**에서 **라이트매스 임포턴스 볼륨**을 놓는다.
2. `R`을 눌러 방 전체를 덮도록 크기를 키운다.
3. 메뉴 바에서 **빌드 → 라이팅 퀄리티**를 원하는 단계로 고른다.
4. **빌드 → 라이팅만 빌드**를 누른다.

**라이트매스 임포턴스 볼륨**은 "이 상자 안은 정밀하게 계산해 달라"고 범위를 알려 주는 액터입니다. 플레이 구역만 덮어야 계산 시간이 줄어듭니다.

라이팅 퀄리티를 **프로덕션**으로 두면 가장 정밀하지만 오래 걸립니다. 작업 중에는 **프리뷰**나 **중간**으로 빠르게 확인하고, 마지막에만 프로덕션으로 빌드합니다. 빛의 종류에 따라 빌드가 필요한지 아닌지가 달라지는데, 그 기준은 Chapter 10에서 다룹니다.

### 02-8 외부 에셋 가져오기

시작용 콘텐츠만으로는 꾸밀 재료가 금방 부족해집니다. 프로젝트에 들어가는 모형, 그림, 소리 파일을 통틀어 **에셋**이라고 하고, 다른 사람이 만든 에셋을 받아 쓸 수 있습니다.

**Fab**은 에픽게임즈가 운영하는 에셋 장터입니다. 예전에는 마켓플레이스라는 이름이었습니다. 무료 에셋도 많이 올라와 있습니다.

1. 에픽게임즈 런처 또는 에디터의 Fab 창에서 원하는 무료 에셋을 찾는다.
2. **내 라이브러리에 추가**를 누른다.
3. 라이브러리에서 해당 에셋의 **프로젝트에 추가**를 누르고 대상 프로젝트를 고른다.
4. 콘텐츠 브라우저에 새 폴더가 생겼는지 확인한다.

다른 사이트에서 받은 모형 파일은 대부분 확장자가 `.fbx`입니다. 이 파일을 콘텐츠 브라우저로 끌어다 놓거나 **임포트** 버튼을 누르면 가져오기 옵션 창이 뜹니다. 기본값 그대로 임포트하면 스태틱 메시가 만들어집니다.

받은 에셋마다 사용 조건이 다릅니다. 무료라도 상업적 사용이 금지된 경우가 있으므로 내려받는 페이지의 라이선스 안내를 확인합니다.

### 02-9 따라하기 — 나만의 방 꾸미기

1. 빈 레벨을 만들고 바닥, 디렉셔널 라이트, 스카이 애트머스피어, 플레이어 스타트를 놓는다.
2. 시작용 콘텐츠의 벽, 탁자, 의자로 방을 만든다.
3. 벽 머티리얼을 하나 이상 바꾼다.
4. 디렉셔널 라이트를 돌려 원하는 시간대 분위기를 만든다.
5. 라이트매스 임포턴스 볼륨으로 방을 덮고 라이팅을 빌드한다.
6. Fab 또는 다른 곳에서 무료 에셋을 하나 받아 방에 놓는다.
7. 플레이해서 방 안을 돌아다녀 본다.

지형을 깎아 넓은 야외를 만드는 방법은 Chapter 03에서 다룹니다.

### 연습문제

1. 문제: 정육면체 큐브를 납작한 바닥으로 만들려면 트랜스폼의 어느 값을 어떻게 바꿔야 하는지 쓰세요.  
   - 조건: 위치·회전·스케일 중 하나를 고르고 예시 숫자를 쓸 것
2. 문제: 플레이어 스타트 액터를 놓지 않으면 게임이 어디에서 시작되는지 한 문장으로 쓰세요.
3. 문제: 라이트매스 임포턴스 볼륨을 레벨 전체가 아니라 플레이 구역만 덮게 하는 이유를 한 문장으로 쓰세요.  
   - 조건: "계산 시간"이라는 말을 포함할 것

### 정답 포인트

- 스케일을 `4, 4, 0.1`처럼 높이만 작게. 플레이어 스타트가 없으면 뷰포트 카메라 위치에서 시작. 정밀 계산 범위를 줄여 계산 시간을 아끼기 위해.
