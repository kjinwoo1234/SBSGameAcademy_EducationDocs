# Chapter 01 언리얼 시작하기

## 학습 목표

- 게임 엔진과 블루프린트가 무엇인지 자신의 말로 설명할 수 있다.
- 언리얼 엔진을 설치하고 템플릿 프로젝트를 만들어 플레이할 수 있다.
- 디폴트 폰 클래스를 바꿔 조종하는 대상을 교체할 수 있다.
- 에디터 화면의 주요 영역 이름과 역할을 구분할 수 있다.

## 본문

### 01-1 게임 엔진과 언리얼

게임을 처음부터 혼자 만들려면 화면에 그림을 그리는 기능, 물체가 부딪히는 기능, 소리를 내는 기능, 키보드 입력을 받는 기능을 전부 직접 만들어야 합니다. 게임마다 이 일을 반복하는 것은 너무 오래 걸립니다.

그래서 게임에 공통으로 필요한 기능을 미리 만들어 묶어 둔 프로그램을 씁니다. 이런 프로그램을 **게임 엔진**이라고 합니다. 자동차 엔진이 자동차를 움직이게 하듯, 게임 엔진은 게임을 만들고 실행할 수 있게 해 줍니다.

**언리얼 엔진**은 에픽게임즈라는 회사가 만든 게임 엔진입니다. 규모가 큰 상용 게임부터 학생 포트폴리오까지 같은 엔진으로 만듭니다. 이 과정에서는 언리얼 엔진 5 버전을 사용합니다.

### 01-2 블루프린트

게임의 동작을 만들려면 보통 프로그래밍 언어로 글자 코드를 써야 합니다. 프로그래밍을 배운 적이 없다면 여기서 막힙니다.

언리얼은 글자 대신 **상자를 선으로 이어서** 동작을 만드는 방법을 제공합니다. 이 방법을 **블루프린트**라고 합니다. 상자 하나가 기능 하나이고, 선은 실행 순서와 값의 흐름입니다.

![블루프린트 이벤트 그래프: 이벤트 노드와 기능 노드가 선으로 연결된 예시 화면](./img/01-blueprint-event-graph-example.png)

블루프린트는 초보자만 쓰는 연습용 기능이 아닙니다. 실제 개발에서도 캐릭터 외형 지정, 수치 조절, 간단한 동작은 블루프린트로 만들고, 복잡한 계산은 C++라는 프로그래밍 언어로 만드는 방식을 함께 씁니다. 이 과정의 Part 01은 블루프린트와 에디터만으로 진행하고, C++는 Part 02부터 다룹니다.

### 01-3 언리얼 엔진 설치

언리얼 엔진은 **에픽게임즈 런처**라는 프로그램을 통해 설치합니다. 런처는 엔진을 내려받고, 여러 버전을 관리하고, 엔진을 실행해 주는 프로그램입니다.

1. 아래 주소에서 에픽게임즈 런처 설치 파일을 받는다.

   https://www.unrealengine.com/ko/download

2. 설치한 런처를 실행하고 에픽게임즈 계정으로 로그인한다. 계정이 없으면 같은 화면에서 만든다.
3. 런처 왼쪽 메뉴에서 **언리얼 엔진**을 누르고, 위쪽 탭에서 **라이브러리**를 누른다.
4. **엔진 버전** 옆의 `+` 버튼을 눌러 5로 시작하는 최신 버전을 고르고 **설치**를 누른다.

![에픽게임즈 런처의 언리얼 엔진 > 라이브러리 탭에서 엔진 버전을 설치하는 화면](./img/01-launcher-library-install.png)

설치 용량이 크기 때문에 시간이 걸립니다. 설치가 끝나면 같은 자리의 버튼이 **실행**으로 바뀝니다.

### 01-4 템플릿 프로젝트 만들기

**프로젝트**는 게임 하나를 만들기 위한 파일 묶음입니다. 언리얼은 처음 시작하기 쉽도록 미리 만들어 둔 예제 프로젝트를 제공합니다. 이것을 **템플릿**이라고 합니다.

1. 런처에서 **실행**을 누른다. **프로젝트 브라우저** 창이 열린다.
2. 왼쪽에서 **게임**을 고른다.
3. 가운데에서 **일인칭**을 고른다.
4. 오른쪽 프로젝트 디폴트에서 **블루프린트**를 고른다.
5. 아래쪽에서 프로젝트를 저장할 위치와 이름을 정하고 **생성**을 누른다.

![프로젝트 브라우저에서 게임 > 일인칭 템플릿과 블루프린트를 고르고 저장 위치·이름을 입력한 화면](./img/01-project-browser-first-person.png)

프로젝트 이름과 저장 경로에는 한글과 띄어쓰기를 넣지 않는 편이 안전합니다. 영문과 숫자로만 짓습니다.

### 01-5 플레이해 보기

프로젝트가 열리면 화면 위쪽 **툴바**에 초록색 재생 버튼이 있습니다. 이 버튼을 누르면 에디터 안에서 바로 게임이 실행됩니다.

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 이동 | 시점 회전 |
| `F11` | 전체 화면으로 전환 |
| `Esc` | 플레이 종료 |

플레이 중 마우스 커서가 게임 화면에 잡혀 있을 때 `Shift + F1`을 누르면 커서가 풀립니다.

같은 방법으로 **삼인칭** 템플릿과 **비히클** 템플릿 프로젝트도 하나씩 만들어 플레이해 보세요. 세 템플릿 모두 프로그래밍 코드 없이 블루프린트만으로 만들어져 있습니다.

### 01-6 디폴트 폰 클래스 바꾸기

플레이어가 직접 조종하는 대상을 언리얼에서는 **폰**이라고 부릅니다. 일인칭 템플릿의 캐릭터도, 비히클 템플릿의 자동차도 폰입니다.

게임이 시작될 때 어떤 폰을 꺼내 줄지는 **디폴트 폰 클래스**라는 설정이 정합니다. 비히클 템플릿에서 이 값을 바꿔 자동차를 교체해 봅니다.

1. 비히클 템플릿 프로젝트를 연다.
2. 화면 오른쪽 **월드 세팅** 패널을 찾는다. 보이지 않으면 메뉴 바에서 **창 → 월드 세팅**을 누른다.
3. **게임 모드** 항목 아래 **디폴트 폰 클래스**의 드롭다운을 누른다.
4. `SportsCar_Pawn`을 `OffroadCar_Pawn`으로 바꾼다.
5. 재생 버튼을 눌러 자동차가 바뀌었는지 확인한다.

![월드 세팅 패널의 게임 모드 항목에서 디폴트 폰 클래스 드롭다운을 연 화면](./img/01-world-settings-default-pawn.png)

두 자동차는 생김새뿐 아니라 속도와 조작감도 다릅니다. 설정 한 칸을 바꿨을 뿐인데 게임의 주인공이 바뀐 것입니다. 게임 모드가 무엇인지는 Chapter 16에서 자세히 다룹니다.

### 01-7 블루프린트 열어 보기

이번에는 일인칭 템플릿으로 돌아가 캐릭터의 블루프린트를 직접 열어 봅니다.

1. 일인칭 템플릿 프로젝트를 연다.
2. 월드 세팅의 **디폴트 폰 클래스** 오른쪽에 있는 폴더 모양 돋보기 아이콘을 누른다.
3. 화면 아래 **콘텐츠 브라우저**에서 해당 파일이 선택되어 강조된다. 그 파일을 더블클릭한다.
4. 새 창이 열리고 가운데 격자무늬 화면에 색이 있는 상자와 선이 보인다.

콘텐츠 브라우저는 프로젝트에 들어 있는 파일을 보여 주는 창입니다. 새로 열린 창은 **블루프린트 에디터**이고, 격자무늬 화면은 동작을 만드는 **이벤트 그래프**입니다.

| 조작 | 동작 |
|---|---|
| 마우스 오른쪽 버튼을 누른 채 드래그 | 그래프 화면 이동 |
| 마우스 휠 | 확대·축소 |
| 선 끝의 동그라미나 화살표를 드래그 | 선을 다른 곳에 연결 |
| `Alt` + 선 끝 클릭 | 선 끊기 |

상자가 보이지 않으면 격자무늬 아무 곳이나 클릭한 뒤 휠을 내려 화면을 축소합니다.

이동이나 시점 회전에 연결된 선을 하나 바꾸고, 왼쪽 위 **컴파일** 버튼을 누른 다음 플레이해 보세요. 컴파일은 그래프에서 바꾼 내용을 게임에 반영하는 버튼입니다. 캐릭터의 움직임이 달라지는 것을 확인했으면 `Ctrl + Z`로 되돌립니다. 노드와 선의 정확한 의미는 Chapter 09에서 배웁니다.

### 01-8 에디터 화면 구성

프로젝트를 열었을 때 보이는 전체 창을 **레벨 에디터**라고 합니다. 앞으로 계속 나올 이름이므로 위치를 눈에 익혀 둡니다.

![레벨 에디터 전체 화면에 메뉴 바·툴바·뷰포트·아웃라이너·디테일 패널·콘텐츠 브라우저 위치를 번호로 표시한 그림](./img/01-level-editor-layout.png)

| 영역 | 위치 | 역할 |
|---|---|---|
| 메뉴 바 | 맨 위 | 파일, 편집, 창 같은 전체 메뉴 |
| 툴바 | 메뉴 바 아래 | 저장, 모드 전환, 추가, 재생 버튼 |
| 뷰포트 | 가운데 | 게임 세상을 보고 꾸미는 화면 |
| 아웃라이너 | 오른쪽 위 | 지금 세상에 놓인 물체의 목록 |
| 디테일 패널 | 오른쪽 아래 | 선택한 물체의 설정값 |
| 콘텐츠 브라우저 | 아래 | 프로젝트에 들어 있는 파일 목록 |

콘텐츠 브라우저가 보이지 않으면 화면 왼쪽 아래의 **콘텐츠 드로어** 버튼을 누르거나 `Ctrl + Space`를 누릅니다. 패널을 실수로 닫았다면 메뉴 바의 **창** 메뉴에서 다시 열 수 있습니다.

### 01-9 따라하기 — 템플릿 세 가지 체험

1. 일인칭, 삼인칭, 비히클 템플릿 프로젝트를 블루프린트로 하나씩 만든다.
2. 각 프로젝트를 플레이하고 `F11`과 `Esc`를 써 본다.
3. 비히클 프로젝트에서 디폴트 폰 클래스를 바꿔 다른 자동차로 플레이한다.
4. 일인칭 프로젝트에서 캐릭터 블루프린트를 열고 이벤트 그래프를 이동·확대·축소해 본다.
5. 레벨 에디터에서 아웃라이너의 항목을 하나 클릭하고, 디테일 패널의 내용이 바뀌는지 확인한다.

이 장에서는 설치와 체험까지만 다뤘습니다. Chapter 02에서 뷰포트를 조작해 직접 맵을 꾸밉니다.

### 연습문제

1. 문제: 게임 엔진이 필요한 이유를 한 문장으로 쓰세요.  
   - 조건: "공통 기능"이라는 말을 포함할 것
2. 문제: 디폴트 폰 클래스를 바꾸면 게임에서 무엇이 달라지는지 한 문장으로 쓰세요.  
   - 조건: 비히클 템플릿에서 직접 바꿔 본 결과를 근거로 쓸 것
3. 문제: 선택한 물체의 설정값을 바꾸려면 어느 패널을 봐야 하는지 쓰세요.  
   - 조건: 패널 이름 하나만 쓸 것

### 정답 포인트

- 게임마다 반복되는 공통 기능을 미리 제공하므로 직접 만들 필요가 없다. 디폴트 폰 클래스를 바꾸면 시작할 때 조종하는 대상이 바뀐다. 설정값은 디테일 패널.
