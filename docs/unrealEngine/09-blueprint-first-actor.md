# Chapter 09 블루프린트 첫 액터

## 학습 목표

- 블루프린트 클래스를 만들고 컴포넌트를 추가해 눈에 보이는 액터를 만들 수 있다.
- 노드, 실행 핀, 데이터 핀의 역할을 구분할 수 있다.
- BeginPlay와 Tick 이벤트가 언제 실행되는지 설명할 수 있다.
- Delta Seconds를 이용해 일정한 속도로 회전하는 액터를 만들 수 있다.

## 본문

### 09-1 블루프린트 클래스 만들기

지금까지는 레벨에 놓인 액터가 모두 가만히 있었습니다. 스스로 움직이는 액터를 만들려면 액터에 동작을 넣어야 합니다.

**블루프린트 클래스**는 액터의 생김새와 동작을 함께 담아 두는 에셋입니다. 붕어빵 틀과 같아서, 한 번 만들어 두면 레벨에 여러 개를 찍어 놓을 수 있습니다. 틀에 해당하는 것을 **클래스**, 찍혀 나온 하나하나를 **인스턴스**라고 부릅니다.

1. 콘텐츠 브라우저를 우클릭하고 **블루프린트 클래스**를 누른다.
2. 부모 클래스 선택 창에서 **액터**를 고른다.
3. 이름을 `BP_RotatingCube`로 짓고 더블클릭해 연다.

**부모 클래스**는 새 클래스가 기본으로 물려받을 바탕입니다. 액터를 고르면 레벨에 놓일 수 있다는 성질을 물려받습니다. 이것을 "액터를 상속받는 블루프린트를 만들었다"고 말합니다.

### 09-2 컴포넌트 추가

방금 만든 블루프린트는 아직 아무 모양이 없습니다. 액터에 붙이는 부품을 **컴포넌트**라고 하고, 모양을 보여 주는 부품, 빛을 내는 부품, 부딪힘을 감지하는 부품을 붙여 액터를 완성합니다.

1. 블루프린트 에디터 왼쪽 위 **컴포넌트** 탭에서 **추가**를 누른다.
2. 목록에서 **큐브**를 고른다.
3. 가운데 **뷰포트** 탭에 정육면체가 나타나는지 확인한다.

![블루프린트 에디터: 왼쪽 컴포넌트 탭에 Cube가 추가되고 가운데 뷰포트에 정육면체가 보이는 화면](./img/09-blueprint-add-cube-component.png)

큐브 컴포넌트를 선택하면 오른쪽 디테일 패널에서 크기와 머티리얼을 바꿀 수 있습니다. Chapter 08에서 만든 머티리얼을 지정해도 됩니다.

### 09-3 노드와 핀

동작은 **이벤트 그래프** 탭에서 만듭니다. Chapter 01에서 구경만 했던 격자무늬 화면입니다.

그래프에 놓인 상자 하나를 **노드**라고 합니다. 노드는 미리 만들어진 기능 하나입니다. 노드의 가장자리에 있는 연결 지점을 **핀**이라고 하고, 핀에는 두 종류가 있습니다.

| 핀 | 모양 | 역할 |
|---|---|---|
| 실행 핀 | 흰색 화살표 | 어떤 순서로 실행할지 잇는다 |
| 데이터 핀 | 색이 있는 동그라미 | 값을 주고받는다 |

노드의 왼쪽에 있는 핀은 받는 쪽이라 **입력 핀**, 오른쪽에 있는 핀은 내보내는 쪽이라 **출력 핀**입니다. 출력 핀을 드래그해 다른 노드의 입력 핀에 놓으면 선으로 이어집니다.

### 09-4 BeginPlay와 Print String

언제 실행할지를 정하는 노드를 **이벤트**라고 합니다. 이벤트 노드는 빨간색이고, 시작점이기 때문에 실행 입력 핀이 없습니다.

새 블루프린트의 이벤트 그래프에는 반투명한 이벤트 노드가 미리 놓여 있습니다. 그중 **Event BeginPlay**는 게임이 시작되어 이 액터가 레벨에 나타났을 때 한 번 실행됩니다.

화면에 글자를 찍어 실행되는지 확인해 봅니다.

1. `Event BeginPlay`의 실행 핀을 드래그해 빈 곳에 놓는다.
2. 검색창에 `Print String`을 입력해 고른다.
3. `Print String` 노드의 **In String** 칸에 `Hello`라고 적는다.
4. 왼쪽 위 **컴파일**을 누르고 저장한다.
5. 콘텐츠 브라우저에서 `BP_RotatingCube`를 레벨로 끌어다 놓는다.
6. 재생 버튼을 누른다.

뷰포트 왼쪽 위에 `Hello`가 잠깐 나타납니다. **Print String**은 넘겨받은 글자를 화면과 출력 로그에 찍는 노드입니다. 만든 기능이 실행되는지, 값이 얼마인지 확인할 때 가장 자주 씁니다. 프로그래밍에서는 글자 묶음을 **문자열**이라고 부르고, String이 문자열이라는 뜻입니다.

### 09-5 Tick과 회전

**Event Tick**은 게임 화면이 한 번 그려질 때마다 실행되는 이벤트입니다. 화면 한 장을 **프레임**이라고 하고, 1초에 보통 수십 프레임이 그려집니다. 매 프레임 조금씩 돌리면 계속 회전하는 것처럼 보입니다.

1. `Event Tick`의 실행 핀을 드래그해 `Add Actor World Rotation` 노드를 만든다.
2. 노드의 **Delta Rotation** 핀을 우클릭하고 **구조체 핀 분할**을 누른다. X, Y, Z 세 칸으로 나뉜다.
3. **Delta Rotation Z** 칸에 `1`을 적는다.
4. 컴파일하고 플레이한다.

**Add Actor World Rotation**은 지금 회전값에 넘겨받은 만큼을 더하는 노드입니다. Z는 위에서 내려다봤을 때 도는 방향입니다. 큐브가 돌기는 하지만 문제가 있습니다. 성능이 좋은 컴퓨터는 1초에 프레임을 더 많이 그리므로 Tick이 더 자주 실행되고, 큐브가 더 빨리 돕니다.

### 09-6 Delta Seconds

컴퓨터 성능과 관계없이 같은 속도로 돌게 하려면 프레임 사이에 흐른 시간을 알아야 합니다.

`Event Tick` 노드에는 **Delta Seconds**라는 초록색 데이터 핀이 있습니다. 바로 앞 프레임부터 지금 프레임까지 걸린 시간을 초 단위로 내보냅니다. 프레임이 자주 그려지면 이 값이 작고, 드물게 그려지면 큽니다.

1초에 돌리고 싶은 각도에 Delta Seconds를 곱하면, 프레임마다 돌릴 각도가 됩니다.

1. `Delta Seconds` 핀을 드래그해 빈 곳에 놓고 `*`를 검색해 **곱하기** 노드를 만든다.
2. 곱하기 노드의 아래 칸에 `90`을 적는다.
3. 곱하기 노드의 출력을 **Delta Rotation Z**에 연결한다.
4. 컴파일하고 플레이한다.

![이벤트 그래프: Event Tick의 Delta Seconds에 90을 곱해 Add Actor World Rotation의 Delta Rotation Z에 연결한 노드](./img/09-tick-delta-rotation.png)

이제 어떤 컴퓨터에서도 1초에 90도씩 돕니다. 1초에 60프레임이 그려지는 컴퓨터는 한 번에 1.5도씩 60번, 30프레임이 그려지는 컴퓨터는 한 번에 3도씩 30번 돌려 결과가 같아집니다. Tick에서 무언가를 움직일 때는 항상 Delta Seconds를 곱합니다.

### 09-7 따라하기 — 회전하는 큐브

1. 액터를 부모로 `BP_RotatingCube`를 만들고 큐브 컴포넌트를 추가한다.
2. BeginPlay에 `Print String`을 연결해 시작할 때 글자가 찍히는지 확인한다.
3. Tick과 Delta Seconds로 1초에 90도씩 회전시킨다.
4. 레벨에 `BP_RotatingCube`를 세 개 놓고 모두 회전하는지 확인한다.
5. `Add Actor World Rotation` 대신 `Add Actor World Offset` 노드를 쓰고 **Delta Location Z**에 연결해, 위로 떠오르는 큐브를 만든다.

5번의 **Add Actor World Offset**은 지금 위치에 넘겨받은 만큼을 더하는 노드입니다. 변수를 써서 인스턴스마다 다른 속도를 주는 방법은 Chapter 12에서 다룹니다.

### 연습문제

1. 문제: 실행 핀과 데이터 핀의 차이를 한 줄씩 쓰세요.  
   - 조건: 핀의 모양을 함께 쓸 것
2. 문제: `Event BeginPlay`와 `Event Tick`이 각각 언제 실행되는지 한 줄씩 쓰세요.
3. 문제: Tick에서 회전값에 Delta Seconds를 곱하지 않으면 생기는 문제를 한 문장으로 쓰세요.  
   - 조건: "프레임"이라는 말을 포함할 것

### 정답 포인트

- 실행 핀은 흰 화살표로 실행 순서, 데이터 핀은 색 동그라미로 값 전달. BeginPlay는 시작할 때 한 번, Tick은 매 프레임. 프레임 수가 많은 컴퓨터일수록 더 빨리 돈다.
