# Chapter 06 머티리얼 — 시간과 그레이디언트

## 학습 목표

- Time 노드와 Frac 노드로 반복되는 색상 애니메이션을 만들 수 있다.
- 반복, 왕복, 깜빡임 흐름을 머티리얼 함수로 묶어 재사용할 수 있다.
- UV 좌표로 가로·세로 그레이디언트를 만들 수 있다.
- Floor와 Fmod로 줄무늬와 체크 패턴을 만들 수 있다.

## 본문

### 06-1 입력 노드와 Time

Chapter 05의 머티리얼은 한 번 정한 색이 계속 그대로였습니다. 전구가 깜빡이거나 네온사인 색이 천천히 변하는 효과를 만들려면 시간이 흐르는 것을 머티리얼이 알아야 합니다.

머티리얼 노드는 역할에 따라 세 종류로 나뉩니다.

| 종류 | 특징 | 예 |
|---|---|---|
| 입력 노드 | 엔진이 값을 넣어 준다. 왼쪽에 핀이 없고 빨간색으로 표시된다 | `Time`, `TexCoord` |
| 일반 노드 | 값을 받아 계산해 넘긴다. 양쪽에 핀이 있다 | `Add`, `Multiply`, `Frac` |
| 출력 노드 | 최종 결과를 받는다. 오른쪽에 핀이 없다 | 결과 노드 |

상수 노드는 한 번 정하면 바뀌지 않지만, 입력 노드는 실행 중 상황에 따라 엔진이 다른 값을 넣어 줍니다.

**`Time`** 노드는 프로그램이 시작된 뒤 흐른 시간을 초 단위로 내보냅니다. 그래프를 우클릭해 `Time`을 검색해서 만들고 `DebugScalarValues`에 연결해 보면 숫자가 계속 커지는 것을 볼 수 있습니다.

### 06-2 반복 애니메이션

`Time` 값은 1초만 지나도 `1`을 넘습니다. 그대로 최종 색에 연결하면 계속 흰색만 보입니다.

여기서 소수점 아래만 보면 `0`에서 `1`까지 올라갔다가 다시 `0`으로 돌아가기를 매초 반복합니다. Chapter 05에서 쓴 `Frac` 노드가 바로 소수점 아래만 남기는 노드입니다.

1. `Time` 노드를 `Frac` 노드에 연결한다.
2. `Frac`을 최종 색에 연결한다.

검정에서 흰색으로 밝아지는 움직임이 1초마다 반복됩니다. 끝나면 처음으로 돌아가 다시 시작하는 이런 흐름을 **반복**이라고 부릅니다.

속도를 바꾸려면 `Frac`에 넣기 전에 시간에 수를 곱합니다.

| `Time`에 곱하는 수 | 결과 |
|---|---|
| `2` | 두 배 빠르게. 0.5초마다 반복 |
| `0.5` | 두 배 느리게. 2초마다 반복 |

### 06-3 반전, 깜빡임, 왕복

`0`에서 `1`로 흐르는 값 하나만 있으면 노드를 덧붙여 여러 가지 흐름을 만들 수 있습니다.

| 노드 | 단축키 | 계산 | 흐름에 붙였을 때 |
|---|---|---|---|
| `1-x` | `O` + 클릭 | 1에서 입력을 뺀다 | 흰색에서 검정으로 거꾸로 흐른다 |
| `Round` | 없음 | 0.5보다 크면 1, 아니면 0 | 0.5초마다 검정과 흰색이 번갈아 깜빡인다 |
| `Min` | 없음 | 두 값 중 작은 쪽 | 아래 왕복 흐름에 쓴다 |

**왕복**은 `0`에서 `1`로 갔다가 끊기지 않고 다시 `0`으로 돌아오는 흐름입니다. 탁구공이 오가는 모습에 빗대어 핑퐁이라고도 합니다.

1. `Frac` 결과를 `1-x` 노드에 연결해 거꾸로 흐르는 값을 만든다.
2. `Min` 노드에 `Frac` 결과와 `1-x` 결과를 함께 연결한다.
3. `Min` 결과에 `Multiply`로 `2`를 곱한다.

올라가는 값과 내려가는 값 중 작은 쪽만 고르면, 앞 절반은 올라가는 값이 선택되고 뒤 절반은 내려가는 값이 선택됩니다. 다만 최댓값이 `0.5`에서 멈추기 때문에 `2`를 곱해 `1`까지 닿게 합니다.

![왕복 흐름 그래프: Time → Frac 과 1-x 를 Min 으로 합치고 Multiply 2 를 거쳐 최종 색에 연결한 노드와 삼각형 모양 그래프](./img/06-pingpong-graph.png)

### 06-4 머티리얼 함수로 묶기

반복, 왕복, 깜빡임은 앞으로 여러 머티리얼에서 계속 씁니다. 매번 노드를 복사해 붙이는 대신 한 번 만들어 이름을 붙여 두고 꺼내 씁니다. 노드 묶음에 이름을 붙여 재사용할 수 있게 만든 에셋을 **머티리얼 함수**라고 합니다.

함수는 값을 받아 계산한 뒤 결과를 내주는 상자입니다. 받는 값을 입력, 내주는 값을 출력이라고 합니다. 이번 함수의 설계는 다음과 같습니다.

| 구분 | 이름 | 종류 | 설명 |
|---|---|---|---|
| 입력 | `PlayRate` | 스칼라 | 재생 속도. 기본값 1 |
| 출력 | `Loop` | 스칼라 | 반복 흐름 |
| 출력 | `PingPong` | 스칼라 | 왕복 흐름 |
| 출력 | `Switch` | 스칼라 | 깜빡임 흐름 |

만드는 순서입니다.

1. 콘텐츠 브라우저를 우클릭해 **머티리얼 → 머티리얼 함수**를 만든다. 이름은 `MF_TimeFlow`로 한다.
2. 더블클릭해 연다. `Result`라는 출력 노드가 하나 있다. 이름을 `Loop`로 바꾼다.
3. 출력 노드를 선택해 `Ctrl + D`로 복제하고 이름을 `PingPong`으로 바꾼다. 디테일 패널의 **정렬 우선순위**를 `1`로 한다.
4. 한 번 더 복제해 이름을 `Switch`, 정렬 우선순위를 `2`로 한다.
5. 우클릭해 `Input`을 검색하고 **Function Input** 노드를 만든다. 이름을 `PlayRate`, 입력 타입을 **스칼라**로 한다.
6. `1` + 클릭으로 상수 `1`을 만들어 입력 노드의 **Preview** 핀에 연결하고, 입력 노드의 **프리뷰 값을 디폴트로 사용**에 체크한다.
7. `Time`에 `PlayRate`를 곱하고 `Frac`을 거친 값을 `Loop`에 연결한다.
8. 06-3의 왕복 노드를 만들어 `PingPong`에 연결한다.
9. `Frac` 결과를 `Round`에 연결해 `Switch`에 연결한다.
10. 그래프 빈 곳을 클릭하고 디테일 패널의 **라이브러리에 노출**에 체크한 뒤 저장한다.

정렬 우선순위는 출력 핀이 나열되는 순서이고 숫자가 작을수록 위에 옵니다. **라이브러리에 노출**을 체크하지 않으면 다른 머티리얼에서 검색해도 이 함수가 나오지 않습니다. 만든 함수가 검색되지 않을 때 가장 먼저 확인할 옵션입니다.

이제 아무 머티리얼에서 우클릭해 `MF_TimeFlow`를 검색하면 노드 하나로 꺼내 쓸 수 있습니다.

### 06-5 UV 좌표

지금까지는 화면 전체가 한 가지 색이었습니다. 한 색에서 다른 색으로 서서히 변하는 표현을 **그레이디언트**라고 하는데, 이를 만들려면 화면의 위치마다 다른 색을 내야 합니다.

화면은 **픽셀**이라는 작은 점들로 이루어져 있고, 그래픽 카드는 점 하나를 그릴 때마다 머티리얼을 한 번씩 계산합니다. 지금 그리는 점이 어디인지 알 수 있다면 위치에 따라 다른 색을 낼 수 있습니다.

**`TexCoord`** 노드는 지금 그리는 점의 위치를 2차원 벡터로 내보내는 입력 노드입니다. `U`를 누른 채 클릭하면 만들어집니다. 이 좌표는 `(x, y)` 대신 `(u, v)`라는 글자를 써서 **UV 좌표**라고 부릅니다.

![UV 좌표계: 왼쪽 위가 (0,0), 오른쪽 위가 (1,0), 왼쪽 아래가 (0,1), 오른쪽 아래가 (1,1)인 사각형 그림](./img/06-uv-coordinates.png)

| 성질 | 내용 |
|---|---|
| 범위 | u와 v 모두 `0`에서 `1` |
| u | 왼쪽이 `0`, 오른쪽이 `1` |
| v | 위쪽이 `0`, 아래쪽이 `1`. 수학 그래프와 세로 방향이 반대 |

`TexCoord`를 바로 최종 색에 연결하면 왼쪽 위는 검정, 오른쪽 위는 빨강, 왼쪽 아래는 초록, 오른쪽 아래는 노랑으로 보입니다. 2차원 벡터 `(u, v)`를 색으로 쓰면 부족한 세 번째 값이 `0`으로 채워져 `(u, v, 0)`이 되기 때문입니다. u가 빨강의 양, v가 초록의 양이 됩니다.

### 06-6 그레이디언트 만들기

UV 좌표에서 u만 꺼내면 왼쪽에서 오른쪽으로 밝아지는 흑백 그레이디언트가 됩니다.

1. `TexCoord` 노드를 `ComponentMask`에 연결하고 R에만 체크한다.
2. 최종 색에 연결한다.

G에만 체크하면 v가 나와 위에서 아래로 밝아지는 그레이디언트가 됩니다.

이 그레이디언트에 06-3의 노드를 붙이면 화면이 구역으로 나뉩니다.

| 그레이디언트 뒤에 붙이는 노드 | 결과 |
|---|---|
| `Round` | 왼쪽 절반은 검정, 오른쪽 절반은 흰색 |
| `Multiply` 5 다음 `Frac` | 같은 그레이디언트가 다섯 번 반복 |
| `Multiply` 5 다음 `Frac` 다음 `Round` | 검정과 흰색 줄무늬 다섯 쌍 |

시간에서는 `Frac`이 흐름을 반복시켰고, 좌표에서는 `Frac`이 무늬를 반복시킵니다. 같은 노드가 넣는 값에 따라 다른 효과를 냅니다.

### 06-7 줄무늬와 체크 패턴

`Round`로 나누면 구역이 항상 짝수 개로만 나뉩니다. 원하는 개수로 나누려면 두 노드를 더 씁니다.

| 노드 | 계산 | 예 |
|---|---|---|
| `Floor` | 소수점 아래를 버린다 | `3.7`이면 `3` |
| `Fmod` | A를 B로 나눈 나머지 | `5`를 `2`로 나누면 `1` |

어떤 정수든 `2`로 나눈 나머지는 짝수면 `0`, 홀수면 `1`입니다. 이것을 이용해 줄무늬를 만듭니다.

1. u 그레이디언트에 `Multiply`로 `5`를 곱한다. 값이 `0`에서 `5`까지 커진다.
2. `Floor`에 연결한다. 구역마다 `0`, `1`, `2`, `3`, `4`가 된다.
3. `Fmod`의 A에 연결하고 B에 `2`를 넣는다. 구역마다 `0`, `1`, `0`, `1`, `0`이 된다.

검정과 흰색이 번갈아 나오는 줄 다섯 개가 만들어집니다. 곱하는 수를 `7`로 바꾸면 일곱 줄이 됩니다.

체크 패턴은 가로 번호와 세로 번호를 더한 값이 짝수인지 홀수인지로 정합니다.

1. `TexCoord`에 2차원 벡터 `(5, 5)`를 `Multiply`로 곱한다.
2. `Floor`에 연결한다.
3. `ComponentMask`로 R과 G를 각각 꺼내 `Add`로 더한다.
4. `Fmod`의 A에 연결하고 B에 `2`를 넣는다.

![체크 패턴 그래프와 5×5 흑백 체크무늬 미리보기](./img/06-checker-pattern-graph.png)

곱하는 벡터를 `(8, 4)`처럼 가로와 세로를 다르게 넣으면 길쭉한 체크 패턴이 됩니다.

### 06-8 따라하기 — 움직이는 줄무늬

1. `Time`과 `Frac`으로 1초마다 밝아지는 머티리얼을 만든다.
2. `MF_TimeFlow` 머티리얼 함수를 만들고 라이브러리에 노출한다.
3. 새 머티리얼에서 `MF_TimeFlow`의 `Loop`, `PingPong`, `Switch`를 차례로 최종 색에 연결해 차이를 본다.
4. `PlayRate`에 `0.5`를 넣어 속도가 느려지는지 확인한다.
5. 가로 그레이디언트, 세로 그레이디언트, 줄무늬 일곱 줄, 5×5 체크 패턴을 만든다.
6. 줄무늬 머티리얼에서 u 그레이디언트에 `MF_TimeFlow`의 `Loop`를 `Add`로 더한 뒤 줄무늬 계산을 이어서, 줄무늬가 옆으로 흐르게 만든다.

Chapter 07에서는 이 흑백 구역을 이용해 사각형과 원을 그립니다.

### 연습문제

1. 문제: `Time` 노드를 그대로 최종 색에 연결하면 계속 흰색만 보이는 이유를 한 문장으로 쓰세요.
2. 문제: 왕복 흐름을 만들 때 `Min` 결과에 `2`를 곱하는 이유를 한 문장으로 쓰세요.  
   - 조건: 곱하기 전 최댓값을 숫자로 쓸 것
3. 문제: 줄무늬를 세 줄로 만들려면 06-7의 순서에서 어느 값을 무엇으로 바꿔야 하는지 쓰세요.  
   - 조건: `Round`가 아닌 `Floor`와 `Fmod`를 쓰는 방법으로 답할 것

### 정답 포인트

- 1초만 지나도 값이 `1`을 넘어서. `Min` 결과의 최댓값이 `0.5`라서 `1`까지 닿게 하려고. `Multiply`에 넣는 수를 `3`으로.
