# Chapter 03 랜드스케이프

## 학습 목표

- 랜드스케이프를 새로 만들고 크기 설정 항목의 의미를 설명할 수 있다.
- 스컬프트 툴과 브러시 옵션으로 지형을 올리고 깎고 다듬을 수 있다.
- 만든 지형 일부를 복사해 다른 곳에 붙여 넣을 수 있다.
- 스플라인으로 곡선 도로를 만들 수 있다.

## 본문

### 03-1 랜드스케이프 만들기

Chapter 02에서는 큐브를 납작하게 눌러 바닥으로 썼습니다. 방 하나는 이렇게 만들 수 있지만, 언덕과 골짜기가 있는 넓은 야외를 큐브로 쌓아 만들기는 어렵습니다.

**랜드스케이프**는 넓은 지형 전용 액터입니다. 한 장의 넓은 판을 붓으로 문질러 올리거나 내리는 방식으로 땅 모양을 만듭니다.

1. 새 레벨을 **기본**으로 만든다. 하늘과 빛이 미리 들어 있다.
2. 처음 들어 있는 바닥 액터는 선택해서 `Delete`로 지운다.
3. 툴바의 모드 버튼을 **선택 모드**에서 **랜드스케이프 모드**로 바꾼다. 단축키는 `Shift + 2`이다.
4. 왼쪽 패널에서 아래 값을 확인하고 **생성**을 누른다.

![랜드스케이프 모드의 새 랜드스케이프 설정 패널과 뷰포트에 표시된 초록색 격자 미리보기](./img/03-landscape-new-settings.png)

| 항목 | 의미 |
|---|---|
| 위치·회전 | 지형이 놓일 자리. `0, 0, 0`으로 둔다 |
| 스케일 | 지형 한 칸의 크기. 기본값 `100, 100, 100` |
| 섹션 크기 | 한 구역에 들어가는 칸 수. 미리보기의 굵은 초록 선 하나가 한 섹션 |
| 컴포넌트별 섹션 | 컴포넌트 하나를 섹션 몇 개로 나눌지 |
| 컴포넌트 수 | 지형 전체를 컴포넌트 몇 개로 깔지 |
| 전체 해상도 | 위 값들로 계산된 전체 칸 수 |

랜드스케이프는 **컴포넌트**라는 조각 여러 개로 이루어집니다. 지형의 실제 크기는 스케일, 섹션 크기, 컴포넌트별 섹션, 컴포넌트 수를 곱한 만큼 커집니다. 처음에는 기본값 그대로 만들어도 충분합니다.

### 03-2 스컬프트 툴

지형을 붓으로 빚는 일을 **스컬프팅**이라고 합니다. 랜드스케이프 모드의 **스컬프트** 탭에 여러 툴이 있습니다.

| 툴 | 동작 |
|---|---|
| 스컬프트 | 문지른 곳을 올린다. `Shift`를 누른 채 문지르면 내린다 |
| 지우기 | 스컬프트한 결과를 원래 높이로 되돌린다 |
| 스무드 | 울퉁불퉁한 곳을 부드럽게 편다 |
| 플래튼 | 처음 클릭한 높이에 맞춰 평평하게 만든다 |
| 경사로 | 두 지점을 찍어 그 사이에 비탈길을 만든다 |
| 침식 | 비바람에 깎인 것처럼 자연스럽게 깎는다 |
| 노이즈 | 무작위로 올리고 내려 거친 표면을 만든다 |

툴을 고른 뒤 뷰포트에서 마우스 왼쪽 버튼을 누른 채 지형을 문지릅니다. 마우스를 따라다니는 원이 붓이 닿는 범위입니다.

### 03-3 브러시 옵션

붓의 모양과 세기를 정하는 값을 묶어 **브러시** 옵션이라고 합니다. 같은 스컬프트 툴이라도 브러시에 따라 결과가 크게 달라집니다.

![스컬프트 탭의 브러시 타입·브러시 감쇠·툴 강도·브러시 크기 옵션과 뷰포트의 이중 원 브러시 표시](./img/03-brush-options.png)

| 옵션 | 의미 |
|---|---|
| 툴 강도 | 한 번 문지를 때 지형이 바뀌는 세기 |
| 브러시 크기 | 붓이 닿는 범위. 뷰포트의 바깥 원 크기 |
| 브러시 감쇠 | 가장자리로 갈수록 세기가 약해지는 정도. 뷰포트의 안쪽 원이 세기가 그대로인 범위 |
| 클레이 브러시 사용 | 켜면 붓 범위 전체가 고르게 올라오고, 끄면 가운데가 볼록하게 솟는다 |

브러시 감쇠가 `0`이면 안쪽 원과 바깥 원이 같아져 가장자리가 절벽처럼 뚝 끊깁니다. 값을 키울수록 안쪽 원이 작아지고 경계가 부드러워집니다.

**브러시 타입**은 붓의 모양입니다.

| 타입 | 모양 |
|---|---|
| 원형 | 둥근 붓. 기본값 |
| 알파 | 그림 파일의 밝기를 붓 모양으로 쓴다. 붓을 움직이면 그림도 따라 움직인다 |
| 패턴 | 그림 파일을 지형 전체에 깔아 놓은 무늬로 쓴다. 붓을 움직여도 무늬 위치는 고정이다 |
| 컴포넌트 | 붓이 컴포넌트 한 조각 전체에 닿는다 |

알파와 패턴 타입을 고르면 **텍스처** 칸이 생깁니다. **텍스처**는 그림 파일 에셋을 가리키는 말입니다. **텍스처 채널**은 그림의 빨강, 초록, 파랑 값 중 어느 것을 붓의 세기로 쓸지 고르는 옵션입니다. 알파 브러시의 **자동 회전**을 켜면 붓을 움직이는 방향으로 그림이 돌아갑니다.

원형 붓에는 **브러시 감쇠 유형**도 있습니다. 가장자리로 갈수록 세기가 줄어드는 곡선의 모양을 고르는 옵션이며, 스무드는 부드러운 언덕, 리니어는 일정한 비탈, 구체는 둥근 돔, 팁은 뾰족한 봉우리 모양이 됩니다.

### 03-4 지형 복사와 붙여넣기

잘 만든 언덕을 다른 자리에도 놓고 싶을 때는 복사 기능을 씁니다. 복사할 범위는 **기즈모**라는 임시 상자로 정합니다.

1. 스컬프트 탭에서 **선택** 툴을 고르고, 복사할 지형 위를 문질러 영역을 칠한다.
2. **복사** 툴로 바꾼다. 레벨에 상자 모양의 기즈모가 나타난다.
3. 툴 옵션의 **기즈모를 선택된 리전에 맞춤**을 누른다. 기즈모가 칠한 영역 크기로 맞춰진다.
4. **데이터를 기즈모에 복사**를 누른다.
5. 기즈모를 붙여 넣을 자리로 옮긴다.
6. `Ctrl + V`를 누른다.

![복사 툴에서 기즈모 상자가 선택 영역을 감싼 모습과 툴 옵션의 맞춤·복사 버튼](./img/03-landscape-copy-gizmo.png)

선택 툴을 쓰지 않고 기즈모의 위치와 크기를 직접 맞춘 뒤 복사해도 됩니다. `Ctrl + V` 대신 기즈모가 있는 자리를 붓으로 문지르면 브러시 설정에 따라 천천히 붙여 넣어집니다.

### 03-5 관리 탭

**관리** 탭은 랜드스케이프의 조각 자체를 늘리거나 줄이는 곳입니다.

| 툴 | 동작 |
|---|---|
| 새로 만들기 | 랜드스케이프 액터를 하나 더 만든다 |
| 선택 | 컴포넌트를 클릭해 고른다. **컴포넌트 선택 지우기**로 해제한다 |
| 추가 | 가장자리 바깥을 클릭해 컴포넌트를 덧붙인다. 지형이 넓어진다 |
| 삭제 | 클릭한 컴포넌트를 없앤다 |

랜드스케이프를 두 개 이상 만들면 스컬프트 탭 위쪽에 편집할 랜드스케이프를 고르는 드롭다운이 생깁니다. 붓은 여기서 고른 랜드스케이프에만 작용합니다.

관리 탭에는 컴포넌트를 다른 레벨로 옮기는 **레벨로 이동** 툴도 있습니다. 넓은 세상을 여러 레벨로 나눠 필요한 부분만 불러오던 예전 방식에서 쓰던 툴입니다. 지금은 넓은 세상을 자동으로 나눠 불러오는 **월드 파티션** 기능이 그 역할을 대신하므로 이 과정에서는 쓰지 않습니다. 레벨을 **오픈 월드**로 만들면 월드 파티션이 켜진 상태로 시작합니다.

### 03-6 스플라인으로 곡선 도로 만들기

붓으로는 일정한 폭으로 굽이치는 도로를 만들기 어렵습니다. **스플라인**은 점 몇 개를 찍으면 그 사이를 부드러운 곡선으로 이어 주는 선입니다. 랜드스케이프 스플라인을 쓰면 곡선을 따라 도로 모형을 깔 수 있습니다.

1. 관리 탭에서 **스플라인** 툴을 고른다.
2. `Ctrl`을 누른 채 지형을 클릭한다. 점이 하나 생긴다.
3. `Ctrl`을 누른 채 다른 곳을 클릭한다. 두 점이 선으로 이어진다. 계속 찍으면 선이 이어진다.
4. 점을 선택하고 이동·회전 기즈모로 곡선 모양을 다듬는다.

점을 **컨트롤 포인트**, 점과 점 사이의 선을 **세그먼트**라고 합니다. 이어진 선과 따로 떨어진 새 스플라인을 시작하려면 빈 곳을 클릭해 선택을 해제한 뒤 다시 `Ctrl` 클릭합니다. 세그먼트 위를 `Ctrl` 클릭하면 그 자리에 컨트롤 포인트가 추가됩니다.

이 상태로 선택 모드에 돌아가면 선이 보이지 않습니다. 선을 따라 깔 모형을 지정해야 합니다.

1. 스플라인 툴에서 컨트롤 포인트 하나를 선택한다.
2. 디테일 패널의 **모든 연결 선택** 옆 **세그먼트**를 누른다. 이어진 세그먼트가 전부 선택된다.
3. **스플라인 메시** 배열의 `+`를 눌러 항목을 하나 추가한다.
4. 추가된 항목의 **메시** 칸에 바닥으로 쓸 스태틱 메시를 지정한다.

![랜드스케이프 스플라인 세그먼트를 선택하고 디테일 패널의 스플라인 메시 배열에 바닥 메시를 지정한 화면](./img/03-landscape-spline-mesh.png)

지정한 모형이 곡선을 따라 휘어져 깔립니다. 툴 옵션의 **랜드스케이프를 스플라인에 맞게 변형**을 누르면 도로 아래 지형이 도로 높이에 맞춰 다듬어집니다.

### 03-7 따라하기 — 야외 지형 만들기

1. 기본 레벨에서 바닥을 지우고 랜드스케이프를 기본값으로 만든다.
2. 스컬프트 툴로 산을 하나 올리고, `Shift`를 누른 채 문질러 호수 자리를 판다.
3. 스무드와 플래튼으로 산 중턱에 평평한 터를 만든다.
4. 브러시 감쇠를 `0`과 `1`로 바꿔 가며 가장자리 차이를 확인한다.
5. 산을 복사해 지형 반대편에 붙여 넣는다.
6. 스플라인으로 산을 돌아가는 곡선 도로를 만든다.
7. 플레이어 스타트를 지형 위에 놓고 플레이해서 걸어 다녀 본다.

지금 지형은 회색 한 가지 색입니다. 풀과 아스팔트 같은 겉모습을 입히는 방법은 Chapter 04에서 다룹니다.

### 연습문제

1. 문제: 스컬프트 툴로 지형을 내리려면 어떤 키를 함께 눌러야 하는지 쓰세요.
2. 문제: 브러시 감쇠 값을 `0`으로 두면 지형 가장자리가 어떻게 되는지 한 문장으로 쓰세요.  
   - 조건: 안쪽 원과 바깥 원의 관계를 언급할 것
3. 문제: 알파 브러시와 패턴 브러시의 차이를 두 문장으로 쓰세요.  
   - 조건: 붓을 움직였을 때 무늬 위치가 어떻게 되는지로 비교할 것

### 정답 포인트

- `Shift`. 감쇠 0이면 안쪽 원과 바깥 원이 같아져 경계가 절벽처럼 끊긴다. 알파는 붓을 따라 무늬가 움직이고, 패턴은 무늬 위치가 지형에 고정된다.
