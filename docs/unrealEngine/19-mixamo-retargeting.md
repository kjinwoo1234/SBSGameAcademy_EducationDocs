# Chapter 19 Mixamo와 애니메이션 리타기팅

## 학습 목표

- 외부에서 받은 캐릭터와 애니메이션 FBX를 프로젝트에 임포트할 수 있다.
- 스켈레톤이 다르면 애니메이션을 그대로 쓸 수 없는 이유를 설명할 수 있다.
- IK 릭과 IK 리타기터로 애니메이션을 다른 캐릭터용으로 변환할 수 있다.

## 본문

### 19-1 Mixamo에서 받아 오기

템플릿에 들어 있는 동작은 걷기, 달리기, 점프 정도입니다. 칼을 휘두르거나 구르는 동작이 필요하면 직접 만들거나 외부에서 받아 와야 합니다.

**Mixamo**는 어도비가 운영하는 사이트로, 캐릭터 모형과 동작 데이터를 무료로 내려받을 수 있습니다. 검색 사이트에서 Mixamo를 찾아 들어가 어도비 계정으로 로그인합니다.

1. **Characters** 탭에서 캐릭터를 하나 고른다. 이 과정에서는 `Paladin`을 쓴다.
2. **Download**를 누르고 Format을 `FBX`, Pose를 `T-pose`로 해서 받는다.
3. **Animations** 탭에서 원하는 동작을 고른다. 검과 방패를 쓰는 공격 동작 네 개를 고른다.
4. 동작마다 **Download**를 누르고 Format `FBX`, Skin을 `Without Skin`으로 해서 받는다.

`Without Skin`은 캐릭터 모형 없이 동작 데이터만 받는 옵션입니다. 캐릭터는 한 번만 받으면 되므로 동작은 이 옵션으로 받아 용량을 줄입니다.

### 19-2 프로젝트에 임포트

1. 콘텐츠 브라우저에 `Paladin` 폴더를 만든다.
2. 캐릭터 FBX를 폴더로 끌어다 놓는다. 임포트 옵션 창에서 **스켈레탈 메시**에 체크되어 있고 **스켈레톤** 칸이 비어 있는지 확인한 뒤 **모두 임포트**를 누른다.
3. 스켈레탈 메시, 스켈레톤, 피직스 에셋이 만들어진다.
4. 동작 FBX들을 끌어다 놓는다. 이번에는 임포트 옵션의 **스켈레톤** 칸에 방금 만들어진 팔라딘의 스켈레톤을 지정하고 임포트한다.

스켈레톤 칸을 비우면 새 스켈레톤을 만들고, 지정하면 그 스켈레톤용 애니메이션으로 가져옵니다. 동작을 임포트할 때 스켈레톤을 지정하지 않으면 동작마다 스켈레톤이 따로 생겨 버립니다.

### 19-3 스켈레톤이 다르면 생기는 문제

가져온 공격 동작을 템플릿 마네킹에게 시키고 싶습니다. 그런데 `ABP_MyAnim`의 애셋 브라우저에는 팔라딘의 동작이 보이지 않습니다. 애니메이션 시퀀스는 자신이 만들어진 스켈레톤에서만 재생되기 때문입니다.

애니메이션은 "어느 뼈를 몇 도 돌려라"라는 기록입니다. 마네킹과 팔라딘은 뼈의 개수, 이름, 길이, 기본 방향이 다릅니다. 억지로 재생하면 팔다리가 뒤틀리거나 엉뚱한 방향으로 움직입니다.

![스켈레톤이 맞지 않는 애니메이션을 억지로 재생해 팔다리가 뒤틀린 마네킹 화면](./img/19-broken-animation-mismatch.png)

한 스켈레톤용 애니메이션을 다른 스켈레톤에 맞게 변환하는 작업을 **리타기팅**이라고 합니다.

### 19-4 빠른 리타기팅

최신 엔진 버전에는 널리 쓰이는 스켈레톤끼리 자동으로 변환해 주는 기능이 있습니다.

1. 변환할 애니메이션 시퀀스를 콘텐츠 브라우저에서 선택하고 우클릭한다.
2. **애니메이션 리타기팅** 관련 메뉴를 누른다. 버전에 따라 **애니메이션 에셋 리타깃** 아래에 있다.
3. 열린 창에서 **타깃 스켈레탈 메시**에 이 동작을 재생할 캐릭터를 지정한다.
4. 미리보기에서 동작이 자연스러운지 확인하고 **리타깃**을 누른다.

타깃 스켈레톤용으로 변환된 새 애니메이션 시퀀스가 만들어집니다. 결과가 어색하거나 이 메뉴가 없는 버전이라면 아래의 수동 방법을 씁니다.

### 19-5 IK 릭 만들기

수동 리타기팅은 두 캐릭터의 뼈대에서 "어느 뼈들이 같은 부위인가"를 알려 주는 작업입니다. 부위를 묶어 놓은 에셋을 **IK 릭**이라고 하고, 묶음 하나를 **체인**이라고 합니다. 예를 들어 왼쪽 어깨부터 손목까지의 뼈들을 `LeftArm` 체인으로 묶습니다.

마네킹의 IK 릭은 템플릿에 이미 들어 있습니다. `IK_Mannequin`을 열어 어떤 체인이 있는지 먼저 살펴봅니다. 팔라딘의 IK 릭은 직접 만듭니다.

1. 콘텐츠 브라우저를 우클릭해 **애니메이션 → 리타기팅 → IK 릭**을 누른다.
2. 팔라딘의 스켈레탈 메시를 고르고 이름을 `IK_Paladin`으로 짓는다.
3. 왼쪽 계층 구조에서 `Hips` 뼈를 우클릭하고 **리타깃 루트 설정**을 누른다.
4. 체인의 시작 뼈부터 끝 뼈까지 선택하고 우클릭해 **선택한 본에서 새 리타깃 체인**을 누른다.
5. 체인 이름을 `IK_Mannequin`의 같은 부위 체인 이름과 똑같이 짓는다.
6. 척추, 머리, 양팔, 양다리를 같은 방법으로 만든다.

![IK_Paladin 에디터: 왼쪽 본 계층 구조와 아래 IK 리타기팅 탭에 Spine·Head·LeftArm·RightArm·LeftLeg·RightLeg 체인이 등록된 화면](./img/19-ik-rig-chains.png)

**리타깃 루트**는 캐릭터 전체의 이동과 회전 기준이 되는 뼈입니다. 마네킹은 맨 위에 `root` 뼈가 있고 그 아래 골반이 달려 있지만, Mixamo 캐릭터는 `root` 없이 골반인 `Hips`부터 시작합니다. 리타깃 루트를 지정하지 않으면 캐릭터가 제자리에서 팔다리만 움직이거나 공중에 떠 버립니다.

### 19-6 IK 리타기터로 변환

IK 릭 두 개를 짝지어 실제 변환을 하는 에셋이 **IK 리타기터**입니다.

1. 콘텐츠 브라우저를 우클릭해 **애니메이션 → 리타기팅 → IK 리타기터**를 누른다.
2. 이름을 `RTG_PaladinToMannequin`으로 짓고 연다.
3. 디테일 패널에서 **소스 IK 릭 에셋**에 `IK_Paladin`을, **타깃 IK 릭 에셋**에 `IK_Mannequin`을 지정한다.
4. 아래 **체인 매핑** 탭에서 타깃 체인마다 짝이 되는 소스 체인이 지정됐는지 확인한다. 이름이 같으면 자동으로 짝지어진다. 비어 있으면 드롭다운에서 고른다.
5. **애셋 브라우저** 탭에서 팔라딘의 동작을 더블클릭해 미리보기에서 마네킹이 같은 동작을 하는지 확인한다.
6. 변환할 동작을 선택하고 **선택된 애니메이션 익스포트**를 누른 뒤 저장할 폴더를 고른다.

![IK 리타기터 에디터: 팔라딘(소스)과 마네킹(타깃)이 나란히 같은 동작을 하는 미리보기와 체인 매핑 목록](./img/19-ik-retargeter.png)

**소스**는 동작을 가지고 있는 쪽, **타깃**은 동작을 받을 쪽입니다. 익스포트하면 마네킹 스켈레톤용 애니메이션 시퀀스가 새로 만들어지고, `ABP_MyAnim`의 애셋 브라우저에도 보이게 됩니다.

소스와 타깃을 반대로 넣은 리타기터를 하나 더 만들면 마네킹의 달리기 동작을 팔라딘에게 시킬 수도 있습니다.

### 19-7 리타기팅의 한계

리타기팅 결과가 원본과 완전히 같지는 않습니다. 두 캐릭터의 팔 길이, 어깨 폭, 뼈의 기본 방향이 다르기 때문입니다. 흔히 보이는 문제는 손목이 꺾이거나 손이 몸을 파고드는 것입니다.

두 캐릭터의 기본 자세가 다르면 차이가 더 커집니다. 팔을 수평으로 벌린 자세와 팔을 비스듬히 내린 자세는 같은 회전값을 줘도 결과가 달라집니다. IK 리타기터의 **리타깃 포즈 편집** 기능으로 한쪽 캐릭터의 기본 자세를 다른 쪽과 비슷하게 맞추면 결과가 나아집니다.

작은 어긋남은 본 구조 차이에서 오는 것이라 완전히 없애기 어렵습니다. 중요한 동작은 변환한 뒤 애니메이션 에디터에서 직접 손봐야 합니다.

### 19-8 따라하기 — 공격 동작 가져오기

1. Mixamo에서 팔라딘 캐릭터와 검 공격 동작 네 개를 받는다.
2. 캐릭터를 임포트하고, 동작은 팔라딘 스켈레톤을 지정해 임포트한다.
3. `IK_Paladin`을 만들고 리타깃 루트와 여섯 개 체인을 설정한다.
4. `RTG_PaladinToMannequin`을 만들고 미리보기에서 동작을 확인한다.
5. 공격 동작 네 개를 마네킹용으로 익스포트한다.
6. `ABP_MyAnim`의 애님 그래프에 익스포트한 동작 하나를 임시로 연결해 마네킹이 재생하는지 확인한 뒤 되돌린다.

익스포트한 공격 동작 네 개는 Chapter 20에서 콤보 공격을 만드는 데 씁니다.

### 연습문제

1. 문제: 동작 FBX를 임포트할 때 스켈레톤 칸에 캐릭터의 스켈레톤을 지정해야 하는 이유를 한 문장으로 쓰세요.
2. 문제: Mixamo 캐릭터의 IK 릭에서 `Hips`를 리타깃 루트로 설정해야 하는 이유를 한 문장으로 쓰세요.  
   - 조건: 마네킹의 `root` 뼈와 비교할 것
3. 문제: 팔라딘의 동작을 마네킹에게 시키려면 IK 리타기터의 소스와 타깃에 각각 어떤 IK 릭을 넣어야 하는지 쓰세요.

### 정답 포인트

- 지정하지 않으면 동작마다 스켈레톤이 새로 생겨 캐릭터와 연결되지 않는다. Mixamo는 `root` 없이 `Hips`부터 시작하므로 기준 뼈를 알려 줘야 한다. 소스는 `IK_Paladin`, 타깃은 `IK_Mannequin`.
