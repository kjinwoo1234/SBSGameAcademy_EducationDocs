# Chapter 08 머티리얼 — 선형 보간

## 학습 목표

- 선형 보간이 무엇을 계산하는지 숫자 예로 설명할 수 있다.
- Lerp 노드로 값의 범위를 바꾸고 움직임을 만들 수 있다.
- 마스크와 Lerp로 도형에 색을 입히고 겹쳐 그릴 수 있다.
- Lerp로 두 장면을 전환하는 머티리얼을 만들 수 있다.

## 본문

### 08-1 선형 보간

`100`과 `200` 사이의 딱 중간 값은 `150`입니다. 30% 지점의 값은 `130`입니다. 이렇게 두 값 사이의 중간 값을 비율로 구하는 일을 **보간**이라고 하고, 비율이 늘어나는 만큼 값도 일정하게 늘어나도록 구하는 방법을 **선형 보간**이라고 합니다. 그래프로 그리면 직선이 되어서 선형이라는 이름이 붙었습니다.

계산식은 다음과 같습니다. A가 시작 값, B가 끝 값, Alpha가 `0`에서 `1` 사이의 비율입니다.

```text
결과 = A + (B - A) × Alpha
```

| Alpha | A=100, B=200일 때 결과 |
|---|---|
| `0` | `100` |
| `0.3` | `130` |
| `0.5` | `150` |
| `1` | `200` |

머티리얼에서는 **`Lerp`** 노드가 이 계산을 합니다. `L`을 누른 채 클릭하면 만들어지고, 입력 핀은 A, B, Alpha 세 개입니다.

### 08-2 범위 바꾸기

그레이디언트는 `0`에서 `1`까지 변합니다. 이 범위를 `0.3`에서 `0.6`처럼 다른 범위로 옮기고 싶을 때 `Lerp`를 씁니다.

1. `Lerp`의 A에 `0.3`, B에 `0.6`을 넣는다.
2. Alpha에 가로 그레이디언트를 연결한다.
3. 최종 색에 연결한다.

왼쪽 끝이 어두운 회색, 오른쪽 끝이 밝은 회색인 좁은 범위의 그레이디언트가 됩니다. A와 B에 `5`와 `10`처럼 `1`보다 큰 값을 넣으면 범위를 넓힐 수도 있습니다.

### 08-3 움직임 만들기

Alpha에 그레이디언트 대신 시간의 흐름을 넣으면 값이 A에서 B로 움직입니다.

Chapter 07에서 그린 얼굴의 입을 움직여 봅니다.

1. `Lerp`의 A에 `0.03`, B에 `0.15`를 넣는다.
2. Alpha에 `MF_TimeFlow`의 `PingPong`을 연결한다.
3. `Append` 노드의 A에 `0.4`를, B에 `Lerp` 결과를 연결해 2차원 벡터를 만든다.
4. 입을 그리는 `MF_Rectangle`의 `Size`에 연결한다.

입의 세로 크기가 `0.03`과 `0.15` 사이를 오가며 벌어졌다 닫힙니다. 시작 값과 끝 값만 정해 주면 중간 값은 `Lerp`가 채워 줍니다.

### 08-4 색 그레이디언트

`Lerp`의 A와 B에는 스칼라뿐 아니라 벡터도 넣을 수 있습니다. 벡터를 넣으면 빨강, 초록, 파랑을 각각 따로 보간한 뒤 다시 묶어 줍니다.

1. `3` + 클릭으로 색 노드 두 개를 만들어 A와 B에 연결한다.
2. Alpha에 가로 그레이디언트를 연결한다.

A 색에서 B 색으로 서서히 변하는 색 그레이디언트가 만들어집니다. 한 색에서 다른 색으로 자연스럽게 섞는 이런 표현을 **블렌딩**이라고 합니다.

무지개처럼 여러 색을 지나가게 하려면 Chapter 05의 HSV 모델을 씁니다.

1. `Append`의 A에 가로 그레이디언트를, B에 2차원 벡터 `(1, 1)`을 연결한다. H가 위치에 따라 변하고 S와 V는 `1`인 HSV 값이 된다.
2. `HSVToRGB`에 연결하고 최종 색에 연결한다.

화면 왼쪽에서 오른쪽으로 색상환 한 바퀴의 색이 펼쳐집니다. H에 `MF_TimeFlow`의 `Loop`를 더하고 `Frac`을 거치면 무지개가 옆으로 흐릅니다.

### 08-5 마스크에 색 입히기

Chapter 07의 마스크는 도형이 검정 `0`, 바깥이 흰색 `1`이었습니다. 이 마스크를 `Lerp`의 Alpha에 넣으면 도형 안과 밖에 원하는 색을 정할 수 있습니다.

| Lerp 핀 | 넣는 것 | 보이는 곳 |
|---|---|---|
| A | 도형 색 | 마스크가 `0`인 도형 안쪽 |
| B | 배경 색 | 마스크가 `1`인 바깥쪽 |
| Alpha | 도형 마스크 | |

Alpha가 `0`이면 A가, `1`이면 B가 그대로 나오기 때문입니다.

### 08-6 가산 합성과 오버레이 합성

색을 입힌 도형 여러 개를 한 화면에 그리는 방법은 두 가지입니다.

먼저 원 세 개를 조금씩 겹치게 놓습니다. 각 원의 마스크를 `1-x`로 뒤집으면 원 안쪽이 `1`, 바깥이 `0`이 됩니다. 여기에 빨강, 초록, 파랑을 각각 `Multiply`로 곱하면 검은 배경 위에 색칠된 원이 됩니다. 세 결과에 `RCircle`, `GCircle`, `BCircle`이라는 명명된 경유 노드를 붙입니다.

**가산 합성**은 세 결과를 `Add`로 모두 더하는 방법입니다. 겹친 곳은 색이 더해져 밝아지고, 세 원이 모두 겹친 가운데는 흰색이 됩니다. 더한 결과가 `1`을 넘을 수 있으므로 마지막에 `Saturate` 노드를 붙입니다. **`Saturate`**는 값을 `0`에서 `1` 범위 안에 가두는 노드입니다.

**오버레이 합성**은 뒤에 있는 것 위에 앞에 있는 것을 덮어 그리는 방법입니다. `Lerp`를 차례로 이어 붙입니다.

1. 첫 번째 `Lerp`의 A에 원 색을, B에 배경 색을, Alpha에 가장 뒤에 놓을 원의 마스크를 넣는다.
2. 두 번째 `Lerp`의 A에 다음 원의 색을, B에 첫 번째 `Lerp` 결과를, Alpha에 그 원의 마스크를 넣는다.
3. 세 번째 `Lerp`도 같은 방법으로 잇는다.

나중에 연결한 원이 앞의 결과를 덮어서, 겹친 곳에서 색이 섞이지 않고 앞의 원만 보입니다.

![원 세 개의 가산 합성 결과와 오버레이 합성 결과를 나란히 비교한 미리보기](./img/08-additive-vs-overlay.png)

| 합성 | 노드 | 겹친 곳 |
|---|---|---|
| 가산 | `Add` 다음 `Saturate` | 색이 더해져 밝아진다 |
| 오버레이 | `Lerp`를 순서대로 연결 | 나중에 그린 것이 덮는다 |

오버레이 합성으로 배경이 흘러가는 장면을 만들 수 있습니다. 세로 방향의 어두운 색 그레이디언트를 배경으로 두고, 크기와 속도가 다른 원 세 개의 `Center`를 `Lerp`와 `MF_TimeFlow`로 움직이면 멀리 있는 것은 천천히, 가까이 있는 것은 빠르게 지나가는 장면이 됩니다.

### 08-7 장면 전환

화면 한 장도 결국 점마다의 색 값입니다. 두 장면을 `Lerp`의 A와 B에 넣고 Alpha를 바꾸면 한 장면에서 다른 장면으로 넘어갑니다.

Chapter 07의 얼굴과 체크 패턴 머티리얼을 `SceneA`로 두고, 체크 패턴만 `1-x`로 뒤집어 반대쪽 칸에 얼굴이 나오게 한 것을 `SceneB`로 둡니다.

| Alpha에 넣는 것 | 전환 방식 |
|---|---|
| `MF_TimeFlow`의 `Switch` | 두 장면이 번갈아 뚝뚝 바뀐다 |
| `MF_TimeFlow`의 `PingPong` | 두 장면이 서서히 겹치며 바뀐다 |
| `Step`으로 만든 움직이는 경계 마스크 | 화면을 옆으로 밀듯이 바뀐다 |

세 번째 방법은 Chapter 07의 첫 실습에서 만든 움직이는 경계를 그대로 Alpha에 연결하면 됩니다.

### 08-8 더 공부할 주제

이 과정의 머티리얼 기초는 여기까지입니다. 수를 색으로 보고, `0`에서 `1`의 흐름을 조절해 마스크를 만들고, `Lerp`로 색을 입혀 마무리하는 흐름을 익혔습니다. 관심이 있다면 아래 순서로 이어서 공부하기를 권합니다.

| 주제 | 내용 |
|---|---|
| 비선형 보간 | 처음엔 천천히, 나중엔 빠르게처럼 속도가 변하는 보간. `SmoothStep` 노드 |
| 삼각함수 | `Sine`, `Cosine` 노드로 만드는 부드러운 왕복과 회전 |
| UV 트랜스폼 | 좌표 자체를 이동·회전·확대해 무늬를 움직이기 |
| 텍스처 | 그림 파일을 머티리얼에서 읽어 쓰기 |

### 08-9 따라하기 — 색이 있는 장면 만들기

1. `Lerp`로 `0.3`에서 `0.6` 범위의 그레이디언트를 만든다.
2. 얼굴 머티리얼의 입이 벌어졌다 닫히게 만든다.
3. 두 색 그레이디언트와 무지개 그레이디언트를 만든다.
4. 색을 입힌 원 세 개를 가산 합성과 오버레이 합성으로 각각 만들어 비교한다.
5. `SceneA`와 `SceneB`를 `Switch`, `PingPong`, 움직이는 경계 마스크로 각각 전환해 본다.
6. 완성한 머티리얼 하나를 머티리얼 도메인 `Surface`로 되돌리고 최종 색 대신 **이미시브 컬러**에 연결해, 레벨의 큐브에 적용한다.

이미시브 컬러는 물체가 스스로 내는 빛의 색입니다. 여기에 연결하면 레벨의 조명과 관계없이 머티리얼에서 계산한 색이 그대로 보입니다.

### 연습문제

1. 문제: `Lerp`의 A가 `10`, B가 `50`, Alpha가 `0.25`일 때 결과를 계산하세요.  
   - 조건: 08-1의 계산식에 숫자를 넣은 과정을 쓸 것
2. 문제: 마스크에 색을 입힐 때 도형 색을 A에, 배경 색을 B에 넣는 이유를 한 문장으로 쓰세요.  
   - 조건: 도형 안쪽의 마스크 값을 언급할 것
3. 문제: 가산 합성과 오버레이 합성에서 두 원이 겹친 곳이 각각 어떻게 보이는지 한 줄씩 쓰세요.

### 정답 포인트

- `10 + (50 - 10) × 0.25 = 20`. 도형 안쪽 마스크가 `0`이라 A가 그대로 나오기 때문. 가산은 색이 더해져 밝아지고, 오버레이는 나중에 그린 원이 덮는다.
