# Chapter 12 블루프린트 인터랙션 기초

## 학습 목표

- 블루프린트 변수를 만들고 인스턴스마다 다른 값을 줄 수 있다.
- 박스 콜리전의 오버랩 이벤트로 다른 액터가 들어오고 나가는 것을 감지할 수 있다.
- 캐스트 노드로 감지한 액터가 원하는 종류인지 확인할 수 있다.
- 키보드 입력 이벤트로 액터를 동작시킬 수 있다.

## 본문

### 12-1 변수로 움직이는 액터

게임은 플레이어와 세상이 서로 반응하면서 진행됩니다. 문 앞에 서면 문이 열리고, 버튼을 누르면 불이 켜집니다. 이런 주고받는 반응을 **인터랙션**이라고 합니다. 이 장에서는 무언가가 다가오면 반응하는 액터를 만듭니다.

먼저 반응을 일으킬 상대, 한쪽 방향으로 계속 움직이는 공을 만듭니다.

1. 액터를 부모로 블루프린트 클래스 `BP_Patrol`을 만든다.
2. 컴포넌트 탭에서 **추가 → 구체**를 붙인다.

움직이는 방향과 속도를 숫자로 직접 적어 넣으면 공마다 다른 방향을 줄 수 없습니다. 값에 이름을 붙여 보관해 두고 필요할 때 꺼내 쓰는 상자를 **변수**라고 합니다.

3. 블루프린트 에디터 왼쪽 아래 **내 블루프린트** 탭에서 **변수** 옆 `+`를 누른다.
4. 이름을 `MoveDirection`으로 짓는다.
5. 디테일 패널에서 **변수 타입**을 **벡터**로 바꾼다.
6. 같은 패널에서 **인스턴스 편집가능**에 체크한다.

변수 타입은 상자에 담을 값의 종류입니다. 벡터는 Chapter 05에서 배운 대로 수 세 개의 묶음이고, 여기서는 X, Y, Z 방향의 속도를 담습니다.

![내 블루프린트 탭에 MoveDirection 변수가 추가되고 디테일 패널에서 벡터 타입과 인스턴스 편집가능이 설정된 화면](./img/12-variable-move-direction.png)

이제 변수 값만큼 매 프레임 이동시킵니다.

7. 변수 `MoveDirection`을 그래프로 끌어다 놓고 **Get MoveDirection**을 고른다.
8. `Event Tick`의 `Delta Seconds`와 `MoveDirection`을 곱하기 노드로 곱한다.
9. `Event Tick`의 실행 핀에 `Add Actor World Offset`을 연결한다.
10. 곱한 결과를 **Delta Location**에 연결한다.
11. 컴파일한다.

`BP_Patrol`을 레벨에 놓고 선택하면 디테일 패널에 **Move Direction** 칸이 보입니다. 인스턴스 편집가능에 체크한 변수는 레벨에 놓인 인스턴스마다 값을 따로 정할 수 있습니다. X에 `100`을 넣고 플레이하면 공이 1초에 100만큼 X 방향으로 움직입니다.

### 12-2 오버랩 감지

다음은 공이 다가오면 반응할 액터입니다. 무언가가 특정 공간에 들어왔는지 알려면 그 공간을 나타내는 부품이 필요합니다.

**박스 콜리전**은 눈에 보이지 않는 상자 모양의 감지 영역 컴포넌트입니다. 다른 액터가 이 상자와 겹치는 것을 **오버랩**이라고 합니다.

1. 액터를 부모로 블루프린트 클래스 `BP_AutoLight`를 만든다.
2. 컴포넌트 탭에서 **추가 → 박스 콜리전**을 붙인다.
3. 박스 콜리전을 선택하고 디테일 패널의 **박스 크기**를 `100, 100, 100`으로 한다.
4. 디테일 패널 맨 아래 **이벤트** 항목에서 **컴포넌트 오버랩 시작 시** 옆 `+`를 누른다.

이벤트 그래프에 **On Component Begin Overlap** 이벤트 노드가 생깁니다. 다른 액터가 상자 안으로 들어오는 순간 한 번 실행됩니다. 이 노드의 **Other Actor** 핀으로 들어온 액터가 누구인지 전달됩니다.

### 12-3 불 켜기

감지했을 때 켤 빛을 붙입니다.

1. `BP_AutoLight`에 **포인트 라이트** 컴포넌트를 추가한다.
2. 라이트 컬러를 눈에 띄는 색으로 바꾼다.
3. 디테일 패널의 **렌더링 → 표시**의 체크를 해제한다. 처음에는 꺼진 상태가 된다.

상자에는 공 말고도 다른 액터가 들어올 수 있습니다. 들어온 액터가 `BP_Patrol`일 때만 불을 켜야 합니다. 어떤 액터가 특정 클래스인지 확인하면서 그 클래스로 바꿔 다루게 해 주는 노드를 **캐스트**라고 합니다.

4. `On Component Begin Overlap`의 `Other Actor` 핀을 드래그해 `Cast To BP_Patrol` 노드를 만든다.
5. 이벤트의 실행 핀을 캐스트 노드의 실행 입력에 연결한다.
6. 컴포넌트 탭에서 포인트 라이트를 그래프로 끌어다 놓는다.
7. 포인트 라이트 핀을 드래그해 `Set Visibility` 노드를 만들고 **New Visibility**에 체크한다.
8. 캐스트 노드의 위쪽 실행 출력 핀을 `Set Visibility`에 연결한다.
9. 컴파일한다.

![BP_AutoLight 이벤트 그래프: On Component Begin Overlap → Cast To BP_Patrol → 포인트 라이트의 Set Visibility](./img/12-overlap-cast-light-on.png)

캐스트 노드에는 실행 출력 핀이 두 개 있습니다. 위쪽은 변환에 성공했을 때, 아래쪽 **Cast Failed**는 실패했을 때 실행됩니다. 들어온 액터가 `BP_Patrol`이 아니면 아래쪽으로 빠져 불이 켜지지 않습니다.

`BP_AutoLight`를 공이 지나갈 길에 놓고 플레이합니다. 주변이 밝으면 불이 잘 보이지 않으므로 Chapter 10에서 배운 대로 디렉셔널 라이트의 강도를 낮춰 어둡게 만듭니다.

### 12-4 불 끄기

공이 상자를 빠져나가면 불을 꺼야 합니다.

1. 박스 콜리전을 선택하고 **이벤트** 항목에서 **컴포넌트 오버랩 종료 시** 옆 `+`를 누른다.
2. 생긴 **On Component End Overlap** 이벤트에 12-3과 같은 캐스트 노드를 연결한다.
3. `Set Visibility` 노드를 하나 더 만들고 **New Visibility**의 체크를 해제한 채 연결한다.

**On Component End Overlap**은 겹쳐 있던 액터가 상자 밖으로 나가는 순간 한 번 실행됩니다. 공이 지나가는 동안만 불이 켜졌다가 꺼집니다.

### 12-5 키보드 입력 받기

이번에는 플레이어가 누른 키에 반응하게 합니다. 가장 간단한 방법은 키보드 이벤트 노드입니다.

이벤트 그래프를 우클릭해 `Space Bar`를 검색하면 **스페이스 바** 이벤트 노드가 나옵니다. 실행 출력 핀이 두 개입니다.

| 핀 | 실행되는 때 |
|---|---|
| Pressed | 키를 누르는 순간 한 번 |
| Released | 키에서 손을 떼는 순간 한 번 |

일반 액터는 처음에는 키 입력을 받지 않습니다. 입력을 받겠다고 설정해야 합니다.

1. 블루프린트 에디터 위쪽 **클래스 디폴트**를 누른다.
2. 디테일 패널의 **입력 → 입력 자동 수신**을 `Player 0`으로 바꾼다.

`Player 0`은 첫 번째 플레이어를 뜻합니다. 이 설정을 빼먹으면 키 이벤트 노드를 연결해도 아무 일도 일어나지 않습니다.

`BP_AutoLight`에서 스페이스 바의 `Pressed`를 불 켜는 `Set Visibility`에, `Released`를 불 끄는 `Set Visibility`에 연결하면 누르고 있는 동안만 불이 켜집니다.

이 방법은 연습용으로 간단하지만 키가 블루프린트에 고정되어 버립니다. 조작 키를 바꿀 수 있게 만드는 제대로 된 입력 방식은 Chapter 17에서 다룹니다.

### 12-6 따라하기 — 자동문과 조종하는 공

1. `BP_Patrol`을 만들고 레벨에 두 개 놓아 서로 다른 `Move Direction`을 준다.
2. `BP_AutoLight`를 만들어 공이 지나갈 때만 불이 켜지게 한다.
3. 자동문 `BP_AutoDoor`를 만든다. 큐브 컴포넌트를 문으로 쓰고, 박스 콜리전에 공이 들어오면 문 컴포넌트를 `Set Relative Location` 노드로 위로 `200`만큼 옮긴다. 공이 나가면 원래 위치로 되돌린다.
4. `BP_Patrol`의 클래스 디폴트에서 입력 자동 수신을 `Player 0`으로 바꾼다.
5. `W`, `A`, `S`, `D` 키 이벤트의 `Pressed`에서 `Set MoveDirection` 노드로 변수 값을 바꿔 공을 조종한다.
6. 스페이스 바를 누르면 `MoveDirection`을 `0, 0, 0`으로 바꿔 공이 멈추게 한다.

3번의 **Set Relative Location**은 컴포넌트의 위치를 액터 기준으로 정하는 노드입니다. 5번의 **Set MoveDirection**은 변수를 그래프로 끌어다 놓을 때 **Set**을 고르면 만들어지며, 변수에 새 값을 넣습니다.

이 장으로 Part 01을 마칩니다. Part 02부터는 같은 일을 C++ 코드로 만들고 블루프린트와 함께 쓰는 방법을 배웁니다.

### 연습문제

1. 문제: 변수의 인스턴스 편집가능 옵션을 켜면 무엇을 할 수 있게 되는지 한 문장으로 쓰세요.  
   - 조건: 디테일 패널을 언급할 것
2. 문제: 오버랩 이벤트에서 캐스트 노드를 쓰지 않고 바로 불을 켜면 생기는 문제를 한 문장으로 쓰세요.
3. 문제: 액터 블루프린트에 스페이스 바 이벤트를 연결했는데 반응이 없을 때 확인할 설정과 바꿀 값을 쓰세요.

### 정답 포인트

- 레벨에 놓인 인스턴스마다 디테일 패널에서 값을 따로 줄 수 있다. 공이 아닌 다른 액터가 들어와도 불이 켜진다. 클래스 디폴트의 입력 자동 수신을 `Player 0`으로.
