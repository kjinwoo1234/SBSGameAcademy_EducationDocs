# Chapter 04 머티리얼 첫걸음과 랜드스케이프 페인트

## 학습 목표

- 머티리얼이 무엇인지 설명하고 단색 머티리얼을 만들어 액터에 적용할 수 있다.
- 받아 온 표면 머티리얼을 랜드스케이프 전체에 입힐 수 있다.
- 레이어 블렌드 머티리얼을 만들어 지형에 풀과 아스팔트를 나눠 칠할 수 있다.

## 본문

### 04-1 머티리얼이란

Chapter 02에서 벽의 머티리얼을 바꿔 벽돌 벽으로 만들었습니다. 모형의 모양은 그대로인데 겉모습만 달라졌습니다.

**머티리얼**은 물체 겉면이 어떤 색이고, 얼마나 반짝이고, 얼마나 거친지를 정하는 에셋입니다. 스태틱 메시가 조각상의 형태라면 머티리얼은 그 위에 칠하는 물감과 광택입니다.

직접 확인해 봅니다.

1. 레벨에 큐브를 하나 놓는다.
2. 디테일 패널의 **머티리얼** 항목에서 `엘리먼트 0` 값을 다른 머티리얼로 바꾼다.
3. 큐브의 색과 질감이 바뀌는 것을 본다.

### 04-2 단색 머티리얼 만들기

이제 머티리얼을 직접 만듭니다.

1. 콘텐츠 브라우저에 `Material` 폴더를 만든다.
2. 폴더 안에서 우클릭하고 **머티리얼**을 누른다. 이름은 `M_MyMaterial`로 한다.
3. 만든 파일을 더블클릭한다. **머티리얼 에디터**가 열린다.

![머티리얼 에디터 화면: 왼쪽 미리보기, 가운데 그래프의 결과 노드, 아래 디테일 패널](./img/04-material-editor-layout.png)

가운데 그래프에 처음부터 놓여 있는 큰 상자가 **결과 노드**입니다. 왼쪽에 **베이스 컬러**, **메탈릭**, **러프니스** 같은 입력 칸이 세로로 나열되어 있습니다. 이 칸에 무엇을 연결하느냐에 따라 머티리얼의 겉모습이 정해집니다.

값을 만드는 상자는 숫자 키를 누른 채 그래프를 클릭해서 만듭니다.

| 조작 | 만들어지는 노드 | 담는 값 |
|---|---|---|
| `1` + 클릭 | 상수 | 숫자 1개 |
| `2` + 클릭 | 상수 2 벡터 | 숫자 2개 |
| `3` + 클릭 | 상수 3 벡터 | 숫자 3개. 빨강·초록·파랑 색 |
| `4` + 클릭 | 상수 4 벡터 | 숫자 4개. 색과 투명도 |

색을 넣어 봅니다.

1. `3`을 누른 채 그래프의 빈 곳을 클릭한다.
2. 만들어진 노드를 더블클릭해 색 선택 창을 열고 분홍색을 고른다.
3. 노드 오른쪽 맨 위의 동그라미를 드래그해 결과 노드의 **베이스 컬러**에 놓는다.
4. 왼쪽 미리보기 공의 색이 바뀌는 것을 확인한다.
5. 위쪽 **적용**과 **저장**을 누른다.

**베이스 컬러**는 겉면의 기본 색입니다. `1` 키로 만든 상수 노드에 `0`에서 `1` 사이 값을 넣어 **메탈릭**이나 **러프니스**에 연결해 보세요. 메탈릭은 금속처럼 보이는 정도이고, 러프니스는 표면이 거친 정도입니다. 러프니스가 `0`에 가까우면 거울처럼 반짝입니다.

콘텐츠 브라우저에서 `M_MyMaterial`을 뷰포트의 큐브 위로 끌어다 놓으면 적용됩니다. 숫자와 색이 겉모습으로 바뀌는 원리는 Chapter 05에서 자세히 배웁니다.

### 04-3 표면 머티리얼 받아 오기

풀이나 아스팔트처럼 사실적인 겉면은 사진을 바탕으로 만든 그림 파일이 필요합니다. 직접 만들기 어렵기 때문에 Chapter 02에서 쓴 Fab에서 무료 표면 에셋을 받아 옵니다.

1. 에디터의 Fab 창에서 무료 표면 에셋 중 잔디 하나와 아스팔트 하나를 찾는다.
2. 각각 프로젝트에 추가한다.
3. 콘텐츠 브라우저에 머티리얼 하나와 텍스처 여러 장이 들어왔는지 확인한다.

받은 텍스처는 이름 끝 글자로 용도를 구분합니다.

| 이름 끝 | 담긴 정보 |
|---|---|
| `_B` 또는 `_BaseColor` | 겉면의 색 |
| `_N` 또는 `_Normal` | 겉면의 올록볼록한 정도 |
| `_ORM` | 그늘진 정도, 거친 정도, 금속 정도를 한 장에 모은 것 |

엔진 버전에 따라 Fab 창 대신 **퀵셀 브리지**라는 창에서 받도록 되어 있을 수 있습니다. 받는 위치만 다르고 결과물은 같습니다.

### 04-4 랜드스케이프 전체에 입히기

받아 온 머티리얼을 지형에 입혀 봅니다.

1. 아웃라이너에서 Chapter 03에서 만든 랜드스케이프를 선택한다.
2. 디테일 패널의 **랜드스케이프 머티리얼** 칸에 잔디 머티리얼을 지정한다.

지형 전체가 잔디로 바뀝니다. 그런데 이 방법으로는 한쪽은 풀, 다른 쪽은 아스팔트처럼 나눠 칠할 수 없습니다. 머티리얼 하나 안에 여러 겉면을 넣고 붓으로 골라 칠할 수 있게 만들어야 합니다.

### 04-5 레이어 블렌드 머티리얼 만들기

여러 겉면을 한 머티리얼에 섞어 넣는 일을 **블렌딩**이라고 합니다. 포토샵에서 레이어를 켜고 끄는 것처럼, 지형의 위치마다 어느 겉면을 보여 줄지 고를 수 있는 머티리얼을 만듭니다.

이 소절은 원리를 이해하기보다 순서대로 따라 해서 결과를 얻는 것이 목표입니다.

1. 새 머티리얼 `M_MyLandscape`를 만들고 연다.
2. 콘텐츠 브라우저에서 잔디의 텍스처 세 장을 그래프로 끌어다 놓는다. **텍스처 샘플** 노드 세 개가 생긴다.
3. 그래프를 우클릭해 `MakeMaterialAttributes` 노드를 만든다.
4. 텍스처 샘플의 출력을 아래 표대로 연결한다.

| 텍스처 | 출력 핀 | MakeMaterialAttributes 입력 |
|---|---|---|
| `_B` | RGB | BaseColor |
| `_N` | RGB | Normal |
| `_ORM` | R | AmbientOcclusion |
| `_ORM` | G | Roughness |
| `_ORM` | B | Metallic |

다음으로 무늬가 얼마나 촘촘하게 반복될지 조절하는 값을 만듭니다.

5. 우클릭해 `TextureCoordinate` 노드를 만든다.
6. `1`을 누른 채 클릭해 상수 노드를 만들고, 우클릭해서 **파라미터로 변환**을 누른다. 이름을 `Tiling`으로 바꾸고 기본값을 `1`로 둔다.
7. `Multiply` 노드를 만들어 `TextureCoordinate`와 `Tiling`을 연결한다.
8. `Multiply`의 출력을 텍스처 샘플 세 개의 **UVs** 입력에 모두 연결한다.
9. 텍스처 샘플 세 개를 선택하고 디테일 패널의 **샘플러 소스**를 `Shared: Wrap`으로 바꾼다.

**파라미터**는 머티리얼을 다시 열지 않고도 밖에서 값을 바꿀 수 있게 열어 둔 숫자입니다. 샘플러 소스를 바꾸는 이유는 머티리얼 하나가 쓸 수 있는 텍스처 수에 제한이 있기 때문이며, 이 설정이 제한에 걸리지 않게 해 줍니다.

![M_MyLandscape 그래프: TextureCoordinate·Tiling·Multiply가 텍스처 샘플 세 개의 UVs에 연결되고 MakeMaterialAttributes로 모이는 묶음](./img/04-landscape-material-layer-group.png)

같은 묶음을 아스팔트용으로 하나 더 만듭니다.

10. 지금까지 만든 노드를 전부 드래그로 선택해 `Ctrl + C`, `Ctrl + V`로 아래에 복사한다.
11. 복사된 텍스처 샘플 세 개의 텍스처를 아스팔트의 `_B`, `_N`, `_ORM`으로 바꾼다.

마지막으로 두 묶음을 레이어로 합칩니다.

12. 우클릭해 `LandscapeLayerBlend` 노드를 만든다.
13. 디테일 패널의 **레이어** 배열에서 `+`를 두 번 눌러 항목을 두 개 만든다.
14. 레이어 이름을 위에서부터 `Grass`, `Asphalt`로 적는다.
15. 잔디 묶음의 `MakeMaterialAttributes` 출력을 `Layer Grass`에, 아스팔트 묶음의 출력을 `Layer Asphalt`에 연결한다.
16. 결과 노드를 선택하고 디테일 패널에서 **머티리얼 어트리뷰트 사용**에 체크한다. 결과 노드의 입력이 하나로 줄어든다.
17. `LandscapeLayerBlend`의 출력을 결과 노드에 연결하고 **적용**, **저장**을 누른다.

### 04-6 랜드스케이프 페인트

머티리얼 원본을 직접 지형에 쓰지 않고, 값만 바꿀 수 있는 복사본을 만들어 씁니다. 이 복사본을 **머티리얼 인스턴스**라고 합니다. 원본을 다시 계산하지 않고도 파라미터 값을 바로 바꿔 볼 수 있습니다.

1. 콘텐츠 브라우저에서 `M_MyLandscape`를 우클릭하고 **머티리얼 인스턴스 생성**을 누른다. 이름은 `MI_MyLandscape`로 한다.
2. 랜드스케이프를 선택하고 **랜드스케이프 머티리얼**에 `MI_MyLandscape`를 지정한다. 지형이 까맣게 보이면 정상이다. 아직 어떤 레이어도 칠하지 않았기 때문이다.
3. 랜드스케이프 모드의 **페인트** 탭을 연다.
4. **레이어** 목록의 `Grass` 오른쪽 `+`를 누르고 **웨이트 블렌딩된 레이어(노멀)**를 고른다.
5. 저장 창이 뜨면 `Landscape` 폴더를 만들어 그 안에 저장한다.
6. `Asphalt`도 같은 방법으로 만든다.

![랜드스케이프 페인트 탭의 레이어 목록에서 Grass·Asphalt 레이어를 만들고 지형 일부를 칠한 화면](./img/04-landscape-paint-layers.png)

이제 칠할 준비가 끝났습니다. 레이어 목록에서 `Grass`를 고르고 지형을 문지르면 풀이 칠해지고, `Asphalt`를 고르고 문지르면 아스팔트가 칠해집니다. 브러시 크기와 감쇠는 Chapter 03의 스컬프트와 같은 방식으로 조절합니다.

칠한 곳이 한 가지 색으로 뭉개져 보이면 무늬가 너무 촘촘하게 반복된 것입니다. `MI_MyLandscape`를 열어 `Tiling` 파라미터에 체크하고 값을 `0.1`처럼 작게 바꾸면 무늬가 커지면서 풀과 아스팔트의 결이 보입니다.

### 04-7 따라하기 — 지형 색칠하기

1. 분홍색 단색 머티리얼을 만들어 큐브에 적용한다.
2. 잔디와 아스팔트 표면 에셋을 받아 온다.
3. `M_MyLandscape`를 레이어 두 개로 만들고 머티리얼 인스턴스를 만든다.
4. 랜드스케이프에 인스턴스를 지정하고 레이어 인포 두 개를 만든다.
5. Chapter 03에서 만든 도로 주변은 아스팔트, 나머지는 풀로 칠한다.
6. `Tiling` 값을 바꿔 가며 가까이에서 무늬를 확인한다.
7. 세 번째 표면 에셋을 받아 레이어를 하나 더 추가해 본다.

### 연습문제

1. 문제: 머티리얼 결과 노드의 베이스 컬러, 메탈릭, 러프니스가 각각 무엇을 정하는지 한 줄씩 쓰세요.
2. 문제: 랜드스케이프 머티리얼 칸에 잔디 머티리얼만 지정했을 때 할 수 없는 일을 한 문장으로 쓰세요.  
   - 조건: "나눠 칠하기"라는 말을 포함할 것
3. 문제: 칠한 지형이 단색으로 뭉개져 보일 때 바꿀 값과 바꾸는 방향을 쓰세요.  
   - 조건: 파라미터 이름을 쓸 것

### 정답 포인트

- 베이스 컬러=기본 색, 메탈릭=금속 정도, 러프니스=거친 정도. 머티리얼 하나만 지정하면 위치별로 나눠 칠하기가 안 된다. `Tiling` 값을 작게.
