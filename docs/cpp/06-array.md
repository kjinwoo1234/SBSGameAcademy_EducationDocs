# Chapter 06 배열과 벡터

## 학습 목표

- 고정 크기 배열을 선언·초기화하고, **0부터** 인덱스로 접근할 수 있다.
- `vector`에 원소를 넣고 `push_back`으로 크기를 늘릴 수 있다.
- 일반 `for`와 범위 기반 `for`로 배열·벡터를 순회할 수 있다.

## 본문

### 06-1 고정 크기 배열

**배열**은 같은 타입 값을 **연속된 칸**에 모아 두는 자료 구조입니다. 크기를 정해 만들 때는 `int scores[5];`처럼 씁니다. 처음부터 값을 넣으려면 `int scores[4] = {80, 95, 70, 100};`처럼 **초기화 목록**을 쓸 수 있습니다.

**인덱스**는 각 칸의 위치 번호이며 **0부터** 시작합니다. 칸이 4개면 유효 인덱스는 `0`부터 `3`까지입니다. 마지막 칸은 `scores[3]` 또는 `scores[크기 - 1]`입니다. 범위를 벗어나면 잘못된 메모리를 건드릴 수 있으므로, **0 이상 · 크기 미만**만 접근합니다.

| 용어 | 의미 |
|---|---|
| 인덱스 | 배열에서 각 원소의 위치 번호. 0부터 시작 |
| 고정 크기 | 선언 때 정한 칸 수를 실행 중 바꿀 수 없음 |

아래를 실행해 첫 칸과 마지막 칸을 확인해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int scores[4] = {80, 95, 70, 100};

    cout << scores[0] << endl;
    cout << scores[3] << endl;
    return 0;
}
```

**예상 출력**

```text
80
100
```

**코드 해석**

- 초기화 목록으로 칸 4개를 만듭니다.
- `scores[0]`은 첫 값, `scores[3]`은 마지막 값입니다.
- `scores[4]`는 범위 밖이라 쓰지 않습니다.

### 06-2 `for`로 순회하기

배열의 모든 칸을 살펴보는 것을 **순회**라고 합니다. 인덱스가 필요할 때는 앞 장에서 배운 **`for`**가 맞습니다. 형태는 `for (int i = 0; i < 크기; i++)`입니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int scores[4] = {80, 95, 70, 100};

    for (int i = 0; i < 4; i++)
    {
        cout << i << ": " << scores[i] << endl;
    }
    return 0;
}
```

**예상 출력**

```text
0: 80
1: 95
2: 70
3: 100
```

**코드 해석**

- `i`는 `0`부터 `4` 직전까지입니다.
- `scores[i]`로 인덱스와 값을 함께 다룹니다.

### 06-3 `vector` 기초

**`vector`**는 실행 중 크기를 늘리거나 줄일 수 있는 **컨테이너**입니다. 컨테이너는 여러 데이터를 저장·관리하는 자료구조 객체입니다. `vector`를 쓰려면 `#include <vector>`가 필요합니다.

`vector<int> v = {1, 2, 3};`처럼 만들고, **`push_back(값)`**으로 뒤에 원소를 추가합니다. 크기가 바뀌는 목록에 잘 맞습니다. 칸 수가 처음부터 고정이면 배열, 실행 중 늘어나면 `vector`를 고르는 편이 읽기 쉽습니다.

| 항목 | 배열 | `vector` |
|---|---|---|
| 크기 변경 | 불가 | 가능 |
| 헤더 | 기본 문법 | `<vector>` |
| 권장 | 크기가 고정된 데이터 | 크기가 바뀌는 데이터 |

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {1, 2, 3};
    v.push_back(4);

    cout << "크기: " << v.size() << endl;
    cout << "마지막: " << v[v.size() - 1] << endl;
    return 0;
}
```

**예상 출력**

```text
크기: 4
마지막: 4
```

**코드 해석**

- 처음 세 칸을 만든 뒤 `push_back(4)`로 네 번째를 추가합니다.
- `v.size()`는 현재 원소 개수입니다.

### 06-4 범위 기반 `for`

**범위 기반 for**는 `for (int x : v)` 형태로 원소를 **값만** 순서대로 꺼낼 때 문장이 짧습니다. 인덱스가 필요 없으면 이 형태가 읽기 쉽습니다. 원본 칸을 직접 바꾸려면 `for (int& x : v)`처럼 **참조**를 씁니다. 참조 세부는 **함수·참조 장**에서 더 다룹니다. 지금은 “값을 읽기만 할 때” 기본형을 쓰면 됩니다.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    int arr[3] = {10, 20, 30};
    vector<int> v = {1, 2, 3};
    v.push_back(4);

    cout << "arr: ";
    for (int i = 0; i < 3; i++)
    {
        cout << arr[i] << ' ';
    }
    cout << endl;

    cout << "vector: ";
    for (int x : v)
    {
        cout << x << ' ';
    }
    cout << endl;
    return 0;
}
```

**예상 출력**

```text
arr: 10 20 30
vector: 1 2 3 4
```

**코드 해석**

- 배열은 인덱스가 드러나는 일반 `for`로 순회합니다.
- `vector`는 범위 기반 `for`로 값을 순서대로 출력합니다.

| 방식 | 적합한 상황 | 주의점 |
|---|---|---|
| 일반 `for` | 인덱스가 필요할 때 | `0`부터 `크기 - 1`까지 |
| 범위 기반 `for` | 값만 순서대로 읽을 때 | 인덱스·크기를 직접 안 봄 |

이 장 범위는 **고정 배열 · `vector` · 순회**입니다. 문자열은 **다음 장**에서 이어집니다.
