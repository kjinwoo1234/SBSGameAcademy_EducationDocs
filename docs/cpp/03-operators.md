# Chapter 03 연산자와 형 변환

## 학습 목표

- **산술·비교·논리 연산자**를 구분해 계산과 조건식에 쓸 수 있다.
- 정수 나눗셈과 실수 나눗셈 결과 차이를 설명할 수 있다.
- **형 변환**이 필요한 상황과 `static_cast`의 쓰임새를 이해한다.

## 본문

### 03-1 산술·비교·대입 연산자

**연산자**는 값과 값을 연결해 새 결과를 만드는 기호입니다. **산술 연산자**는 `+ - * / %`처럼 수치를 계산할 때, **비교 연산자**는 `== != > < >= <=`처럼 “같다/크다”를 물을 때 씁니다. 비교 결과는 `bool`이며, `cout`으로 찍으면 보통 `1`/`0`처럼 보입니다.

`/`는 **피연산자 타입**에 따라 결과가 달라집니다. `int`끼리 나누면 **소수점이 버려진 정수**가 나오고, 한쪽이라도 실수이면 실수 나눗셈이 됩니다. `%`는 나머지로, 짝수·홀수 판정에 자주 씁니다.

| 분류 | 연산자 | 용도 | 입문 예 |
|---|---|---|---|
| 산술 | `+ - * / %` | 계산 | `7 / 2`, `7 % 2` |
| 비교 | `== != > < >= <=` | 조건식 | `score >= 60` |
| 대입 | `= += -= *= /=` | 값 저장·갱신 | `score += 10` |

**자주 하는 실수:** 같음 비교는 `==`이고, `=`는 대입입니다.

아래 코드를 실행해 예상 출력과 비교해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 7, b = 2;

    cout << "합: " << a + b << endl;
    cout << "나머지: " << a % b << endl;
    cout << "a > b: " << (a > b) << endl;
    cout << "정수 나눗셈: " << a / b << endl;
    cout << "실수 나눗셈: " << static_cast<double>(a) / b << endl;

    return 0;
}
```

**예상 출력**

```text
합: 9
나머지: 1
a > b: 1
정수 나눗셈: 3
실수 나눗셈: 3.5
```

**코드 해석**

- `%`로 7을 2로 나눈 나머지 `1`을 구합니다.
- `a / b`는 둘 다 `int`라 `3`입니다.
- `static_cast<double>(a) / b`는 실수 나눗셈이라 `3.5`입니다.

### 03-2 증감 연산

`++`는 1 증가, `--`는 1 감소입니다. **`++x`**는 먼저 증가한 뒤 그 값을 쓰고, **`x++`**는 지금 값을 쓴 뒤 증가합니다. 복잡한 식에서는 괄호로 의도를 명확히 하고, **한 줄에 증감을 여러 번 섞지 않는** 편이 안전합니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int x = 5;

    cout << "pre ++x: " << ++x << endl;
    cout << "post x++: " << x++ << endl;
    cout << "after x: " << x << endl;

    return 0;
}
```

**예상 출력**

```text
pre ++x: 6
post x++: 6
after x: 7
```

**코드 해석**

- 첫 줄에서 `x`가 6이 된 뒤 출력됩니다.
- 둘째 줄은 출력할 때는 6이고, 그다음 `x`가 7이 됩니다.
- 셋째 줄에서 `7`을 확인합니다.

### 03-3 논리 연산자

**논리 연산자**는 `bool` 값을 결합·반전할 때 씁니다. `&&`는 **양쪽이 모두 참**일 때만 참, `||`는 **하나라도 참**이면 참, `!`는 참/거짓을 **뒤집습니다.**

`&&`와 `||`는 **단락 평가**를 합니다. 왼쪽만으로 결과가 확정되면 오른쪽을 평가하지 않습니다. 조건을 여러 개 묶을 때는 괄호로 의도를 드러내는 편이 안전합니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score = 85;
    double attend = 0.9;

    bool pass = (score >= 60) && (attend >= 0.8);
    bool warn = (score < 60) || (attend < 0.8);

    cout << "합격: " << pass << endl;
    cout << "경고 대상: " << warn << endl;
    cout << "합격 아님: " << !pass << endl;

    return 0;
}
```

**예상 출력**

```text
합격: 1
경고 대상: 0
합격 아님: 0
```

**코드 해석**

- 점수·출석률 **둘 다** 기준을 넘어야 `pass`가 참입니다.
- `!pass`는 합격을 뒤집은 값입니다.

### 03-4 형 변환

**형 변환**은 값을 다른 타입으로 해석하는 일입니다. 컴파일러가 알아서 맞추는 경우를 **암시적 변환**, 코드를 적어 바꾸는 경우를 **명시적 변환**이라고 합니다.

입문에서 자주 쓰는 명시적 변환은 **`static_cast<double>(a)`**입니다. 정수끼리 나눗셈에서 소수 결과가 필요할 때, **나누기 전에** 한쪽을 실수로 올립니다. `static_cast<double>(a / b)`는 **이미 정수로 나눈 뒤** 실수로 바꾸는 것이라 `3`이 되어, 원하는 `3.5`와 다를 수 있습니다. **괄호 위치**가 결과에 직결됩니다.

| 방식 | 예 | 적합한 상황 |
|---|---|---|
| `static_cast` | `static_cast<double>(a)` | 숫자 ↔ 숫자 |
| C 스타일 캐스트 | `(double)a` | 같은 목적. 입문 예제에도 자주 등장 |

**오류 방지:** `(a + b + c) / 3`처럼 합과 개수가 모두 `int`이면 소수 평균이 깨집니다. `(a + b + c) / 3.0` 또는 `static_cast<double>(a + b + c) / 3`처럼 **나누기 전에** 실수 쪽으로 올립니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = 7, b = 2;

    cout << a / b << endl;
    cout << static_cast<double>(a) / b << endl;
    cout << static_cast<double>(a / b) << endl;

    return 0;
}
```

**예상 출력**

```text
3
3.5
3
```

**코드 해석**

- 둘째 줄만 실수 나눗셈입니다.
- 셋째 줄은 정수 나눗셈 결과를 실수로 올린 것이라 `3`입니다.

이 장 범위는 **연산자 · 증감 · 논리 · 형 변환**입니다. 조건문·반복문은 **다음 장들**에서 조합을 하나씩 늘려 갑니다.

### 연습문제

**문제 1**

- 문제: 정수 3개의 평균을 **소수점**까지 출력하세요.
- 입력: 정수 3개
- 출력: 실수 평균 1개
- 조건: `static_cast` 또는 `3.0` 나눗셈 사용

**문제 2**

- 문제: 같은 변수에 전위·후위 증가를 적용해 각 단계 값을 출력하세요.
- 입력: 없음
- 출력: 각 단계 값
- 조건: 한 줄에 증감을 여러 번 섞지 말 것

**문제 3**

- 문제: 정수 `n`이 짝수인지 여부를 `bool`로 출력하세요. (`n % 2 == 0`)
- 입력: 없음. 변수에 값을 대입해도 됨
- 출력: `1` 또는 `0`
- 조건: `%` 사용. 짝수/홀수 **문자열** 분기는 조건문 장에서 이어감

### 정답 포인트

- 문제 1: 합을 `double`로 나눔. `(a + b + c) / 3`만 쓰면 정수 평균
- 문제 2: `++x`와 `x++`를 **다른 줄**에서 출력해 비교
- 문제 3: `cout << (n % 2 == 0) << endl;`
- 공통: 정수 나눗셈은 소수점 손실, 조건 결합은 괄호로 의도 명확화
