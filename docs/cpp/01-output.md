# Chapter 01 출력

## 학습 목표

- 프로그램이 무엇인지, 코드를 “실행한다”는 말이 무엇인지 대략 설명할 수 있다.
- `cout << "문장";` / `cout << "문장" << endl;`로 화면에 글자를 출력할 수 있다.
- `endl`로 줄을 바꾸는 것과, 같은 줄에 `<<`로 이어 붙이는 차이를 구분해 쓸 수 있다.

## 본문

### 01-1 프로그램이 시작되는 곳

**프로그램**은 컴퓨터에게 “이렇게 해 줘”라고 적어 둔 지시 모음입니다. 그 지시를 사람이 읽고 쓸 수 있게 적어 둔 글이 **코드**이고, Visual Studio에서 **실행**하면 컴퓨터가 그 코드를 **위에서 아래 순서**로 따라 합니다. “실행한다”는 말은 **적어 둔 코드 한 줄 한 줄을 실제로 수행한다**는 뜻에 가깝습니다.

C++ 콘솔에서는 보통 `main`이라고 적힌 부분 **안쪽**부터 따라가기 시작합니다. **우리가 쓰는 문장은** `main`**의** `{`**와** `}` **사이에 적는다**고만 기억하면 충분합니다.

**따라 실행하기 (처음 한 번)**

1. Visual Studio에서 **콘솔 앱** 프로젝트를 만든다. 이미 있으면 그 프로젝트를 연다.
2. 소스 파일의 `main` `{` `}` **안**을 아래 코드처럼 맞춘다.
3. **디버그하지 않고 실행**(보통 `Ctrl + F5`)한다. 창이 바로 닫히면 출력을 못 볼 수 있다.
4. 검은 콘솔 창에 글이 보이면 성공이다. `예상 출력`과 다르면 따옴표·`;`를 다시 본다.

지금부터 가장 간단한 코드 하나를 만들어 보겠습니다. 아래에는 `#include`, `using`, `int main` 같은 낯선 단어도 보이는데, **지금은 뜻을 외울 필요 없습니다.** “C++ 콘솔 프로그램의 **기본 뼈대**가 이렇게 생겼다”고만 보고, 우리가 고칠 곳은 `main`의 `{` `}` **안**이라고 생각하면 됩니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "프로그램이 시작되었습니다." << endl;
    return 0;
}
```

**예상 출력**

```text
프로그램이 시작되었습니다.
```

맨 위 `#include <iostream>`은 화면에 글자를 보내는 기능을 쓰기 위해 자주 들어가는 줄입니다. `using namespace std;`는 `std::`를 매번 붙이지 않게 해 주는 관례적인 줄입니다. 네임스페이스 세부는 **뒤 장**에서 다룹니다. 지금은 **지우지 말고 그대로** 둡니다. `int main()`과 `return 0;`도 “나중에 배울 단어가 붙은 **기본 형태**”로만 두고, 우선은 안쪽에 출력 문장을 적어 실행해 보는 데 집중하세요.

**코드 해석**

- `main`의 `{` `}` 안에 있는 줄이 실제로 실행됩니다.
- `cout << "프로그램이 시작되었습니다." << endl;` 한 줄이 콘솔에 문장을 보여 준 뒤 줄을 바꿉니다.

### 01-2 화면에 글자 출력하기

화면에 글자를 **출력**할 때는 `cout << "출력할 글자";` 형태를 가장 먼저 익히면 됩니다. **`cout`**은 콘솔로 값을 보내는 **출력 스트림**입니다. 스트림은 데이터가 흘러가는 통로라고 보면 됩니다. `<<`는 오른쪽 값을 `cout`으로 **흘려보내는** 연산자입니다.

큰따옴표 `"..."`로 묶인 글을 **문자열**이라고 부릅니다. 줄 끝의 `;`는 “이 지시가 여기서 끝난다”는 표시입니다.

**`endl`**은 줄을 바꾼 뒤 출력 버퍼를 비우는 조작자입니다. `cout << "문장" << endl;`처럼 쓰면 문장을 출력한 뒤 **줄을 바꿉니다.** `endl` 없이 `cout << "문장";`만 쓰면 **같은 줄에 이어서** 쓸 수 있습니다.

| 쓰는 형태 | 줄바꿈 | 이럴 때 |
|---|---|---|
| `cout << "문장";` | 없음 | 같은 줄에 이어서 출력 |
| `cout << "문장" << endl;` | 있음 | 결과 한 줄 출력 |

`<<`는 여러 번 이어 붙일 수 있습니다. `cout << "닉네임: " << "Jinwoo" << endl;`처럼 한 줄에 조각과 줄바꿈을 함께 쓸 수 있습니다.

이 장에서는 **따옴표 안에 적어 둔 문장을 그대로 출력**하는 데만 집중합니다. 값을 이름 붙여 담아 두는 법과, 키보드로 값을 받는 법은 **다음 장들**에서 이어집니다.

아래 코드를 실행해 `endl` 유무와 `<<` 연결 차이를 확인해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "닉네임: ";
    cout << "Jinwoo";
    cout << endl;
    cout << "점수: 100" << endl;
    return 0;
}
```

**예상 출력**

```text
닉네임: Jinwoo
점수: 100
```

**코드 해석**

- `cout << "닉네임: ";`는 따옴표 안 글자만 출력하고 줄은 바꾸지 않습니다.
- 이어서 `cout << "Jinwoo";`로 같은 줄에 이름을 붙입니다.
- `cout << endl;`만 쓰면 **줄바꿈**합니다.
- `cout << "점수: 100" << endl;`은 문장을 출력한 뒤 줄을 바꿉니다.

C에서 `printf`로 찍던 자리와 역할이 비슷합니다. C++에서는 `cout`과 `<<`를 쓰는 것이 기본입니다.

### 연습문제

**문제 1**

- 문제: `cout`으로 `Hello, C++`을 한 줄 출력하세요.
- 입력: 없음
- 출력: `Hello, C++`
- 조건: 큰따옴표로 문장을 묶고, 줄바꿈에 `endl`을 사용할 것

**문제 2**

- 문제: `cout`으로 `이름:` 을 출력한 뒤, 같은 줄에 `Kim`을 이어서 출력하세요. 다음 줄에는 `완료`를 출력하세요.
- 입력: 없음
- 출력: 첫 줄 `이름: Kim`, 다음 줄 `완료`
- 조건: `endl`이 없는 출력과 있는 출력을 모두 사용

**문제 3**

- 문제: 세 줄로 `하나`, `둘`, `셋`을 각각 출력하세요.
- 입력: 없음
- 출력: 첫 줄 `하나`, 둘째 줄 `둘`, 셋째 줄 `셋`
- 조건: `cout`과 `endl`을 세 번 사용

### 정답 포인트

- 문제 1: `cout << "Hello, C++" << endl;`
- 문제 2: `cout << "이름: ";` → `cout << "Kim";` → `cout << endl;` → `cout << "완료" << endl;`
- 문제 3: `cout << "하나" << endl;` 등을 세 번
- 공통: 출력은 큰따옴표로 묶은 문장으로 한다. 고칠 곳은 `main`의 `{` `}` 안이다.
