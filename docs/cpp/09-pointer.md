# Chapter 09 포인터와 참조자

## 학습 목표

- 포인터로 주소 저장·역참조·값 변경을 할 수 있다.
- 참조자를 변수의 별칭으로 선언하고 원본을 바꿀 수 있다.
- 포인터와 참조자의 차이인 `nullptr`·재지정 여부를 구분한다.

## 본문

### 09-1 포인터 기초

**포인터**는 **메모리 주소**를 담는 변수입니다. 일반 변수가 값을 직접 담는다면, 포인터는 “그 값이 있는 위치”를 담습니다. 주소는 `&`로 구합니다. `int* p = &n;`은 `n`의 주소를 `p`에 넣습니다. 포인터가 가리키는 값에 접근하려면 **역참조** `*p`를 씁니다. `*p = 20;`은 주소에 있는 원본을 바꿉니다.

아직 유효한 대상을 모를 때는 **`nullptr`**를 둡니다. `nullptr`는 “가리키는 곳 없음”을 뜻합니다. `nullptr`인 포인터를 `*p`로 읽거나 쓰면 프로그램이 비정상 종료될 수 있으니, 쓰기 전에 유효한 주소를 넣었는지 확인합니다.

아래를 실행해 포인터로 원본이 바뀌는지, 주소가 출력되는지 확인해 보세요. 주소 숫자는 실행마다 달라질 수 있습니다.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n = 10;
    int* p = &n;

    cout << "변경 전 n: " << n << endl;
    *p = 20;
    cout << "변경 후 n: " << n << endl;
    cout << "주소: " << p << endl;
    return 0;
}
```

**예상 출력**

```text
변경 전 n: 10
변경 후 n: 20
주소: 0x...
```

**코드 해석**

- `int* p = &n;`에서 `p`는 `n`의 주소를 저장합니다.
- `*p = 20;`은 주소를 따라가 `n`을 `20`으로 바꿉니다.
- `cout << p`는 주소 값을 출력합니다. 실행 환경마다 숫자가 다릅니다.

함수 인자로 포인터를 받으면, 호출쪽 변수의 주소를 넘겨 원본을 바꿀 수 있습니다. 앞 장에서 배운 참조 전달과 목적은 비슷하고, 문법은 `*`·`&`가 더 드러납니다.

```cpp
#include <iostream>
using namespace std;

void DoubleByPtr(int* p)
{
    if (p == nullptr)
    {
        return;
    }
    *p = *p * 2;
}

int main()
{
    int x = 5;
    DoubleByPtr(&x);
    cout << x << endl;
    return 0;
}
```

**예상 출력**

```text
10
```

**코드 해석**

- `DoubleByPtr(&x)`는 `x`의 주소를 넘깁니다.
- 함수 안 `*p`가 `x` 원본을 두 배로 만듭니다.
- `nullptr`이면 바로 return 해 잘못된 역참조를 막습니다.

### 09-2 참조자 기초

**참조자**는 이미 있는 변수의 **또 다른 이름**입니다. `int& r = n;`처럼 선언과 동시에 반드시 대상을 정합니다. 이후 `r`을 쓰면 곧 `n`을 쓰는 것과 같습니다. `r = 30;`은 `n`을 `30`으로 바꿉니다.

참조자는 선언 뒤 **다른 변수로 대상을 바꿀 수 없습니다**. `r = other;`는 “별칭 대상을 바꾼다”가 아니라, 참조가 가리키는 **원본 값**에 `other`를 대입하는 것입니다. “없을 수도 있음”을 표현할 `nullptr`도 참조자에는 없습니다. 항상 유효한 변수에 묶여 있다고 가정합니다.

아래를 실행해 참조자로 바꾼 값이 원본에 반영되는지 확인해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n = 10;
    int& r = n;

    r = 30;
    cout << "n: " << n << endl;
    cout << "r: " << r << endl;
    return 0;
}
```

**예상 출력**

```text
n: 30
r: 30
```

**코드 해석**

- `int& r = n;`은 `n`의 별칭 `r`을 만듭니다.
- `r = 30;`은 별칭을 통해 원본 `n`을 바꿉니다.
- `n`과 `r`을 출력하면 같은 `30`입니다.

앞 장에서 함수 매개변수 `int&`로 원본을 바꾼 것도 같은 별칭 규칙입니다. 이 장에서는 지역 변수에도 같은 문법이 쓰인다는 점만 더 확인하면 됩니다.

### 09-3 포인터와 참조자 비교

둘 다 원본에 닿는 수단이지만 성격이 다릅니다. **포인터**는 주소를 담는 **변수**라서 `nullptr`이 될 수 있고, 다른 주소를 다시 대입할 수 있습니다. **참조자**는 처음부터 묶인 **별칭**이라 `nullptr`이 없고, 대상을 바꾸지 않습니다. 문법도 포인터는 `*`·`&`가 드러나고, 참조자는 일반 변수처럼 씁니다.

| 항목 | 포인터 | 참조자 |
|---|---|---|
| 의미 | 주소를 담는 변수 | 기존 변수의 별칭 |
| `nullptr` | 가능 | 불가 |
| 대상 재지정 | 가능 | 불가 |
| 접근 문법 | `*p`, `&n` | 변수처럼 `r` |

| 용어 | 의미 |
|---|---|
| 주소 | 값이 저장된 메모리 위치 |
| 역참조 | 주소를 따라가 실제 값에 접근하는 동작 |
| `nullptr` | 유효한 대상을 가리키지 않음을 나타내는 값 |

아래를 실행해 포인터로 한 번, 참조자로 한 번 원본을 바꾼 뒤 최종 `n`을 확인해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n = 10;
    int* p = &n;
    int& r = n;

    *p = 20;
    r = 30;

    cout << "n: " << n << endl;
    cout << "주소: " << p << endl;
    return 0;
}
```

**예상 출력**

```text
n: 30
주소: 0x...
```

**코드 해석**

- `*p = 20;`으로 `n`이 `20`이 됩니다.
- `r = 30;`으로 같은 `n`이 `30`이 됩니다.
- 포인터 `p`는 주소 출력이 가능하고, 참조자 `r`은 값만 일반 변수처럼 씁니다.

선택이 헷갈리면 이렇게 잡습니다. “없을 수 있음”이나 대상을 나중에 바꿀 필요가 있으면 포인터, 항상 유효한 원본만 다루면 참조자가 읽기 쉽습니다. 함수에서는 앞 장처럼 참조 전달을 먼저 쓰고, 주소·`nullptr` 검사가 필요하면 포인터를 씁니다.

### 연습문제

**문제 1**

- 문제: 정수 변수 하나를 두고 포인터로 값을 2배로 바꾸세요.
- 입력: 없음. 예로 초기값 `7`
- 출력: 변경 전·후 값. 예 `7`과 `14`
- 조건: `*p`로 변경

**문제 2**

- 문제: 참조자로 값을 바꾼 뒤 원본이 바뀌는지 출력하세요.
- 입력: 없음. 예로 초기값 `5`, 참조자로 `12` 대입
- 출력: 원본 변수 값 `12`
- 조건: `int&` 사용. 포인터 없이 해결

**문제 3**

- 문제: 포인터 매개변수로 정수를 1 증가시키는 함수를 작성하세요.
- 입력: 없음. `main`에서 예로 `x = 9`를 두고 호출
- 출력: `10`
- 조건: 함수 시그니처에 `int*` 사용. `nullptr`이면 아무 것도 하지 않음

- 문제 1: `int* p = &n; *p = *p * 2;` 후 전·후 출력
