# Chapter 02 변수와 자료형

## 학습 목표

- C++ **기본 자료형**(`int`, `double`, `bool`, `char`, `string`)의 역할과 예시 값을 구분한다.
- 변수 **선언·초기화·재할당**과 `const`를 올바르게 작성한다.
- **`auto`**와 명시적 타입 선언의 차이를 이해한다.
- `cin >> 변수`로 값을 받아 `cout`으로 다시 출력할 수 있다.

## 본문

### 02-1 기본 자료형

**변수**는 값을 담는 **이름이 붙은 상자**입니다. **자료형**은 그 상자에 어떤 종류의 값을 넣을지 정하는 규칙입니다. 앞 장에서 배운 `cout`으로 담아 둔 값을 화면에 확인할 수 있습니다.

| 타입 | 예시 값 | 한 줄 설명 | 자주 쓰는 곳 |
|---|---|---|---|
| `int` | `10`, `-3` | 정수 | 점수, 횟수 |
| `double` | `3.14`, `0.8` | 실수 | 평균, 비율 |
| `bool` | `true`, `false` | 참/거짓 | 플래그, 조건 결과 |
| `char` | `'A'`, `'1'` | 문자 1개 | 등급, 키 한 글자 |
| `string` | `"Hello"` | 문자열 | 이름, 안내 문구 |

`char`는 작은따옴표 `'A'`, `string`은 큰따옴표 `"A"`를 씁니다. `string`을 쓰려면 `#include <string>`이 필요합니다. 문자열을 더 깊게 다루는 법은 **뒤 장**에서 이어집니다. 지금은 **이름을 담는 타입** 정도로 쓰면 됩니다.

아래 코드를 실행해 타입별 출력을 확인해 보세요.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int level = 5;
    double ratio = 0.8;
    bool isClear = true;
    char grade = 'A';
    string name = "Kim";

    cout << level << endl;
    cout << ratio << endl;
    cout << isClear << endl;
    cout << grade << endl;
    cout << name << endl;
    return 0;
}
```

**예상 출력**

```text
5
0.8
1
A
Kim
```

**코드 해석**

- 타입마다 넣을 수 있는 값의 형태가 다릅니다.
- `bool`을 `cout`으로 출력하면 보통 `1`/`0`처럼 보이는 경우가 많습니다.
- `string name = "Kim";`은 글자 덩어리를 변수에 담은 예입니다.

### 02-2 선언·초기화·`const`

선언은 `타입 이름;` 또는 `타입 이름 = 값;`처럼 씁니다. 처음 값을 넣는 것을 **초기화**라고 합니다. 지역 변수를 초기화하지 않은 채 읽으면 쓰레기값이 나올 수 있으므로, **쓰기 전에 값을 넣는** 습관이 중요합니다.

같은 타입을 여러 개 둘 때는 `int x = 1, y = 2;`처럼 나열할 수 있습니다. 이미 선언된 변수에 새 값을 넣는 것은 **재할당**입니다. `const int MaxHp = 100;`처럼 `const`를 붙이면 이후 재할당이 막혀, 바뀌면 안 되는 값에 씁니다.

`int n{10};`처럼 **중괄호 초기화**를 쓰면, 범위를 벗어나는 축소 변환을 컴파일러가 더 잘 막아 주는 경우가 많습니다. 입문에서는 `=` 초기화와 중괄호 초기화 둘 다 “값을 넣는다”는 점은 같습니다.

변수 이름은 영문·숫자·밑줄(`_`)을 쓰고 **숫자로 시작할 수 없습니다.** `int`, `for`, `class` 같은 **예약어**는 이름으로 쓸 수 없습니다.

**자주 하는 실수**

- 타입과 값 불일치: `int n = 3.5;`처럼 소수만 넣으려 할 때
- 초기화 전 사용
- `char` / `string` 따옴표 혼동

아래 코드를 실행해 예상 출력과 비교해 보세요.

```cpp
#include <iostream>
using namespace std;

int main()
{
    int score;
    score = 0;
    score = score + 10;

    const int MaxScore = 100;

    cout << score << endl;
    cout << MaxScore << endl;
    return 0;
}
```

**예상 출력**

```text
10
100
```

**코드 해석**

- `score`는 0으로 시작한 뒤 10으로 바뀝니다.
- `MaxScore`는 재할당이 막힌 상수입니다.

### 02-3 `auto`

**`auto`**는 “타입이 없다”는 뜻이 아니라, **오른쪽 초기값을 보고 컴파일러가 타입을 추론**한다는 뜻입니다. `auto score = 95;`는 컴파일 시점에 `int`로 고정되고, 이후 다른 타입을 넣으면 오류입니다.

입문에서는 **명시적 타입**을 먼저 익히고, `auto`는 오른쪽만 봐도 타입이 분명할 때 쓰는 편이 안전합니다.

| 쓰는 형태 | 예 | 이럴 때 | 입문 권장 |
|---|---|---|---|
| 명시적 타입 | `string nick = "Kim";` | 타입을 코드에 바로 보이게 | **먼저 익히기** |
| `auto` | `auto nick = "Kim";` | 초기값만 봐도 타입이 분명할 때 | 익숙해진 뒤 |

```cpp
#include <iostream>
using namespace std;

int main()
{
    auto nick = "Kim";
    auto level = 5;

    cout << nick << endl;
    cout << level << endl;
    return 0;
}
```

**예상 출력**

```text
Kim
5
```

**코드 해석**

- `auto`로 선언해도 타입은 컴파일 시점에 확정됩니다.
- `"Kim"`은 문자열이므로 `nick`은 문자열 계열로 추론됩니다.

### 02-4 변수와 문장을 함께 출력하기

변수 값을 안내 문장과 함께 찍을 때는 `<<`로 이어 붙이면 됩니다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string nick = "Jinwoo";
    int score = 100;

    cout << "닉네임: " << nick << endl;
    cout << "점수: " << score << endl;
    return 0;
}
```

**예상 출력**

```text
닉네임: Jinwoo
점수: 100
```

**코드 해석**

- 문자열 리터럴과 변수를 `<<`로 한 줄에 연결합니다.

### 02-5 `cin`으로 입력받기

키보드에서 값을 받을 때는 **`cin >> 변수`**를 씁니다. **`cin`**은 입력 스트림이고, `>>`는 스트림에서 값을 꺼내 변수에 넣는 연산자입니다. 안내 문구는 앞 장의 `cout`으로 같은 줄에 보여 주는 패턴이 흔합니다.

`cin >>`는 기본적으로 **공백 전까지만** 읽습니다. 숫자·단어 입력에 맞습니다. 공백이 포함된 한 줄 전체는 **문자열 장**에서 이어서 다룹니다.

아래를 실행한 뒤, 이름과 나이를 입력해 출력을 확인해 보세요.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name;
    int age = 0;

    cout << "이름 입력: ";
    cin >> name;
    cout << "나이 입력: ";
    cin >> age;

    cout << "안녕하세요, " << name << "님. " << age << "살이군요." << endl;
    return 0;
}
```

**예상 출력 (이름 `Kim`, 나이 `20`을 입력한 경우)**

```text
이름 입력: Kim
나이 입력: 20
안녕하세요, Kim님. 20살이군요.
```

**코드 해석**

- `string name;`과 `int age`에 입력값을 담을 자리를 마련합니다.
- `cin >> name;`, `cin >> age;`로 각각 읽어 들입니다.
- 마지막 `cout`에서 문자열과 숫자를 `<<`로 이어 출력합니다.

이 장 범위는 **자료형 · 변수 · `auto`/`const` · 기본 `cin`**입니다. 연산자·형 변환은 **다음 장**에서 이어집니다.

### 연습문제

**문제 1**

- 문제: `int`, `double`, `char`, `bool` 변수를 선언하고 각각 출력하세요.
- 입력: 없음
- 출력: 값 4개 (값은 달라도 타입만 맞으면 됨)
- 조건: 각 변수에 초기값 포함

**문제 2**

- 문제: `const`와 `auto`를 각각 1개 이상 사용해 값을 출력하세요.
- 입력: 없음
- 출력: 상수·추론 변수 값
- 조건: `const` 값 변경 시도 금지

**문제 3**

- 문제: 정수 하나와 이름 하나를 입력받아 `이름=..., 점수=...` 형태로 한 줄 출력하세요.
- 입력: 이름 1개, 정수 1개
- 출력: 예) `이름=Kim, 점수=90`
- 조건: `cin`과 `cout` 사용

### 정답 포인트

- 문제 1: 타입별 선언 후 `cout << ... << endl;`
- 문제 2: `const int Max = 10;` / `auto n = 3;`
- 문제 3: `cin >> name;` / `cin >> score;` 후 `<<`로 연결 출력
- 공통: 고칠 곳은 `main`의 `{` `}` 안
