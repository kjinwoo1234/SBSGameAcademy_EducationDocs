# Chapter 19 STL 알고리즘과 람다

## 학습 목표

- `<algorithm>`의 `sort`, `count_if` 등으로 컨테이너를 처리할 수 있다.
- 람다식으로 비교·조건 함수를 짧게 넘길 수 있다.
- 알고리즘과 람다를 조합해 정렬·개수 세기 코드를 작성한다.

## 본문

### 19-1 `<algorithm>` 기초

앞 장까지는 컨테이너에 값을 넣고 직접 반복문으로 다루는 경우가 많았습니다. **알고리즘**은 “정렬한다”, “조건에 맞는 개수를 센다”처럼 **의도**를 함수 이름으로 드러냅니다. 헤더는 `<algorithm>`입니다.

대표적으로 `sort(v.begin(), v.end())`는 구간을 오름차순 정렬합니다. `v.begin()`은 첫 원소 위치, `v.end()`는 **마지막 다음** 위치입니다. 이 둘로 “어디서부터 어디까지”를 나타냅니다. `count_if`는 조건을 만족하는 원소 개수를 세고, `find_if`는 조건을 만족하는 첫 위치를 찾습니다.

알고리즘은 반복문을 무조건 없애는 도구가 아닙니다. 읽었을 때 “무엇을 하는지”가 분명해지도록 돕는 도구입니다.

| 함수 | 하는 일 | 입문 예 |
|---|---|---|
| `sort` | 구간 정렬 | 점수 오름·내림차순 |
| `count_if` | 조건 만족 개수 | 80점 이상 몇 명 |
| `find_if` | 조건 만족 첫 원소 | 특정 이름 찾기 |

아래를 실행해 기본 `sort`로 오름차순이 되는지 확인해 보세요.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> scores = {70, 95, 82, 60, 88};
    sort(scores.begin(), scores.end());

    for (int s : scores)
    {
        cout << s << " ";
    }
    cout << endl;
    return 0;
}
```

**예상 출력**

```text
60 70 82 88 95
```

**코드 해석**

- `sort`에 시작·끝 반복자를 넘겨 전체 구간을 정렬합니다.
- 기본 비교는 오름차순입니다.
- 정렬 후 범위 기반 `for`로 출력합니다.

### 19-2 람다식

**람다**는 이름 없는 짧은 함수 객체입니다. 필요할 때 그 자리에서 정의합니다. 기본 형태는 `[캡처](매개변수){ 본문 }`입니다. 캡처는 람다 밖 변수를 안으로 가져오는 부분이고, 당장은 `[]`처럼 비워 두어도 됩니다.

```cpp
[](int a, int b) { return a > b; }
```

위 람다는 두 정수를 받아 “앞이 더 큰가?”를 참·거짓으로 돌려줍니다. `sort`에 넘기면 내림차순 비교로 쓸 수 있습니다. 조건만 필요할 때는 `[](int x) { return x >= 80; }`처럼 인자 하나짜리 람다를 씁니다.

| 용어 | 의미 |
|---|---|
| 람다 | 그 자리에서 정의하는 익명 함수 |
| 캡처 | 외부 변수를 람다 안에서 쓰도록 가져오는 방법 |

캡처가 필요하면 `[=]`는 복사, `[&]`는 참조로 바깥 변수를 가져옵니다. 입문에서는 비교·조건에 쓰는 짧은 `[]` 람다부터 익숙해지면 충분합니다.

### 19-3 알고리즘과 람다 조합

`sort`의 세 번째 인자로 비교 람다를 넘기면 정렬 기준을 바꿉니다. `count_if`의 세 번째 인자로 조건 람다를 넘기면 “몇 개가 조건에 맞는가”를 바로 얻을 수 있습니다. 별도 함수를 파일 위에 따로 두지 않아도, 의도가 짧은 경우에는 람다가 읽기 쉽습니다.

문자열을 길이 순으로 정렬할 때도 비교 람다에서 `a.size() < b.size()`처럼 쓰면 됩니다. “무엇을 기준으로 비교하는가”가 호출 자리에 보입니다.

아래를 실행해 내림차순 정렬 결과를 확인해 보세요.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> scores = {70, 95, 82, 60, 88};
    sort(scores.begin(), scores.end(), [](int a, int b) {
        return a > b;
    });

    for (int s : scores)
    {
        cout << s << " ";
    }
    cout << endl;
    return 0;
}
```

**예상 출력**

```text
95 88 82 70 60
```

**코드 해석**

- 세 번째 인자 람다가 “앞이 더 크면 앞으로” 비교를 제공합니다.
- 그 결과 내림차순이 됩니다.
- 별도 비교 함수 이름을 만들지 않아도 됩니다.

이어서 `count_if`로 80 이상 개수를 세어 보세요.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> scores = {70, 95, 82, 60, 88};
    int count = count_if(scores.begin(), scores.end(), [](int x) {
        return x >= 80;
    });
    cout << count << endl;
    return 0;
}
```

**예상 출력**

```text
3
```

**코드 해석**

- `count_if`가 구간을 돌며 람다 조건이 참인 원소만 셉니다.
- `95`, `82`, `88` 세 개가 80 이상입니다.
- 직접 `for`로 세는 것과 결과는 같고, 의도는 함수 이름에 드러납니다.

이 장에서는 `sort`·`count_if`와 람다 조합이 핵심입니다. 예외로 오류를 알리고 자원을 안전하게 묶는 방법은 다음 장에서 다룹니다.

### 연습문제

**문제 1**

- 문제: 정수 벡터에서 80 이상 점수 개수를 세세요.
- 입력: 없음. 예 `{70, 95, 82, 60, 88}`
- 출력: `3`
- 조건: `count_if`와 람다 사용

**문제 2**

- 문제: 문자열 벡터를 길이 기준 오름차순으로 정렬해 출력하세요.
- 입력: 없음. 예 `{"sword", "axe", "bow"}`
- 출력: 짧은 문자열부터. 예 `axe` / `bow` / `sword` 순서
- 조건: `sort` 비교 람다에서 `size()` 비교

**문제 3**

- 문제: 정수 벡터를 내림차순 정렬한 뒤 한 줄로 출력하세요.
- 입력: 없음. 예 `{1, 4, 2, 8}`
- 출력: `8 4 2 1` 형태
- 조건: `sort` + 비교 람다

### 정답 포인트

- 문제 1: `count_if(..., [](int x){ return x >= 80; })`
- 문제 2: `[](const string& a, const string& b){ return a.size() < b.size(); }`
- 문제 3: `[](int a, int b){ return a > b; }`
- 공통: 알고리즘은 의도 명확화. 람다는 짧고 목적이 분명할 때
