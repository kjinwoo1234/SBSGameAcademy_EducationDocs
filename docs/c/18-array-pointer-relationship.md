# Chapter 18 다차원 배열과 포인터의 관계

## 학습 목표

- `int arr[2][3]`에서 배열 이름 `arr`가 “한 행”을 가리키는 포인터처럼 읽힘을 이해한다.
- 함수 매개변수에서 열 크기를 밝히는 이유를 설명한다.
- `int arr[][3]`과 `int (*arr)[3]` 선언을 표로 구분한다.

## 본문

### 18-1 2차원 배열 이름의 타입

`int arr[2][3]`에서 배열 이름 `arr`는 단순히 `int *`가 아닙니다. 한 줄로 말하면 **`int` 세 개짜리 한 행을 가리키는 포인터**에 가깝습니다. 타입으로 쓰면 `int (*)[3]`입니다. 그래서 `arr`는 첫 행 전체를 가리키고, `arr + 1`은 다음 행으로 한 줄 이동합니다. `arr[0]`은 첫 행의 시작으로 이어져 `arr[0][0]`이 첫 값이 됩니다.

| 표현 | 의미 |
|---|---|
| `arr` | 첫 행을 가리키는 행 포인터에 가까움 |
| `arr + 1` | 다음 행 |
| `arr[r][c]` | `r`행 `c`열의 값 |

아래를 실행해 행을 옮겨 가며 첫 열 값이 바뀌는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int arr[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    printf("%d\n", arr[0][0]);
    printf("%d\n", arr[1][0]);
    printf("%d\n", (*(arr + 1))[0]);
    return 0;
}
```

**예상 출력**

```text
1
4
4
```

**코드 해석**

- `arr[0][0]`은 첫 행 첫 열 `1`입니다.
- `arr[1][0]`과 `(*(arr + 1))[0]`은 둘 다 둘째 행 첫 열 `4`입니다.
- `arr + 1`은 바이트 1이 아니라 **행 하나**만큼 이동합니다.

### 18-2 함수 인자와 열 크기

2차원 배열을 함수에 넘길 때 컴파일러는 **한 행의 폭**, 곧 열 개수를 알아야 `arr[r][c]` 위치를 계산할 수 있습니다. 그래서 매개변수에 열 크기를 밝힙니다. 흔한 형태는 `void print_sum(int arr[][3], int row)`입니다. `int (*arr)[3]`도 같은 폭을 드러내는 선언입니다. 행 개수는 길이처럼 별도 인자로 받는 경우가 많습니다.

| 선언 | 의미 |
|---|---|
| `int arr[][3]` | 열 크기 3이 고정된 2차원 배열 매개변수 |
| `int (*arr)[3]` | `int[3]` 한 행을 가리키는 포인터 |
| `int *arr` | 1차원처럼만 보이므로 2차원 인덱스 계산과 혼동하기 쉬움 |

아래를 실행해 함수가 전체 합을 출력하는지 확인해 보세요.

```c
#include <stdio.h>

void print_sum(int arr[][3], int row)
{
    int r;
    int c;
    int sum = 0;

    for (r = 0; r < row; r++)
    {
        for (c = 0; c < 3; c++)
        {
            sum += arr[r][c];
        }
    }
    printf("sum: %d\n", sum);
}

int main(void)
{
    int data[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    print_sum(data, 2);
    return 0;
}
```

**예상 출력**

```text
sum: 21
```

**코드 해석**

- `print_sum(data, 2)`는 배열과 행 수 `2`를 넘깁니다.
- 매개변수 `arr[][3]`의 `3`이 열 폭입니다.
- 합은 `1+2+3+4+5+6 = 21`입니다.

### 18-3 행 단위로 다루기

행 포인터를 변수에 담아 한 행씩 처리할 수도 있습니다. `int (*row)[3] = arr;`처럼 두면 `row`는 첫 행을 가리키고, `row + 1`로 다음 행으로 옮깁니다. 입문에서는 `arr[r][c]` 표기를 먼저 익히고, 행 포인터는 “한 줄 단위로 움직인다”는 그림만 잡으면 됩니다.

아래를 실행해 행 포인터로 각 행의 첫 값을 출력해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int arr[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };
    int (*row)[3] = arr;
    int i;

    for (i = 0; i < 2; i++)
    {
        printf("%d\n", (*row)[0]);
        row = row + 1;
    }
    return 0;
}
```

**예상 출력**

```text
1
4
```

**코드 해석**

- `row`는 처음에 첫 행을 가리키므로 `(*row)[0]`은 `1`입니다.
- `row = row + 1` 뒤 둘째 행의 첫 값 `4`입니다.
- `(*row)[0]`은 현재 행의 열 `0`입니다.

### 연습문제

**문제 1**
- 문제: 2차원 배열과 행 수를 받아 최댓값을 반환하는 함수를 작성하세요.
- 입력: 없음. 예로 `{{1, 8, 3},{4, 5, 2}}`, 행 수 `2`, 열 크기 `3`
- 출력: `8`
- 조건: 매개변수에 열 크기 `3`을 명시. `const`를 붙여도 됩니다

**문제 2**
- 문제: 2차원 배열의 각 행의 합을 한 줄씩 출력하는 함수를 작성하세요.
- 입력: 없음. 예로 `{{1, 2, 3},{4, 5, 6}}`
- 출력:
  ```text
  6
  15
  ```
- 조건: `void print_row_sums(int arr[][3], int row)` 형태. 바깥=행, 안쪽=열

**문제 3**
- 문제: `int (*p)[3]`에 2차원 배열 이름을 넣고, `p[r][c]`로 모든 원소를 공백 구분 한 줄 출력하세요.
- 입력: 없음. 예로 `{{1, 2, 3},{4, 5, 6}}`
- 출력: `1 2 3 4 5 6`
- 조건: `int (*p)[3] = data;` 사용 후 이중 루프

### 정답 포인트

- 문제 1: `max = arr[0][0]` 후 모든 `arr[r][c]`와 비교
- 문제 2: 행마다 합을 0으로 리셋하고 열을 더해 출력
- 문제 3: `p[r][c]`는 행 포인터 배열 접근. `data[r][c]`와 같은 칸
- 공통: 함수 매개변수에서 **열 크기 고정**, 행 수는 인자로 전달
