# Chapter 21 구조체와 사용자 정의 자료형 1

## 학습 목표

- `struct`로 서로 다른 타입의 멤버를 한 덩어리로 묶는다.
- 구조체 변수는 `.`, 구조체 포인터는 `->`로 멤버에 접근한다.
- 구조체 배열과 함수 인자로 구조체·구조체 포인터를 넘기는 차이를 이해한다.

## 본문

### 21-1 구조체 선언과 멤버 접근

**구조체**는 이름·점수·등급처럼 타입이 다른 값을 **하나의 사용자 정의 자료형**으로 묶습니다. 선언은 `struct` 태그 이름과 중괄호 안 멤버 목록으로 합니다. 변수를 만들면 멤버마다 칸이 생기고, 접근은 **점(`.`) 연산자**로 합니다.

초기화는 `{ 값1, 값2, ... }`처럼 멤버 순서대로 넣거나, 선언 뒤 하나씩 대입해도 됩니다. 멤버 이름은 그 구조체 안에서만 의미가 있습니다. 다른 구조체에 같은 이름 멤버가 있어도 서로 다른 칸입니다.

| 용어 | 의미 |
|---|---|
| 구조체 | 여러 멤버를 묶은 사용자 정의 타입 |
| 멤버 | 구조체 안의 한 칸 |
| `.` | 구조체 변수에서 멤버 접근 |

아래를 실행해 `id`와 `score`가 한 줄에 나오는지 확인해 보세요.

```c
#include <stdio.h>

struct Student
{
    int id;
    int score;
};

int main(void)
{
    struct Student s;

    s.id = 1;
    s.score = 95;
    printf("%d %d\n", s.id, s.score);
    return 0;
}
```

**예상 출력**

```text
1 95
```

**코드 해석**

- `struct Student`가 새 타입 이름입니다.
- `s.id`, `s.score`로 멤버에 값을 넣고 읽습니다.
- 두 값이 한 변수 `s` 안에 묶여 있습니다.

### 21-2 구조체 배열

같은 모양의 객체가 여러 개면 **구조체 배열**이 편합니다. `struct Student list[3];`처럼 두면 `list[0]`, `list[1]`이 각각 한 명의 데이터입니다. 순회할 때는 인덱스와 `.`를 함께 씁니다. `list[i].score`는 `i`번째 학생의 점수입니다.

배열 초기화는 `{{1, 90}, {2, 80}}`처럼 안쪽 중괄호로 한 요소씩 채울 수 있습니다. 길이는 지금까지 배운 배열과 같습니다. 인덱스는 `0`부터입니다.

| 표기 | 의미 |
|---|---|
| `list[i]` | `i`번째 구조체 |
| `list[i].id` | 그 구조체의 `id` 멤버 |

아래를 실행해 두 학생 정보가 두 줄로 출력되는지 확인해 보세요.

```c
#include <stdio.h>

struct Student
{
    int id;
    char grade;
    int score;
};

int main(void)
{
    struct Student s[2] = {
        {1, 'A', 95},
        {2, 'B', 82}
    };
    int i;

    for (i = 0; i < 2; i++)
    {
        printf("%d %c %d\n", s[i].id, s[i].grade, s[i].score);
    }
    return 0;
}
```

**예상 출력**

```text
1 A 95
2 B 82
```

**코드 해석**

- `s[0]`과 `s[1]`이 각각 한 명의 `Student`입니다.
- 반복문으로 배열을 돌며 `.`로 멤버를 출력합니다.
- `grade`는 `char`이므로 `%c`로 찍습니다.

### 21-3 구조체 포인터와 `->`

구조체를 가리키는 **포인터**가 있으면 멤버 접근은 **화살표(`->`)**를 씁니다. `p->id`는 `(*p).id`와 같습니다. 괄호와 점을 매번 쓰기보다 `->`가 읽기 쉽습니다.

주소는 `&`로 얻습니다. `struct Student *p = &s;`처럼 두면 `p`는 `s`와 **같은 메모리**를 봅니다. `p->score = 100;`은 `s.score`를 바꿉니다.

| 상황 | 연산자 | 예 |
|---|---|---|
| 구조체 변수 | `.` | `s.id` |
| 구조체 포인터 | `->` | `p->id` |

아래를 실행해 포인터로 바꾼 점수가 출력되는지 확인해 보세요.

```c
#include <stdio.h>

struct Student
{
    int id;
    int score;
};

int main(void)
{
    struct Student s = {1, 70};
    struct Student *p = &s;

    p->score = 100;
    printf("%d %d\n", s.id, s.score);
    return 0;
}
```

**예상 출력**

```text
1 100
```

**코드 해석**

- `p`는 `s`의 주소입니다.
- `p->score = 100`이 `s.score`를 바꿉니다.
- `printf`는 변수 `s`를 읽어도 이미 `100`입니다.

### 21-4 함수에 구조체 넘기기

함수 인자로 구조체를 **값**으로 넘기면 호출 시 **내용 전체가 복사**됩니다. 함수 안에서 멤버를 바꿔도 원본은 그대로입니다. **포인터**로 넘기면 주소만 전달되고, 함수 안 `->`로 원본을 바꿀 수 있습니다. 읽기만 하면 `const struct Student *p`처럼 `const`를 붙여 실수로 쓰지 못하게 할 수 있습니다.

크기가 커질수록 값 복사는 부담이 됩니다. 입문에서는 “바꾸려면 포인터, 읽기만이면 값 또는 `const` 포인터” 정도로 고르면 됩니다.

| 전달 | 특징 |
|---|---|
| 값 (`struct Student s`) | 복사본. 원본 불변 |
| 포인터 (`struct Student *p`) | 같은 메모리. 원본 변경 가능 |
| `const` 포인터 | 읽기 전용으로 원본 공유 |

아래를 실행해 포인터로 올린 점수가 `main`에도 반영되는지 확인해 보세요.

```c
#include <stdio.h>

struct Student
{
    int id;
    int score;
};

void add_bonus(struct Student *p, int bonus)
{
    p->score = p->score + bonus;
}

int main(void)
{
    struct Student s = {3, 80};

    add_bonus(&s, 10);
    printf("%d %d\n", s.id, s.score);
    return 0;
}
```

**예상 출력**

```text
3 90
```

**코드 해석**

- `add_bonus`는 주소를 받아 `p->score`를 올립니다.
- `main`의 `s.score`가 `90`이 됩니다.
- 값으로 `struct Student s`만 넘겼다면 `main`의 점수는 그대로 `80`이었을 것입니다.

### 연습문제

**문제 1**
- 문제: `Book` 구조체에 제목 문자열과 가격 정수를 두고, 한 권을 만들어 한 줄로 출력하세요.
- 입력: 없음. 예로 제목 `"C Book"`, 가격 `15000`을 코드에 넣어도 됨
- 출력: `C Book 15000`
- 조건: `struct Book` 정의. 멤버 접근은 `.` 사용

**문제 2**
- 문제: 학생 3명의 `id`와 `score`를 구조체 배열에 두고, 최고 점수의 `id`와 `score`를 출력하세요.
- 입력: 없음. 예: `(1, 70)`, `(2, 95)`, `(3, 88)`
- 출력: `2 95`
- 조건: 반복으로 배열 순회. 현재 최고와 비교해 갱신

**문제 3**
- 문제: `void set_score(struct Student *p, int score)`를 작성해 점수를 바꾼 뒤 `main`에서 출력하세요.
- 입력: 없음. 초기 `id = 10`, `score = 50` 후 `set_score`로 `90` 설정
- 출력: `10 90`
- 조건: 함수 인자는 포인터. 멤버 접근은 `->`
