문제를 고를 때는 입력과 출력을 먼저 적고, 핵심 계산을 함수로 빼 두면 읽기 쉽습니다. 구현이 끝나면 정상 값뿐 아니라 **경계값**도 넣어 봅니다.

### 11-2 반복·조건·배열·함수를 섞을 때

**반복** 문제의 핵은 언제 멈추는지와 매 회차 무엇이 바뀌는지입니다. **조건** 문제는 갈래를 나누는 기준과 경계가 맞는지가 중요합니다. **배열**은 여러 값을 한 묶음으로 둘 때 쓰고, **함수**는 같은 계산을 이름 붙여 재사용할 때 씁니다. 재귀는 종료 조건을 먼저 고정한 뒤 호출 식을 적습니다.

아래는 연습 전에 흐름만 확인하는 짧은 뼈대입니다. `N`을 받아 1부터 `N`까지 합을 함수로 구한 예입니다.

```c
#include <stdio.h>

int sum_to_n(int n)
{
    int i;
    int sum = 0;

    for (i = 1; i <= n; i++)
    {
        sum += i;
    }
    return sum;
}

int main(void)
{
    int n;
    scanf("%d", &n);
    printf("%d\n", sum_to_n(n));
    return 0;
}
```

**예상 출력** — 입력 `5`

```text
15
```

**코드 해석**

- `sum_to_n`이 누적합을 계산해 `return`합니다.
- `main`은 입력과 출력만 담당합니다.
- 같은 합을 재귀로도 만들 수 있습니다. 연습문제에서 다시 다룹니다.

### 연습문제

**문제 1**
- 문제: 정수 `N`을 입력받아 1부터 `N`까지의 합을 출력하세요.
- 입력: 양의 정수 `N` 1개. 범위 `1 <= N <= 10000`. 예: `5`
- 출력: `15`
- 조건: 누적합 변수와 반복문 사용. 합 계산은 함수로 분리 권장

**문제 2**
- 문제: 단 `dan`을 입력받아 `dan x 1`부터 `dan x 9`까지 한 줄씩 출력하세요.
- 입력: 정수 `dan` 1개. 범위 `2 <= dan <= 9`. 예: `3`
- 출력:
  ```text
  3 x 1 = 3
  3 x 2 = 6
  3 x 3 = 9
  3 x 4 = 12
  3 x 5 = 15
  3 x 6 = 18
  3 x 7 = 21
  3 x 8 = 24
  3 x 9 = 27
  ```
- 조건: `for` 또는 `while`로 1부터 9까지 곱셈 결과 출력

**문제 3**
- 문제: 높이 `h`를 입력받아 왼쪽 정렬 별 피라미드를 출력하세요.
- 입력: 정수 `h` 1개. 범위 `1 <= h <= 10`. 예: `3`
- 출력:
  ```text
  *
  **
  ***
  ```
- 조건: 바깥 반복은 줄, 안쪽 반복은 별 개수

**문제 4**
- 문제: 연도 `year`를 입력받아 윤년이면 `Leap`, 아니면 `Common`을 출력하세요.
- 입력: 정수 연도 1개. 예: `2000`
- 출력: `Leap`
- 조건: `year % 4 == 0 && year % 100 != 0` 이거나 `year % 400 == 0`이면 윤년

**문제 5**
- 문제: 정수 세 개를 입력받아 가장 큰 값을 출력하세요.
- 입력: 정수 3개. 예: `4 9 2`
- 출력: `9`
- 조건: `if`/`else if`/`else` 또는 비교 갱신. 배열을 써도 됩니다

**문제 6**
- 문제: 정수 다섯 개를 배열에 저장한 뒤 최댓값과 합을 출력하세요.
- 입력: 정수 5개. 예: `3 9 2 7 5`
- 출력:
  ```text
  9
  26
  ```
- 조건: 1차원 배열과 반복문. 최댓값·합은 각각 함수로 분리 권장

**문제 7**
- 문제: 정수 `N`을 입력받아 `N!`을 재귀 함수로 계산하세요.
- 입력: 정수 `N` 1개. 예: `5`
- 출력: `120`
- 조건: 재귀 사용. 종료 조건을 먼저 작성. `N`은 `0` 이상 `12` 이하로 가정해도 됩니다

**문제 8**
- 문제: 정수 `N`을 입력받아 1부터 `N`까지의 합을 재귀 함수로 계산하세요.
- 입력: 정수 `N` 1개. 예: `4`
- 출력: `10`
- 조건: `N <= 1`을 종료 조건으로 두고 `N + sum(N - 1)` 형태 사용

**문제 9**
- 문제: 공백 없는 단어 하나를 `char` 배열로 입력받아 재귀로 역순 출력하세요.
- 입력: 문자열 1개. 예: `abc`
- 출력: `cba`
- 조건: `\0`을 만날 때까지 재귀 호출한 뒤, 돌아오면서 한 글자씩 출력. `string.h` 역순 함수 사용 금지

### 정답 포인트

- 문제 1: `sum = 0;` 후 `for (i = 1; i <= n; i++) sum += i;`
- 문제 2: `for (i = 1; i <= 9; i++) printf("%d x %d = %d\n", dan, i, dan * i);`
- 문제 3: 줄 `r`마다 별 `r`개. 이중 `for`
- 문제 4: 윤년 조건을 `if` 한곳에 모으고, 참이면 `Leap` 아니면 `Common`
- 문제 5: `max`를 첫 수로 두고 나머지와 비교해 갱신, 또는 세 갈래 `if`
- 문제 6: 배열에 `scanf`로 채운 뒤 순회로 최댓값·합. 문제 1·5 패턴 재사용
- 문제 7: `if (n <= 1) return 1;` 후 `return n * factorial(n - 1);`
- 문제 8: `if (n <= 1) return n;` 후 `return n + sum_to_n(n - 1);`
- 문제 9: `void print_rev(char word[], int i)`에서 `word[i] == '\0'`이면 return. 아니면 `print_rev(word, i + 1)` 후 `printf("%c", word[i]);`. 시작 호출은 `print_rev(word, 0)`
- 공통: 입력 범위·출력 형식·종료 조건을 먼저 고정하고, 경계값으로 재확인
