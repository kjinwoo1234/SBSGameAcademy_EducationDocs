# Chapter 06 `printf` 함수와 `scanf` 함수 정리

## 학습 목표

- `%d`·`%f`·`%c`·`%s`·`%%` 등 **형식 지정자**로 `printf` 출력을 맞출 수 있다.
- `scanf`로 정수·실수·문자를 읽고, 숫자에는 `&`가 필요한 이유를 한 줄로 말할 수 있다.
- 문자열 입력에서 `%19s`처럼 **길이 제한**을 두는 습관을 적용할 수 있다.

## 본문

### 06-1 `printf`와 형식 지정자

앞 장까지 `printf`로 글자와 변수 값을 찍어 보았습니다. 이 장에서는 **형식 지정자**를 한곳에 모아 정리합니다. 형식 지정자는 `%`로 시작하는 기호로, “이 자리를 어떤 타입처럼 보여 줄지”를 정합니다.

| 형식 지정자 | 대상 타입 | 설명 | 예 |
|---|---|---|---|
| `%d` | `int` | 10진 정수 | `25` |
| `%f` | `float`, `double` | 실수. 기본 소수 6자리 | `3.141590` |
| `%.2f` | `float`, `double` | 소수 둘째 자리까지 | `3.14` |
| `%c` | `char` | 문자 1개 | `A` |
| `%s` | `char[]` | 문자열 | `Kim` |
| `%%` | 없음 | `%` 글자 자체 | `95%` |

`%s`는 **문자열**을 찍을 때 씁니다. `"Kim"`처럼 따옴표로 묶인 글자 묶음이 그 예입니다. `char text[] = "Kim";`처럼 변수에 담을 수도 있는데, `[]`는 “문자 칸을 여러 개 이어 둔다”는 표시입니다. 배열의 세부는 뒤 장에서 다룹니다. 컴퓨터는 문자열 끝에 **끝 표시**로 `\0`을 두고, `%s`는 그 앞까지만 출력합니다.

`printf` 안에서 `%`는 형식의 시작입니다. 화면에 `%` 글자만 찍으려면 `%%`를 씁니다. 예를 들어 `printf("배터리: 95%%\n");`를 실행하면 화면에는 `배터리: 95%`가 출력됩니다.
```c
#include <stdio.h>

int main(void)
{
    int n = 25;
    double pi = 3.14159;
    char ch = 'A';
    char text[] = "Kim";

    printf("%%d -> %d\n", n);
    printf("%%f -> %f\n", pi);
    printf("%%.2f -> %.2f\n", pi);
    printf("%%c -> %c\n", ch);
    printf("%%s -> %s\n", text);
    printf("배터리: 95%%\n");
    return 0;
}
```

**예상 출력**

```text
%d -> 25
%f -> 3.141590
%.2f -> 3.14
%c -> A
%s -> Kim
배터리: 95%
```

**코드 해석**

- 각 `%…` 자리에 뒤에 넘긴 값이 순서대로 들어갑니다.
- `%%`는 형식 자리가 아니라 `%` 한 글자입니다.

출력 폭을 맞출 때는 `%5d`, `%-5d`, `%8.2f`처럼 씁니다.

| 형식 | 의미 |
|---|---|
| `%5d` | 최소 5칸. 오른쪽 정렬 |
| `%-5d` | 최소 5칸. 왼쪽 정렬 |
| `%8.2f` | 전체 폭 8칸, 소수 2자리 |

```c
#include <stdio.h>

int main(void)
{
    int x = 42;
    double y = 3.5;

    printf("|%5d|\n", x);
    printf("|%-5d|\n", x);
    printf("|%8.2f|\n", y);
    return 0;
}
```

**예상 출력**

```text
|   42|
|42   |
|    3.50|
```

**코드 해석**

- `|`는 칸 경계를 눈으로 보기 위한 표시입니다.
- `%5d`는 오른쪽으로 밀고, `%-5d`는 왼쪽으로 붙입니다.

문자열 안의 **이스케이프**도 자주 씁니다. `\n`은 줄바꿈, `\t`는 탭, `\"`는 큰따옴표 자체입니다.

### 06-2 `scanf`와 주소 `&`

**`scanf`**는 키보드에서 읽은 값을 변수에 넣습니다. 숫자·문자 한 글자에는 보통 **`&변수`**를 넘깁니다. `&`는 그 변수가 있는 위치를 알려 주는 기호입니다. “어디에 쓸지”를 `scanf`에 전하는 역할입니다. 주소·포인터의 세부는 **포인터 장**에서 이어집니다.

| 형식 | 입력 대상 | 전달 |
|---|---|---|
| `%d` | `int` | `&num` |
| `%f` | `float` | `&height` |
| `%lf` | `double` | `&weight` |
| `%c` | `char` | `&ch` |
| `%s` | 문자열 배열 | `name` — `&` 없음 |

이 장에서는 **형식과 `&`를 맞추는 것**에 집중합니다. 입력이 몇 개 성공했는지 검사하는 문법은 **조건문** 장에서 이어갑니다. 문자열 배열은 배열 이름이 시작 위치처럼 동작하는 경우가 많아 `&` 없이 넘깁니다. 버퍼가 20칸이면 `%19s`처럼 **최대 길이를 제한**해 마지막 칸을 남겨 두는 편이 안전합니다.
```c
#include <stdio.h>

int main(void)
{
    int num;
    float height;
    double weight;
    char grade;
    char name[20];

    printf("입력 예시: 10 173.5 65.2 A Kim\n");
    scanf("%d %f %lf %c %19s", &num, &height, &weight, &grade, name);

    printf("num=%d, height=%.1f, weight=%.1lf, grade=%c, name=%s\n",
           num, height, weight, grade, name);
    return 0;
}
```

**예상 출력(입력: `10 173.5 65.2 A Kim`)**

```text
num=10, height=173.5, weight=65.2, grade=A, name=Kim
```

헷갈리기 쉬운 규칙은 표로 다시 짚으면 다음과 같습니다.

| 항목 | 규칙 |
|---|---|
| 숫자/실수/문자 1개 입력 | 보통 `&변수명` 사용 |
| 문자열 배열 입력 | 배열 이름(`name`) 자체 전달 (`&` 없음) |
| 공백 포함 문자열 | `scanf("%s")`만으로는 부족할 수 있어, 나중에 배우는 다른 입력 함수를 고려 |

아래 예시는 이름·나이·키를 한 줄로 받는 패턴입니다. `char name[20]`은 문자 칸 20개짜리 자리이고, `%19s`는 최대 19글자까지만 받아 마지막 한 칸을 끝 표시(`\0`)에 남겨 두려는 뜻입니다. `age`와 `height`는 값이 들어갈 위치가 필요하므로 `&`를 붙이고, `name`은 배열 이름이 시작 위치처럼 동작하므로 `&` 없이 넘깁니다.

```c
#include <stdio.h>

int main(void)
{    int age;
    float height;
    char name[20];

    printf("이름 나이 키 입력: ");
    scanf("%19s %d %f", name, &age, &height);

    printf("이름: %s\n", name);
    printf("나이: %d\n", age);
    printf("키: %.1f\n", height);
    return 0;
}
```

**예상 출력** — 입력 `Kim 20 173.5`인 경우

```text
이름 나이 키 입력: Kim 20 173.5
이름: Kim
나이: 20
키: 173.5
```

**코드 해석**

- `%19s`는 `name`에, `%d`는 `&age`에, `%f`는 `&height`에 맞춰 읽습니다.
- `name`에는 `&`가 없고, 숫자에는 `&`가 있습니다.

**자주 하는 실수**

- 형식 지정자와 변수 타입 불일치
- 숫자 변수에서 `&` 누락
- 문자열에 길이 제한 없이 `%s`만 사용

`scanf("%s")`는 공백 전까지만 읽습니다. 공백이 포함된 한 줄은 배열·문자열을 더 배운 뒤 `fgets` 등으로 이어가면 됩니다. 연습할 때는 **숫자와 공백 없는 단어**부터 입력하세요.

이 장 범위는 **`printf`/`scanf` 형식 정리**입니다. 조건에 따라 입력을 다시 받는 법은 **조건문 장**에서 이어집니다.

### 연습문제

**문제 1**

- 문제: 정수 두 개를 입력받아 합·차·곱을 출력하세요.
- 입력: 정수 2개
- 출력: 합, 차, 곱
- 조건: `scanf("%d %d", &a, &b);` 사용

**문제 2**

- 문제: 문자열 하나를 입력받아 `입력값: ...` 형식으로 출력하세요.
- 입력: 공백 없는 문자열 1개
- 출력: `입력값: <문자열>`
- 조건: 버퍼 크기 20이면 `%19s` 사용

**문제 3**

- 문제: 실수 `3.14159`를 소수점 둘째 자리까지 출력하세요.
- 입력: 없음. 변수에 값을 두어도 됨
- 출력: `3.14`
- 조건: `printf("%.2f\n", value);`

### 정답 포인트

- 문제 1: `scanf` 후 `printf`로 `a + b`, `a - b`, `a * b`
- 문제 2: `scanf("%19s", text);` → `printf("입력값: %s\n", text);`
- 문제 3: `%.2f`
- 공통: 숫자에는 `&`, 문자열 배열에는 길이 제한
