# Chapter 02 프로그램의 기본구성

## 학습 목표

- C 프로그램이 `main`의 `{` `}` 안부터 실행된다는 점을 설명할 수 있다.
- `#include <stdio.h>` 덕분에 `printf`를 호출할 수 있다는 흐름을 말할 수 있다.
- `printf`로 문자열을 출력하고, `//` / `/* */` 주석을 쓸 수 있다.

## 본문

### 02-1 `main`과 기본 뼈대

앞 장에서 환경을 맞추고 첫 출력을 확인했습니다. 이 장에서는 그 **뼈대가 왜 그렇게 생겼는지**를 짧게 정리합니다. Visual Studio에서는 `Ctrl + Shift + B` 또는 `Ctrl + B`로 빌드한 뒤 `Ctrl + F5` 또는 `F5`로 실행해 결과를 확인하면 됩니다.

C 프로그램은 실행될 때 **항상 `main`부터** 들어갑니다. 그래서 `main`을 **프로그램의 출발점**이라고 부릅니다. `main`은 **함수**입니다. 함수는 이름 붙인 작업 묶음인데, **지금은 “시작 함수 이름이 `main`이다”** 정도만 기억하면 됩니다. 함수를 직접 여러 개 만드는 법은 **뒤 장**에서 다룹니다.

아래는 글자 출력 없이 끝나는 가장 작은 `main` 예시입니다.

```c
int main(void)
{
    return 0;
}
```

`int`는 이 함수가 정수 결과를 돌려준다는 표시입니다. `{`와 `}`는 이 함수 내용의 범위를 묶습니다. `return 0;`은 정상 종료를 알리는 관례적인 줄입니다. 문장 끝의 `;`는 “여기서 한 지시가 끝난다”는 표시입니다.

화면에 글자를 찍으려면 보통 `printf`를 씁니다. 앞 장과 같이 `#include <stdio.h>`를 맨 위에 둔 뒤, `main` 안에서 호출합니다.

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

**예상 출력**

```text
Hello, World!
```

**코드 해석**

- `#include <stdio.h>`로 표준 입출력 관련 선언을 가져옵니다.
- `printf("Hello, World!\n");`가 콘솔에 문장을 출력합니다.
- `\n`은 줄바꿈입니다.

**자주 하는 실수**

- `return 0` 뒤에 `;`를 빠뜨리면 컴파일 오류가 날 수 있습니다.
- 시작 함수 이름을 `main`이 아닌 다른 이름으로 바꾸면 예제가 통째로 어긋날 수 있습니다.

### 02-2 `#include`와 `printf`

`printf`는 우리가 파일 안에 새로 만든 함수가 아닙니다. **헤더 파일**에 “이런 이름으로 이렇게 호출할 수 있다”는 **선언**이 적혀 있고, `#include`로 그 내용을 소스에 읽어 들입니다.

**`stdio.h`**는 standard input/output과 관련된 헤더입니다. `#include <stdio.h>`가 없으면 컴파일러가 `printf`를 제대로 이해하지 못해 오류가 나는 경우가 많습니다. `#`으로 시작하는 줄의 세부는 전처리기 장에서 다시 정리합니다. 지금은 **출력하려면 이 줄을 둔다**고만 기억하면 됩니다.

정리하면 한 덩어리는 이렇게 읽습니다.

- `#include <stdio.h>` — `printf` 사용에 필요한 선언을 가져온다.
- `int main(void) { ... }` — 프로그램 시작점.
- `printf("...");` — 문자열을 콘솔에 출력한다.
- `return 0;` — 정상 종료.

### 02-3 주석

**주석**은 컴퓨터가 실행하지 않고, **사람이 읽기 위한 메모**입니다. 한 줄 주석은 `//`, 여러 줄 주석은 `/* ... */`를 씁니다. “왜 이렇게 썼는지”를 짧게 남겨 두면 복습할 때 도움이 됩니다.

아래 코드를 실행해 보세요. 주석 줄은 화면에 나오지 않습니다.

```c
#include <stdio.h>

int main(void)
{
    // 한 줄 주석: 아래 문장은 인사말을 출력합니다.
    printf("안녕하세요!\n");

    /*
      여러 줄 주석:
      목적이나 메모를 길게 적을 때 사용합니다.
    */
    return 0;
}
```

**예상 출력**

```text
안녕하세요!
```

**코드 해석**

- `//` 뒤와 `/* ... */` 안은 실행되지 않습니다.
- 실행되는 출력은 `printf` 한 줄뿐입니다.

### 02-4 `printf`로 여러 줄 출력

`printf`는 콘솔에 글자를 출력할 때 가장 기본으로 쓰는 함수입니다. `\n`을 문자열 안에 넣으면 줄을 바꿉니다. 이 장에서는 **고정 문자열과 줄바꿈**에만 집중합니다. 변수 값을 `%d` 같은 형식으로 끼워 넣는 법은 **다음 장**에서 이어집니다.

```c
#include <stdio.h>

int main(void)
{
    printf("안녕하세요.\n");
    printf("C 언어를 시작합니다.\n");
    printf("줄바꿈 연습 중입니다.\n");

    return 0;
}
```

**예상 출력**

```text
안녕하세요.
C 언어를 시작합니다.
줄바꿈 연습 중입니다.
```

**코드 해석**

- 각 `printf`가 한 줄씩 출력합니다. 문자열 끝의 `\n`이 줄바꿈입니다.
- 한 번의 `printf` 안에 `\n`을 여러 개 넣어도 여러 줄이 됩니다.

이 장 범위는 **뼈대 읽기 · `#include` · 주석 · 문자열 출력**입니다. 변수·연산·형식 지정자는 **다음 장**으로 미룹니다.

### 연습문제

**문제 1**

- 문제: `Hello, World!`를 출력하는 프로그램을 작성하세요.
- 입력: 없음
- 출력: `Hello, World!`
- 조건: `#include <stdio.h>`와 `main`을 포함할 것

**문제 2**

- 문제: 한 줄 주석(`//`)과 여러 줄 주석(`/* */`)을 각각 한 번 이상 넣은 소스를 만드세요.
- 입력: 없음
- 출력: 컴파일·실행 가능한 소스
- 조건: 주석 두 종류를 모두 사용

**문제 3**

- 문제: `printf`로 자기소개를 3줄 이상 출력하세요.
- 입력: 없음
- 출력: 자기소개 3줄 이상
- 조건: `\n`으로 줄을 나눌 것

### 정답 포인트

- 문제 1: `#include` + `main` + `printf("Hello, World!\n");`
- 문제 2: `//`와 `/* ... */`를 각각 최소 한 번
- 문제 3: `printf`와 `\n`으로 세 줄 이상
- 공통: 시작 함수 이름은 `main`, 고칠 곳은 `main`의 `{` `}` 안
