# Chapter 03 변수와 연산자

## 학습 목표

- `int`·`float`·`double`·`char` 변수를 **선언·초기화**하고 `printf`로 값을 확인할 수 있다.
- **산술·비교·논리·대입** 연산자를 구분해 계산과 조건식에 쓸 수 있다.
- `scanf`로 정수·실수를 변수에 읽고, `&`가 왜 필요한지 한 줄로 말할 수 있다.

## 본문

### 03-1 변수와 자료형

**변수**는 값을 담는 **이름이 붙은 상자**입니다. **자료형**은 그 상자에 어떤 종류의 값을 넣을지 정합니다. 값을 처음 넣는 것을 **초기화**라고 합니다. 초기화하지 않은 지역 변수를 바로 읽으면 **쓰레기값**이 나올 수 있으므로, 쓰기 전에 값을 넣는 습관이 중요합니다.

| 자료형 | 예시 값 | 한 줄 설명 |
|---|---|---|
| `int` | `-3`, `0`, `120` | 정수 |
| `float` | `3.14f` | 실수 |
| `double` | `3.14` | `float`보다 정밀도가 높은 실수 |
| `char` | `'A'` | 문자 1개 |

바이트 크기 같은 세부는 구현마다 다를 수 있습니다. 확실히 알고 싶을 때는 뒤에서 배우는 `sizeof`로 확인하면 됩니다. `short`·`long`·`unsigned` 등은 **상수·자료형 장**에서 더 정리합니다.

선언은 `int score;` 또는 `int score = 100;`처럼 씁니다. 같은 타입을 여러 개 둘 때는 `int x = 1, y = 2;`처럼 나열할 수 있습니다. 바뀌면 안 되는 값은 `const int MAX_HP = 100;`처럼 `const`로 고정합니다.
변수 이름은 영문·숫자·밑줄(`_`)을 쓰고 **숫자로 시작할 수 없습니다.** `int`, `for`, `return` 같은 **예약어**는 이름으로 쓸 수 없습니다. 의미가 드러나는 이름(`player_hp`, `totalScore`)을 쓰면 읽기 쉽습니다.

**`printf`로 변수 확인하기**

`printf`의 첫 인자에 출력 틀을 적고, `%`로 시작하는 **형식 지정자**를 넣은 뒤, 쉼표 뒤에 **같은 순서**로 변수를 적습니다. 정수는 `%d`, 실수는 `%f`, 문자는 `%c`를 자주 씁니다. 형식과 타입이 어긋나면 출력이 이상해질 수 있습니다.
예제에 나오는 `int main(void)`를 잠시 봅니다. 이름 앞의 `int`는 앞 장과 같이 **결과로 정수를 돌려준다**는 뜻입니다. 괄호 안의 `void`는 **이 함수가 받는 입력(매개변수)이 없다**는 뜻입니다. C에서 `void`는 자리에 따라 뜻이 갈립니다. 이름 앞에 쓰면 “결과 없음”, 괄호 안 `(void)`처럼 쓰면 “매개변수 없음”입니다. 앞 장의 `int main()`과 입문 단계에서는 같은 출발점으로 보면 됩니다. 이 문서의 뒤 예제도 `int main(void)` 형태를 자주 씁니다.

```c
#include <stdio.h>

int main(void)
{
    int age = 20;
    float height = 173.5f;
    char grade = 'A';

    printf("나이: %d\n", age);
    printf("키: %.1f\n", height);
    printf("등급: %c\n", grade);

    return 0;
}
```

**예상 출력**

```text
나이: 20
키: 173.5
등급: A
```

**코드 해석**

- `%d` 자리에 `age`, `%.1f` 자리에 `height`, `%c` 자리에 `grade`가 들어갑니다.
- `%.1f`는 실수를 소수 첫째 자리까지 보여 주는 예입니다.

문자열을 `char name[] = "Kim";`처럼 두고 `%s`로 출력하는 패턴도 있습니다. 배열 세부는 **배열 장**에서 이어집니다. 지금은 “글자 여러 개를 한 이름으로 두고 `%s`로 찍는다” 정도만 보면 됩니다.

### 03-2 산술·비교·대입 연산자

**연산자**는 값과 값을 연결해 새 결과를 만드는 기호입니다. **산술**은 `+ - * / %`, **비교**는 `== != > < >= <=`, **대입**은 `=`와 `+=` 같은 복합 대입입니다.

| 분류 | 연산자 | 용도 | 입문 예 |
|---|---|---|---|
| 산술 | `+ - * / %` | 계산 | `7 / 2`, `7 % 2` |
| 비교 | `== != > < >= <=` | 조건식 | `score >= 60` |
| 대입 | `= += -= *= /=` | 값 저장·갱신 | `score += 10` |

`/`는 **둘 다 정수**이면 소수점이 버려진 **정수 나눗셈**이 됩니다. `%`는 나머지입니다. 비교 결과는 C에서 보통 참이면 `1`, 거짓이면 `0`으로 다룹니다.

**자주 하는 실수:** 같음 비교는 `==`이고, `=`는 대입입니다.
```c
#include <stdio.h>

int main(void)
{
    int a = 7, b = 2;

    printf("합: %d\n", a + b);
    printf("나머지: %d\n", a % b);
    printf("a > b: %d\n", a > b);
    printf("정수 나눗셈: %d\n", a / b);
    printf("실수 나눗셈: %f\n", (double)a / b);

    return 0;
}
```

**예상 출력**

```text
합: 9
나머지: 1
a > b: 1
정수 나눗셈: 3
실수 나눗셈: 3.500000
```

**코드 해석**

- `a / b`는 둘 다 `int`라 `3`입니다.
- `(double)a / b`는 실수 나눗셈이라 `3.5`에 가깝게 나옵니다.
- `a > b`는 참이라 `1`이 출력됩니다.

`++` / `--`는 값을 1 늘리거나 줄입니다. `++a`는 먼저 증가한 뒤 쓰고, `a++`는 쓴 뒤 증가합니다. 입문에서는 **한 줄에 증감을 여러 번 섞지 않는** 편이 안전합니다. 비트 연산·삼항 연산자 `?:`는 필요할 때 뒤에서 더 다룹니다.

### 03-3 논리 연산자

**논리 연산자**는 조건을 결합·반전할 때 씁니다. `&&`는 **양쪽이 모두 참**일 때만 참, `||`는 **하나라도 참**이면 참, `!`는 참/거짓을 **뒤집습니다.**

```c
#include <stdio.h>

int main(void)
{
    int score = 85;
    double attend = 0.9;

    int pass = (score >= 60) && (attend >= 0.8);
    int warn = (score < 60) || (attend < 0.8);

    printf("합격: %d\n", pass);
    printf("경고: %d\n", warn);
    printf("합격 아님: %d\n", !pass);
    return 0;
}
```

**예상 출력**

```text
합격: 1
경고: 0
합격 아님: 0
```

**코드 해석**

- 점수와 출석률 **둘 다** 기준을 넘어야 `pass`가 `1`입니다.
- `!pass`는 합격을 뒤집은 값입니다.

조건을 여러 개 묶을 때는 괄호로 의도를 드러내는 편이 안전합니다.

### 03-4 `scanf`로 입력받기

**`scanf`**는 형식이 정해진 값을 읽어 변수에 넣을 때 씁니다. 숫자형에는 보통 **`&변수`**를 넘깁니다. `&`는 그 변수가 있는 메모리 위치를 가리키는 기호로, “어디에 쓸지”를 `scanf`에 알려 줍니다. 주소·포인터의 세부는 **포인터 장**에서 본격적으로 다룹니다. 지금은 **`scanf("%d", &age);`처럼 `&`를 붙인다**고 기억하면 됩니다.

형식 지정자와 변수 타입을 맞추는 것이 중요합니다. `%d`에는 `int`, `%f`에는 `float`를 짝짓습니다.

```c
#include <stdio.h>

int main(void)
{
    int age;
    float height;

    printf("나이와 키를 입력하세요 (예: 20 173.5): ");
    scanf("%d %f", &age, &height);

    printf("나이: %d, 키: %.1f\n", age, height);
    return 0;
}
```

**예상 출력 (입력 `20 173.5`인 경우)**

```text
나이와 키를 입력하세요 (예: 20 173.5): 20 173.5
나이: 20, 키: 173.5
```

**코드 해석**

- `scanf("%d %f", &age, &height);`가 정수·실수를 각각 읽습니다.
- `printf`로 다시 확인합니다.

`printf`·`scanf`의 형식 지정자를 더 체계적으로 모으는 내용은 **`printf`/`scanf` 정리 장**에서 이어집니다. Windows에서 키 한 글자를 받거나 창이 바로 닫히지 않게 잠시 멈출 때 `getch`를 쓰는 예도 있는데, 표준이 아니라서 **이 과정 본 연습은 `scanf`/`printf`를 우선**합니다.

이 장 범위는 **변수 · 기본 연산 · `scanf` 입문**입니다. 데이터 표현·상수·형식 지정자 심화는 **이후 장**으로 미룹니다.

### 연습문제

**문제 1**

- 문제: `int x = 8, y = 5;`일 때 `x + y`, `x / y`, `x % y`를 각각 출력하세요.
- 입력: 없음
- 출력: `13`, `1`, `3`
- 조건: 정수 나눗셈임을 확인할 것

**문제 2**

- 문제: `int score = 75;`일 때 `score >= 60` 결과를 `%d`로 출력하세요.
- 입력: 없음
- 출력: `1`
- 조건: 비교 연산 사용

**문제 3**

- 문제: 정수 두 개를 입력받아 합을 출력하세요.
- 입력: 정수 2개
- 출력: 합 1개
- 조건: `scanf("%d %d", &a, &b);` 사용

### 정답 포인트

- 문제 1: `printf`로 세 식 결과를 각각 출력. `8 / 5`는 `1`
- 문제 2: `printf("%d\n", score >= 60);`
- 문제 3: `scanf`에 `&`를 붙이고 `a + b`를 출력
- 공통: `=`와 `==`를 혼동하지 말 것
