# Chapter 08 반복문

## 학습 목표

- `while`로 조건 변수 만들기 → 조건 검사 → 본문에서 조건 바꾸기 흐름을 실행으로 확인한다.
- `do-while`과 `while`이 조건을 언제 검사하는지 구분한다.
- `for`가 위 세 단계를 한 줄에 모아 둔 형태임을 이해하고, `break`와 `continue`를 구분해 쓴다.

## 본문

### 08-1 `while`

**반복문**은 같은 작업을 조건이 참인 동안 되풀이하는 구조입니다. **`while`**은 조건을 앞에 두고, 참일 때만 본문을 실행합니다.

보통 세 가지를 따로 적습니다. 조건에 쓸 변수를 만들고, `while`로 검사하고, 본문에서 그 변수를 바꿔 언젠가 거짓이 되게 합니다. 본문에서 변수를 안 바꾸면 **무한 루프**입니다.

```c
#include <stdio.h>

int main(void)
{
    int n = 5;
    printf("while 카운트다운: ");
    while (n > 0)
    {
        printf("%d ", n);
        n--;
    }
    printf("\n");
    return 0;
}
```

**예상 출력**

```text
while 카운트다운: 5 4 3 2 1
```

**코드 해석**

- `n`을 만든 뒤 `n > 0`이 참인 동안만 출력합니다.
- 매 회차 `n--`로 조건을 거짓으로 만듭니다.

### 08-2 `do-while`

**`do-while`**은 본문을 **먼저** 한 번 실행한 뒤 조건을 봅니다. `while`은 조건이 처음부터 거짓이면 0회입니다. `do-while`은 최소 1회입니다. 끝은 `while (조건);`처럼 **세미콜론**이 붙습니다.

```c
#include <stdio.h>

int main(void)
{
    int menu = 0;

    do
    {
        printf("메뉴: 1. 시작  2. 종료\n");
        printf("입력: ");
        scanf("%d", &menu);
    } while (menu != 2);

    printf("프로그램 종료\n");
    return 0;
}
```

**예상 출력** — 입력 `1` 다음 `2`

```text
메뉴: 1. 시작  2. 종료
입력: 1
메뉴: 1. 시작  2. 종료
입력: 2
프로그램 종료
```

**코드 해석**

- `do` 블록이 먼저 실행된 뒤 `while (menu != 2)`로 계속 여부를 봅니다.

| | `while` | `do-while` |
|---|---|---|
| 순서 | 조건 → 본문 | 본문 → 조건 |
| 최소 실행 | 0회 가능 | 최소 1회 |

### 08-3 `for`

`while`의 세 단계인 변수 만들기·검사·변화를 **`for (초기; 조건; 증감)`** 한곳에 모은 형태입니다. 횟수·범위가 분명할 때 읽기 쉽습니다.

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    int i;

    for (i = 1; i <= 5; i++)
    {
        sum += i;
    }
    printf("1~5 합: %d\n", sum);
    return 0;
}
```

**예상 출력**

```text
1~5 합: 15
```

**코드 해석**

- `i`를 1로 만들고, `i <= 5`인 동안 돌며, 매 회차 끝에 `i++`합니다.
- `sum`에 1부터 5까지 더합니다.

| 방식 | 적합한 상황 | 주의점 |
|---|---|---|
| `while` | 끝이 입력·상태에 달릴 때 | 조건 갱신 누락 |
| `do-while` | 최소 1회 필요 | 끝 `;` |
| `for` | 횟수·범위가 분명할 때 | 세 칸 실수 |

### 08-4 `break`와 `continue`

**`continue`**는 이번 회차 나머지를 건너뛰고 다음 반복으로 갑니다. **`break`**는 반복 자체를 즉시 끝냅니다. 앞 장 `switch`의 `break`는 `switch`를 나가는 뜻이라, **루프인지 `switch`인지** 문맥을 먼저 봅니다.

```c
#include <stdio.h>

int main(void)
{
    int i;
    for (i = 1; i <= 10; i++)
    {
        if (i % 3 == 0)
        {
            continue;
        }
        if (i >= 8)
        {
            break;
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

**예상 출력**

```text
1 2 4 5 7
```

**코드 해석**

- `3`, `6`은 `continue`로 출력하지 않습니다.
- `8`에서 `break`로 끝나 `8` 이후는 나오지 않습니다.

이 장 범위는 **반복**입니다. 배열 순회는 **다음 장**에서 이어집니다.

### 연습문제

**문제 1**

- 문제: 정수 `n`을 입력받아 `while`로 `n`부터 1까지 카운트다운하세요.
- 입력: 정수 1개. 예: `4`
- 출력: `4 3 2 1` 형태
- 조건: `while`. 변수·검사·감소를 모두 둘 것

**문제 2**

- 문제: `do-while`로 메뉴를 한 번 이상 보여 주고 `3`을 입력하면 종료하세요.
- 입력: 메뉴 번호 여러 번
- 출력: 매 회차 메뉴 안내 후 `프로그램 종료`
- 조건: `do-while`. 끝 `while (조건);`

**문제 3**

- 문제: 단을 2~9로 입력받아 해당 구구단을 `for`로 출력하세요.
- 입력: 정수 1개. 예: `3`
- 출력: `3 x 1 = 3` … `3 x 9 = 27`
- 조건: `for` 사용

### 정답 포인트

- 문제 1: `while (n > 0) { printf("%d ", n); n--; }`
- 문제 2: `do { ... } while (menu != 3);`
- 문제 3: `for (i = 1; i <= 9; i++)` 안에서 곱셈식 출력
- 공통: `while` 세 단계와 `for` 한 줄이 같은 역할인지 먼저 짚기
