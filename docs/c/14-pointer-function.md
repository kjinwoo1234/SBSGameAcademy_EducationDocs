# Chapter 14 포인터와 함수

## 학습 목표

- 함수 인자로 배열을 넘기면 시작 주소가 전달됨을 이해한다.
- 값 전달과 주소 전달을 구분해, 원본을 바꾸는 `swap`을 작성한다.
- 읽기만 하는 배열 인자에 `const`를 붙여 의도를 드러낸다.

## 본문

### 14-1 함수 인자로 배열 전달

C에서 배열 이름을 함수 인자로 넘기면 **첫 원소의 주소**가 전달됩니다. 함수 안에서는 호출 쪽 배열의 칸 개수를 자동으로 알 수 없는 경우가 많습니다. 그래서 **시작 주소와 길이를 함께** 넘기는 패턴이 안전합니다. 매개변수는 `int arr[]` 또는 `int *arr`처럼 쓰고, 길이는 `int n`으로 받습니다.

아래를 실행해 함수가 배열 합을 계산하는지 확인해 보세요.

```c
#include <stdio.h>

int sum_array(int arr[], int n)
{
    int i;
    int sum = 0;

    for (i = 0; i < n; i++)
    {
        sum += arr[i];
    }
    return sum;
}

int main(void)
{
    int nums[3] = {1, 2, 3};

    printf("%d\n", sum_array(nums, 3));
    return 0;
}
```

**예상 출력**

```text
6
```

**코드 해석**

- `sum_array(nums, 3)`은 시작 주소와 길이 `3`을 넘깁니다.
- 함수 안 `arr[i]`는 호출 쪽 `nums`의 같은 칸을 가리킵니다.
- 길이 `n`을 넘기지 않으면 어디까지 돌지 알 수 없습니다.

### 14-2 값 전달과 주소 전달

C의 기본 인자 전달은 **값 복사**입니다. 함수 안에서 매개변수 `x`를 바꿔도 호출 쪽 변수는 그대로인 경우가 많습니다. 원본을 바꾸려면 **주소를 넘겨** 같은 메모리를 가리키게 합니다. `swap`은 `int *a`, `int *b`를 받아 `*a`와 `*b`를 교환합니다. 호출은 `swap(&x, &y);`입니다.

| 방식 | 인자 형태 | 원본 변경 |
|---|---|---|
| 값 전달 | `int x` | 불가 |
| 주소 전달 | `int *x` | 가능 |

| 용어 | 의미 |
|---|---|
| 값 전달 | 복사본을 넘김. 원본 변수는 직접 바뀌지 않음 |
| 주소 전달 | 주소를 넘겨 같은 칸을 읽고 씀 |

아래를 실행해 `swap` 뒤 `x`와 `y`가 바뀌는지 확인해 보세요.

```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 3;
    int y = 7;

    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}
```

**예상 출력**

```text
7 3
```

**코드 해석**

- `swap(&x, &y)`는 `x`와 `y`의 주소를 넘깁니다.
- `*a`와 `*b`를 바꾸면 호출 쪽 `x`, `y`가 바뀝니다.
- `temp`는 교환용 임시 변수입니다.

### 14-3 포인터 대상 `const`

`const int *arr`처럼 쓰면 “이 포인터로 가리키는 **값을 바꾸지 않겠다**”는 약속에 가깝습니다. 합·평균처럼 읽기만 하는 함수에 붙이면, 실수로 `arr[i] = ...`를 넣는 것을 컴파일 단계에서 막기 쉽습니다. 원본을 바꾸는 함수에는 `const`를 붙이지 않습니다.

아래를 실행해 `const` 배열 인자로 합을 구하는지 확인해 보세요.

```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int sum_array(const int *arr, int n)
{
    int i;
    int sum = 0;

    for (i = 0; i < n; i++)
    {
        sum += arr[i];
    }
    return sum;
}

int main(void)
{
    int x = 3;
    int y = 7;
    int nums[3] = {1, 2, 3};

    swap(&x, &y);
    printf("%d %d\n", x, y);
    printf("sum: %d\n", sum_array(nums, 3));
    return 0;
}
```

**예상 출력**

```text
7 3
sum: 6
```

**코드 해석**

- `swap`은 주소를 받아 원본을 바꿉니다.
- `sum_array`의 `const int *arr`는 읽기 전용 의도를 드러냅니다.
- `nums`를 넘겨도 합만 계산하고 칸 값은 바꾸지 않습니다.

### 연습문제

**문제 1**
- 문제: 정수 두 개를 입력받아 작은 값이 앞, 큰 값이 뒤에 오도록 맞추는 함수를 만드세요.
- 입력: 정수 2개. 예: `9 4`
- 출력: `4 9`
- 조건: 함수 인자는 `int *a`, `int *b`. 필요하면 값을 교환

**문제 2**
- 문제: 배열과 길이를 받아 평균을 `double`로 반환하는 함수를 작성하세요.
- 입력: 길이 `n`과 정수 `n`개. 예: `n = 4`, 값 `80 90 70 100`
- 출력: `85.00`처럼 소수 둘째 자리까지. `printf("%.2f\n", ...)` 사용
- 조건: 매개변수는 `const int *arr`, `int n`. `n`이 `0`이면 `0.0` 반환

**문제 3**
- 문제: 배열과 길이를 받아 최댓값을 찾아 반환하는 함수를 작성하세요.
- 입력: 없음. 예로 `{3, 9, 2, 7}`와 길이 `4`
- 출력: `9`
- 조건: `const int *arr`, `int n` 사용. `n`은 `1` 이상으로 가정해도 됩니다

### 정답 포인트

- 문제 1: `if (*a > *b) { int t = *a; *a = *b; *b = t; }`
- 문제 2: 합을 구한 뒤 `(double)sum / n`. `n == 0`이면 바로 `0.0`
- 문제 3: `max = arr[0]`으로 시작한 뒤 나머지와 비교해 갱신
- 공통: 원본 변경은 포인터, 배열 함수는 **시작 주소 + 길이**, 읽기만이면 `const`
