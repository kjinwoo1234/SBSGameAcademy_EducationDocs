# Chapter 13 포인터와 배열

## 학습 목표

- 배열 이름과 첫 원소 주소의 관계를 문장으로 설명한다.
- 포인터 연산으로 배열 칸을 이동하며 `*(p + i)`와 `p[i]`가 같음을 확인한다.
- 문자열 리터럴을 `const char *`로 다루는 이유를 이해한다.
- 포인터 배열로 여러 문자열 시작 주소를 묶어 출력한다.

## 본문

### 13-1 배열 이름과 첫 원소 주소

**배열 이름**은 대부분의 식에서 **첫 번째 원소의 주소**로 읽힙니다. `int arr[3]`이 있으면 `arr`와 `&arr[0]`은 같은 위치를 가리키는 경우가 많습니다. 그래서 `int *p = arr;`처럼 쓰면 `p`가 첫 칸을 가리킵니다. 배열 전체를 통째로 복사하는 값이 아니라, **시작 위치**를 넘긴다고 생각하면 다음 장의 함수 인자와도 이어집니다.

| 표현 | 의미 |
|---|---|
| `arr` | 대부분의 식에서 첫 원소 주소 |
| `&arr[0]` | 첫 원소의 주소. `arr`와 같은 위치 |
| `arr[i]` | `i`번째 칸의 값 |

아래를 실행해 `arr`와 `&arr[0]`이 같은지, `p`로도 첫 값을 읽는지 확인해 보세요. 주소 숫자는 실행마다 다를 수 있습니다.

```c
#include <stdio.h>

int main(void)
{
    int arr[3] = {10, 20, 30};
    int *p = arr;

    printf("같은 주소인가: %d\n", (arr == &arr[0]));
    printf("첫 값 arr[0]: %d\n", arr[0]);
    printf("첫 값 *p   : %d\n", *p);
    return 0;
}
```

**예상 출력**

```text
같은 주소인가: 1
첫 값 arr[0]: 10
첫 값 *p   : 10
```

**코드 해석**

- `int *p = arr;`는 `p`가 `arr[0]`을 가리키게 합니다.
- `arr == &arr[0]`이 참이면 `1`이 출력됩니다.
- `*p`와 `arr[0]`은 같은 `10`입니다.

### 13-2 포인터 연산과 칸 이동

`p + 1`은 메모리에서 1바이트만 가는 것이 아닙니다. 포인터가 가리키는 **타입 크기만큼** 한 칸 이동합니다. `int *`이면 보통 `int` 한 개 크기만큼, `char *`이면 1바이트만큼 건너뜁니다. `*(p + i)`는 `p`에서 `i`칸 떨어진 곳의 값이고, `p[i]`와 **같은 의미**로 씁니다.

| 표현 | 의미 |
|---|---|
| `p + i` | `p`에서 `i`칸 앞 주소 |
| `*(p + i)` | 그 칸의 값 |
| `p[i]` | `*(p + i)`와 동일 |

아래를 실행해 인덱스 표기와 포인터 연산 표기가 같은 값을 내는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int arr[3] = {10, 20, 30};
    int *p = arr;
    int i;

    for (i = 0; i < 3; i++)
    {
        printf("%d %d\n", arr[i], *(p + i));
    }
    return 0;
}
```

**예상 출력**

```text
10 10
20 20
30 30
```

**코드 해석**

- `arr[i]`와 `*(p + i)`가 같은 줄을 출력합니다.
- `p`는 첫 칸에서 시작해 `i`만큼 칸을 이동합니다.
- 유효 인덱스는 `0`부터 `2`까지입니다. `i < 3` 조건을 지킵니다.

### 13-3 문자열 리터럴과 `const char *`

코드에 직접 적은 `"Hello"` 같은 값을 **문자열 리터럴**이라고 합니다. 이 내용은 읽기 전용 영역에 놓일 수 있어, 글자를 바꾸면 위험합니다. `const char *msg = "Hello";`처럼 쓰면 “이 포인터로 **내용을 바꾸지 않겠다**”는 의도가 타입에 드러납니다. 내용을 바꿔야 하면 `char buf[] = "Hello";`처럼 **복사본 배열**을 쓰는 쪽이 안전합니다.

| 용어 | 의미 |
|---|---|
| 문자열 리터럴 | 코드에 직접 적은 `"..."` 문자열 |
| `const char *` | 가리키는 `char`를 바꾸지 않겠다는 포인터 |

아래를 실행해 리터럴을 포인터로 가리켜 출력해 보세요. 리터럴 내용을 대입으로 수정하는 코드는 넣지 마세요.

```c
#include <stdio.h>

int main(void)
{
    const char *msg = "Hello";

    printf("%s\n", msg);
    printf("첫 글자: %c\n", msg[0]);
    return 0;
}
```

**예상 출력**

```text
Hello
첫 글자: H
```

**코드 해석**

- `msg`는 `"Hello"`의 시작 주소를 담습니다.
- `%s`는 널 문자까지 문자열을 출력합니다.
- `msg[0]`은 첫 글자 `H`입니다. `*(msg + 0)`과 같습니다.

### 13-4 포인터 배열

**포인터 배열**은 포인터를 여러 칸에 담는 배열입니다. `const char *names[3]`은 문자열 시작 주소 세 개를 한곳에 모읍니다. 각 칸은 서로 다른 문자열을 가리킬 수 있고, `names[i]`로 `i`번째 문자열을 출력합니다.

아래를 실행해 이름 세 개가 한 줄에 나오는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int arr[3] = {10, 20, 30};
    int *p = arr;
    const char *names[3] = {"Kim", "Lee", "Park"};
    int i;

    printf("%d %d %d\n", p[0], *(p + 1), *(p + 2));

    for (i = 0; i < 3; i++)
    {
        printf("%s", names[i]);
        if (i < 2)
        {
            printf(" ");
        }
    }
    printf("\n");
    return 0;
}
```

**예상 출력**

```text
10 20 30
Kim Lee Park
```

**코드 해석**

- `p[0]`, `*(p + 1)`, `*(p + 2)`로 정수 배열을 포인터로 읽습니다.
- `names[i]`는 `i`번째 문자열의 시작 주소입니다.
- 포인터 배열은 “주소들의 목록”이지, 문자 전체를 한 배열에 붙인 것이 아닙니다.

### 연습문제

**문제 1**
- 문제: 정수 배열을 만들고, 인덱스 `arr[i]` 대신 포인터 연산 `*(p + i)`만으로 합계를 구하세요.
- 입력: 없음. 예로 `arr`가 `2 5 8 1`일 때
- 출력: `16`
- 조건: 합 루프 안에서 `arr[i]` 표기 금지. `*(p + i)`만 사용

**문제 2**
- 문제: 문자열 세 개를 포인터 배열에 넣고, 인덱스가 큰 쪽부터 역순으로 한 줄씩 출력하세요.
- 입력: 없음. 예로 `"red"`, `"green"`, `"blue"`
- 출력:
  ```text
  blue
  green
  red
  ```
- 조건: `const char *names[3]` 사용. 역순은 인덱스만 뒤집기

**문제 3**
- 문제: 포인터 `p`를 배열 시작에 두고, `p`를 한 칸씩 증가시키며 모든 원소를 출력하세요.
- 입력: 없음. 예로 `{4, 9, 1}`
- 출력: `4 9 1`
- 조건: 루프에서 `p++` 또는 `p = p + 1`로 이동. `arr[i]`로 출력하지 말 것

### 정답 포인트

- 문제 1: `int *p = arr;` 후 `sum += *(p + i);`
- 문제 2: `for (i = 2; i >= 0; i--) printf("%s\n", names[i]);`
- 문제 3: `p`가 마지막을 지나지 않게 횟수 또는 끝 주소와 비교
- 공통: `p[i]`와 `*(p + i)`는 같고, 문자열 리터럴은 `const char *`로 읽기만
