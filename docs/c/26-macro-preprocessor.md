# Chapter 26 매크로와 전처리기

## 학습 목표

- 전처리 단계가 컴파일 전에 소스를 어떻게 바꾸는지 이해한다.
- `#define` 객체형·함수형 매크로와 괄호 규칙을 익힌다.
- `#ifdef` 등 조건부 컴파일과 `#`, `##`의 역할을 안다.

## 본문

### 26-1 전처리기란

**전처리기**는 본격적인 컴파일 전에 소스 텍스트를 한 번 손봅니다. `#`로 시작하는 줄이 지시문입니다. `#include`는 다른 파일 내용을 그 자리에 붙여 넣고, `#define`은 이름을 정해 둔 텍스트로 바꿉니다. 이 단계가 끝난 뒤 컴파일러가 본 코드를 읽습니다.

매크로는 타이핑을 줄이거나, 빌드 옵션에 따라 코드를 켜고 끌 때 씁니다. 다만 함수와 달리 **타입 검사**가 약하고, 인자 부작용에 취약할 수 있어 규칙을 지켜야 합니다.

| 용어 | 의미 |
|---|---|
| 전처리기 | 컴파일 전 소스 변환 단계 |
| 지시문 | `#`로 시작하는 전처리 명령 |
| 매크로 | `#define`으로 정의한 치환 규칙 |

### 26-2 `#define` 객체형과 함수형

**객체형**은 `PI`처럼 이름만 바꿔 둡니다. `#define PI 3.14`이면 코드의 `PI`가 `3.14`로 치환됩니다. **함수형**은 인자를 받습니다. `#define SQUARE(x) ((x) * (x))`처럼 씁니다.

안전한 습관은 **인자마다 괄호**, **식 전체에도 괄호**입니다. `#define SQUARE(x) x * x`만 쓰면 `SQUARE(1 + 2)`가 `1 + 2 * 1 + 2`로 깨질 수 있습니다. 또한 `SQUARE(n++)`처럼 부작용이 있는 식을 넘기면 `n++`가 두 번 평가될 수 있습니다. 그런 경우 함수가 더 안전합니다.

`#undef`는 매크로 정의를 없앱니다.

| 형태 | 예 |
|---|---|
| 객체형 | `#define MAX_N 100` |
| 함수형 | `#define MAX(a, b) ((a) > (b) ? (a) : (b))` |

아래를 실행해 `16`과 로그 한 줄이 나오는지 확인해 보세요.

```c
#include <stdio.h>

#define SQUARE(x) ((x) * (x))
#define LOG(msg) printf("[LOG] %s\n", msg)

int main(void)
{
    int n = 4;

    printf("%d\n", SQUARE(n));
    LOG("start");
    return 0;
}
```

**예상 출력**

```text
16
[LOG] start
```

**코드 해석**

- `SQUARE(n)`은 `((n) * (n))`으로 바뀌어 `16`입니다.
- `LOG("start")`는 `printf` 호출로 치환됩니다.
- 인자와 식에 괄호가 있어 `SQUARE(1 + 2)`도 `9`가 됩니다.

### 26-3 대표 지시문

`#include <stdio.h>`는 시스템 헤더 경로에서 찾고, `#include "my.h"`는 보통 현재 프로젝트 쪽을 먼저 찾습니다. `#pragma`는 컴파일러에 힌트를 줍니다. 종류는 환경마다 다릅니다. 입문에서는 include와 define·조건부 컴파일을 우선합니다.

| 지시문 | 역할 |
|---|---|
| `#include` | 헤더 포함 |
| `#define` / `#undef` | 매크로 정의·해제 |
| `#pragma` | 컴파일러 지시 |

### 26-4 조건부 컴파일

`#if`, `#ifdef`, `#ifndef`, `#else`, `#elif`, `#endif`는 **조건에 맞는 줄만** 남깁니다. `#ifdef DEBUG`는 `DEBUG` 매크로가 정의되어 있을 때만 안쪽을 컴파일합니다. 디버그 로그를 켜고 끄는 데 자주 씁니다.

정의는 코드에 `#define DEBUG`를 두거나, 컴파일 옵션으로 넣는 방법이 있습니다. 이 교재 예제는 소스 안에 `#define`을 두는 방식으로 확인합니다.

| 지시문 | 의미 |
|---|---|
| `#ifdef NAME` | `NAME`이 정의됨 |
| `#ifndef NAME` | `NAME`이 정의되지 않음 |
| `#if 식` | 전처리 상수식 |

아래를 실행해 디버그 로그가 출력되는지 확인해 보세요.

```c
#include <stdio.h>

#define DEBUG

int main(void)
{
    printf("run\n");
#ifdef DEBUG
    printf("debug on\n");
#endif
    return 0;
}
```

**예상 출력**

```text
run
debug on
```

**코드 해석**

- `#define DEBUG`가 있으므로 `#ifdef DEBUG` 안이 살아 남습니다.
- `#define DEBUG` 줄을 지우면 `debug on`은 컴파일되지 않아 출력도 없습니다.
- `run`은 조건 밖이라 항상 나옵니다.

### 26-5 문자열화 `#`와 토큰 결합 `##`

함수형 매크로에서 **`#인자`**는 그 인자를 **문자열 리터럴**로 바꿉니다. `#define STR(x) #x`이면 `STR(hello)`가 `"hello"`가 됩니다. **`##`**는 두 토큰을 붙여 새 이름을 만듭니다. 변수 이름이나 식별자를 기계적으로 조합할 때 씁니다.

남용하면 읽기 어렵습니다. 필요할 때만 쓰고, 가능하면 일반 함수·변수로 충분한지 먼저 봅니다.

| 연산 | 역할 |
|---|---|
| `#` | 인자를 문자열로 |
| `##` | 토큰 이어 붙이기 |

아래를 실행해 문자열화된 이름이 출력되는지 확인해 보세요.

```c
#include <stdio.h>

#define STR(x) #x

int main(void)
{
    printf("%s\n", STR(player_hp));
    return 0;
}
```

**예상 출력**

```text
player_hp
```

**코드 해석**

- `STR(player_hp)`는 `"player_hp"`로 바뀝니다.
- 인자를 코드에 쓰이지 않고 문자열로만 씁니다.
- 디버그 메시지에 이름 붙일 때 응용할 수 있습니다.

### 연습문제

**문제 1**
- 문제: 두 수 중 큰 값을 고르는 `MAX(a, b)` 매크로를 만들고, 입력 두 정수 중 큰 값을 출력하세요.
- 입력: 정수 2개. 예: `3 9`
- 출력: `9`
- 조건: 인자·식 전체에 괄호. 삼항 연산 사용 가능

**문제 2**
- 문제: `#ifdef DEBUG`로만 동작하는 `DLOG(msg)` 매크로를 만드세요. `DEBUG`가 정의되어 있으면 `[D] ` 접두와 메시지를 출력하고, 없으면 아무 일도 하지 않습니다.
- 입력: 없음. 소스에 `#define DEBUG`를 둔 상태로 테스트
- 출력: `[D] hello` 형태 한 줄
- 조건: `DEBUG`를 주석 처리하면 해당 출력이 컴파일되지 않아야 함

**문제 3**
- 문제: `SQUARE(x)` 매크로로 `SQUARE(2 + 3)` 결과가 `25`가 되게 정의하고 출력하세요.
- 입력: 없음
- 출력: `25`
- 조건: 괄호 규칙 준수. `x * x`만 두고 괄호를 빼면 안 됨

### 정답 포인트

- 문제 1: `#define MAX(a, b) ((a) > (b) ? (a) : (b))`
- 문제 2: `#ifdef DEBUG` … `#define DLOG(msg) printf("[D] %s\n", msg)` … `#else` … `#define DLOG(msg)` … `#endif`
- 문제 3: `#define SQUARE(x) ((x) * (x))` → `SQUARE(2 + 3)`는 `25`
- 공통: 매크로는 치환. 부작용 있는 인자·괄호 누락에 주의
