# Chapter 17 포인터의 포인터

## 학습 목표

- 이중 포인터 `type **`가 “포인터를 가리키는 포인터”임을 설명한다.
- 함수에서 포인터 변수 자체를 바꿀 때 `type **`와 `&포인터`가 필요함을 확인한다.
- `p`, `*pp`, `**pp` 표현을 표로 구분한다.

## 본문

### 17-1 이중 포인터란

**이중 포인터**는 `int **pp`처럼 쓰며, 포인터를 가리키는 포인터입니다. `int *p`가 `int` 값의 주소를 담는다면, `int **pp`는 **`p`라는 포인터 변수의 주소**를 담습니다. 값에 한 번 더 간접적으로 손대야 할 때, 접근 단계가 한 층 더 필요할 때 등장합니다.
| 표현 | 의미 |
|---|---|
| `p` | 실제 데이터 쪽을 가리키는 포인터 변수 |
| `*pp` | `pp`가 가리키는 포인터. 곧 `p`와 같은 역할 |
| `**pp` | 그 포인터가 가리키는 실제 데이터 값 |

아래를 실행해 `pp`를 통해 `num` 값을 읽는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int num = 10;
    int *p = &num;
    int **pp = &p;

    printf("%d\n", num);
    printf("%d\n", *p);
    printf("%d\n", **pp);
    return 0;
}
```

**예상 출력**

```text
10
10
10
```

**코드 해석**

- `p`는 `num`의 주소입니다.
- `pp`는 `p`의 주소입니다.
- `**pp`는 `p`가 가리키는 `num`의 값 `10`입니다.

### 17-2 함수에서 포인터 변수 바꾸기

함수 안에서 **포인터 변수 자체**를 다른 주소로 바꾸고 싶을 때 이중 포인터가 필요합니다. 인자로 `int *p`만 받으면, 함수 안에서의 `p`는 복사본이라 호출 쪽 포인터 변수는 바뀌지 않습니다. 호출 쪽 `p`를 바꾸려면 `int **pp`로 받아 `*pp = 새주소;`처럼 씁니다. 호출은 `change(&p);`입니다.

문자열을 가리키는 포인터를 다른 리터럴로 바꿀 때도 같은 패턴입니다.

아래를 실행해 함수 호출 뒤 `msg`가 가리키는 문자열이 바뀌는지 확인해 보세요.

```c
#include <stdio.h>

void change_text(const char **p)
{
    *p = "Changed";
}

int main(void)
{
    const char *msg = "Original";

    printf("%s\n", msg);
    change_text(&msg);
    printf("%s\n", msg);
    return 0;
}
```

**예상 출력**

```text
Original
Changed
```

**코드 해석**

- `change_text(&msg)`는 `msg` 포인터 변수의 주소를 넘깁니다.
- 함수 안 `*p = "Changed";`는 호출 쪽 `msg`가 가리키는 대상을 바꿉니다.
- 문자열 내용 글자를 수정한 것이 아니라, **가리키는 위치**를 바꾼 것입니다.

### 17-3 배열 시작 주소를 포인터에 다시 넣기

정수 배열 두 개가 있을 때, 포인터 `p`가 처음에는 첫 배열을 가리키다가 함수에서 둘째 배열 시작으로 바뀌게 할 수 있습니다. 이때도 `int **pp`로 `*pp = arr2;`처럼 포인터 변수를 갱신합니다.

아래를 실행해 호출 전후 `*p`가 달라지는지 확인해 보세요.

```c
#include <stdio.h>

void retarget(int **pp, int *next)
{
    *pp = next;
}

int main(void)
{
    int a[3] = {1, 2, 3};
    int b[3] = {7, 8, 9};
    int *p = a;

    printf("전: %d\n", *p);
    retarget(&p, b);
    printf("후: %d\n", *p);
    return 0;
}
```

**예상 출력**

```text
전: 1
후: 7
```

**코드 해석**

- 처음 `p`는 `a[0]`을 가리키므로 `*p`는 `1`입니다.
- `retarget(&p, b)` 뒤 `p`는 `b[0]`을 가리키므로 `*p`는 `7`입니다.
- `*pp = next;`가 호출 쪽 포인터 변수를 바꿉니다.

### 연습문제

**문제 1**
- 문제: `int *p`를 함수 안에서 다른 배열의 시작 주소로 바꾸세요.
- 입력: 없음. 예로 `a = {1, 2}`, `b = {9, 8}`, 처음 `p = a`
- 출력:
  ```text
  1
  9
  ```
- 조건: 함수 인자는 `int **pp`. 함수에서 `*pp`를 새 주소로 변경

**문제 2**
- 문제: 문자열 포인터를 함수에서 `"Before"`에서 `"After"`로 바꾸세요.
- 입력: 없음
- 출력:
  ```text
  Before
  After
  ```
- 조건: 호출 시 `&포인터변수` 전달. 함수 내부에서 `*p` 변경. `const char *` 사용

**문제 3**
- 문제: `int num`과 `int *p`, `int **pp`를 연결한 뒤, `**pp`로 `num`을 `100`으로 바꾸세요.
- 입력: 없음. 처음 `num = 1`
- 출력: `100`
- 조건: `num`에 직접 대입하지 말고 `**pp`만 사용

### 정답 포인트

- 문제 1: `void f(int **pp) { *pp = b; }` 후 `f(&p);`
- 문제 2: `void f(const char **p) { *p = "After"; }`
- 문제 3: `p = &num; pp = &p; **pp = 100;`
- 공통: 포인터 **변수 자체**를 바꾸려면 `type **`와 `&포인터변수`
