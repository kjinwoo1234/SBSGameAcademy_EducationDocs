# Chapter 19 함수 포인터와 `void` 포인터

## 학습 목표

- 함수 포인터를 선언·배열에 담고 호출한다.
- `void *`가 주소를 담는 범용 포인터임을 이해하고, 사용 전 구체 타입으로 되돌린다.
- `main`의 `argc`, `argv`로 실행 인자를 읽는다.

## 본문

### 19-1 함수 포인터

**함수 포인터**는 함수가 있는 위치를 저장하는 포인터입니다. 선언은 `반환형 (*이름)(매개변수 타입)` 형태입니다. 예로 `int (*fp)(int, int);`는 정수 두 개를 받아 정수를 돌려주는 함수를 가리킬 수 있습니다. `fp = add;`처럼 함수 이름을 넣고, `fp(7, 3)`처럼 호출합니다. 메뉴 번호에 따라 다른 함수를 고르거나, 나중에 호출해 달라고 함수를 넘길 때 씁니다. 이렇게 넘겨 두었다가 필요할 때 대신 호출하는 방식을 **콜백**이라고 부릅니다.

함수 포인터를 배열에 담으면 `op[0]`, `op[1]`처럼 고를 수 있습니다.

| 항목 | 의미 |
|---|---|
| 함수 포인터 | 함수 주소를 저장하는 포인터 |
| 콜백 | 넘겨 둔 함수를 필요한 시점에 대신 호출하는 방식 |

아래를 실행해 덧셈·뺄셈을 함수 포인터 배열로 호출해 보세요.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int sub(int a, int b)
{
    return a - b;
}

int main(void)
{
    int (*op[2])(int, int) = {add, sub};

    printf("add: %d\n", op[0](7, 3));
    printf("sub: %d\n", op[1](7, 3));
    return 0;
}
```

**예상 출력**

```text
add: 10
sub: 4
```

**코드 해석**

- `op[0]`은 `add`, `op[1]`은 `sub`를 가리킵니다.
- `op[0](7, 3)`은 `add(7, 3)`과 같아 `10`입니다.
- `op[1](7, 3)`은 `4`입니다.

### 19-2 `void` 포인터

**`void *`**는 타입을 특정하지 않고 **주소만** 담는 범용 포인터입니다. 어떤 객체의 주소든 넣을 수 있지만, 그 자체로는 `*vp`처럼 값을 바로 읽지 않습니다. 실제로 쓰려면 `(int *)vp`처럼 **구체 타입 포인터로 변환**한 뒤 역참조합니다. 지금은 “주소 상자”와 “쓰기 전에 타입을 되살린다”는 두 문장만 확실히 합니다. 잘못된 타입으로 되돌리면 위험하므로, 넣은 타입과 꺼내는 타입을 맞춥니다.

| 항목 | 의미 |
|---|---|
| `void *` | 타입 정보 없이 주소만 담는 포인터 |
| 타입 변환 | 사용 전에 `int *` 등으로 되돌리는 것 |

아래를 실행해 `void *`에 `int` 주소를 넣었다가 다시 읽는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int num = 42;
    void *vp = &num;
    int *ip = (int *)vp;

    printf("%d\n", *ip);
    return 0;
}
```

**예상 출력**

```text
42
```

**코드 해석**

- `vp`는 `num`의 주소를 타입 없이 담습니다.
- `(int *)vp`로 `int *`를 만든 뒤 `*ip`로 값을 읽습니다.
- `void *`만으로는 `*vp`처럼 쓰지 않습니다.

### 19-3 `main`의 `argc`와 `argv`

`main`을 `int main(int argc, char *argv[])` 형태로 쓰면, 프로그램을 실행할 때 함께 넘긴 문자열 인자를 받을 수 있습니다. **`argc`**는 인자 개수이고, **`argv`**는 그 문자열들을 가리키는 포인터 배열입니다. `argv[0]`은 보통 프로그램 이름 쪽이고, `argv[1]`부터가 사용자가 추가로 넣은 인자입니다. 인자 없이 실행하면 `argc`는 `1`인 경우가 많습니다.

| 항목 | 의미 |
|---|---|
| `argc` | 실행 인자 개수 |
| `argv` | 인자 문자열을 가리키는 포인터 배열 |
| `argv[0]` | 프로그램 이름에 해당하는 문자열인 경우가 많음 |

아래를 실행해 `argc`만 확인합니다. 인자를 더 넣어 실행하면 숫자가 커집니다.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int sub(int a, int b)
{
    return a - b;
}

int main(int argc, char *argv[])
{
    int (*op[2])(int, int) = {add, sub};

    printf("add: %d\n", op[0](7, 3));
    printf("sub: %d\n", op[1](7, 3));
    printf("argc: %d\n", argc);

    if (argc > 1)
    {
        printf("argv[1]: %s\n", argv[1]);
    }
    return 0;
}
```

**예상 출력** — 인자 없이 실행할 때

```text
add: 10
sub: 4
argc: 1
```

**코드 해석**

- 함수 포인터 배열로 연산을 고릅니다.
- 인자 없이 실행하면 `argc`는 `1`인 경우가 많습니다.
- `argc > 1`일 때만 `argv[1]`을 출력해 범위를 지킵니다.

### 연습문제

**문제 1**
- 문제: `add`, `sub`에 `mul`, `div`를 더해 네 가지 연산을 함수 포인터 배열로 처리하세요.
- 입력: 피연산자 2개와 연산 선택값 `0`~`3`. 예: `7 3 0`이면 덧셈
- 출력: 선택한 연산 결과. 예: `10`
- 조건: `div`는 나누는 값이 `0`이면 `Error` 출력 후 계산하지 않음

**문제 2**
- 문제: `argc`와 `argv`로 실행 시 넘긴 모든 인자를 인덱스와 함께 한 줄씩 출력하세요.
- 입력: 실행 인자 여러 개. 예: 프로그램 뒤에 `hello world`
- 출력 예:
  ```text
  0: ...(프로그램 이름)
  1: hello
  2: world
  ```
- 조건: `for (i = 0; i < argc; i++)`로 순회

**문제 3**
- 문제: `void *`에 `double` 변수 주소를 넣고, 다시 `double *`로 읽어 출력하세요.
- 입력: 없음. 예로 값 `3.14`
- 출력: `3.14`
- 조건: `printf`는 `%.2f` 사용. `void *`에서 바로 역참조하지 말 것

### 정답 포인트

- 문제 1: `int (*op[4])(int, int) = {add, sub, mul, div};` 후 `op[sel](a, b)`. `div` 전 `b == 0` 검사
- 문제 2: `printf("%d: %s\n", i, argv[i]);`
- 문제 3: `void *vp = &x; double *dp = (double *)vp; printf("%.2f\n", *dp);`
- 공통: 함수 포인터 선언은 `반환형 (*이름)(매개변수)`, `void *`는 쓰기 전 타입 복원
