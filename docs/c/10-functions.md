# Chapter 10 함수

## 학습 목표

- 함수 선언·정의·호출과 반환 구조를 실행으로 확인한다.
- 매개변수와 반환값, `void` 함수를 구분해 쓴다.
- 지역 변수와 전역 변수, 함수 안 `static`의 수명·범위를 구분한다.
- 종료 조건이 있는 재귀 함수를 작성한다.

## 본문

### 10-1 함수 정의와 호출

**함수**는 반복되는 코드를 이름 붙여 묶어 두고, 필요할 때 **호출**해 재사용하는 단위입니다. 형태는 `반환형 이름(매개변수)`입니다. 예로 `int add(int a, int b)`는 정수 두 개를 받아 정수를 돌려줍니다. 반환형이 **`void`**이면 값을 반환하지 않고, 안에서 `printf`처럼 일만 합니다.

호출은 `add(3, 4)`처럼 이름 뒤에 괄호를 붙입니다. 괄호 안 값을 **인자**, 선언부 칸을 **매개변수**라고 부릅니다. `printf`도 표준 라이브러리 **함수**입니다. `#include <stdio.h>`를 넣으면 헤더에 선언이 있어 직접 원형을 적지 않아도 호출할 수 있습니다.

아래를 실행해 반환값이 있는 함수와 `void` 함수의 차이를 확인해 보세요.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

void print_done(void)
{
    printf("호출 완료\n");
}

int main(void)
{
    int sum = add(3, 4);
    printf("%d\n", sum);
    print_done();
    return 0;
}
```

**예상 출력**

```text
7
호출 완료
```

**코드 해석**

- `add`는 `return`으로 합을 돌려주고, `main`이 그 값을 `sum`에 담아 출력합니다.
- `print_done`은 `void`라 반환값이 없고, 안에서 바로 출력합니다.
- 정의를 `main`보다 위에 두었으므로 별도 선언 없이도 호출됩니다.

### 10-2 선언과 정의 분리

**선언**은 “이런 이름·인자·반환형의 함수가 있다”고 미리 알려 주는 약속입니다. **프로토타입**이라고도 합니다. **정의**는 실제로 어떤 일을 하는 본문입니다. 정의를 호출보다 아래에 두려면, 위쪽에 선언을 먼저 둡니다. 파일이 길어질수록 선언과 정의를 나누는 방식이 읽기 쉽습니다.

| 용어 | 의미 |
|---|---|
| 함수 선언 | 이름·매개변수·반환형을 먼저 알려 주는 문장 |
| 함수 정의 | 함수가 실제로 하는 일을 적은 본문 |
| 매개변수 | 함수가 입력으로 받는 칸 |
| 반환값 | 함수가 실행 후 돌려주는 값 |

| 방식 | 사용 조건 | 장점 | 주의점 |
|---|---|---|---|
| 선언 + 정의 분리 | 정의가 아래에 있을 때 | 구조가 분명함 | 선언과 정의 시그니처를 맞춰야 함 |
| 정의 먼저 | 정의를 호출보다 위에 둘 수 있을 때 | 짧음 | 파일이 커지면 찾기 어려움 |

아래를 실행해 선언 → 호출 → 정의 순서를 확인해 보세요.

```c
#include <stdio.h>

int add(int a, int b); /* 선언 */

int main(void)
{
    printf("%d\n", add(3, 4)); /* 호출 */
    return 0;
}

int add(int a, int b) /* 정의 */
{
    return a + b;
}
```

**예상 출력**

```text
7
```

**코드 해석**

- 위쪽 `int add(int a, int b);`가 컴파일러에게 함수 형태를 알립니다.
- `main`에서 `add(3, 4)`를 호출하고, 아래 정의가 실제 합을 계산합니다.
- 선언과 정의의 반환형·매개변수 타입이 같아야 합니다.

### 10-3 값 전달

C의 기본 전달은 **값 전달**입니다. 함수에 넘긴 것은 복사본이므로, 함수 안에서 매개변수를 바꿔도 호출쪽 변수는 그대로입니다. 원본 변수를 함수가 직접 바꾸려면 주소를 넘기는 방법이 필요하며, 그 내용은 포인터 장에서 이어집니다. 지금은 “복사본이 바뀌어도 원본은 남는다”만 실행으로 확인합니다.

아래를 실행해 `main`의 `x`가 그대로인지 확인해 보세요.

```c
#include <stdio.h>

void try_double(int n)
{
    n = n * 2;
}

int main(void)
{
    int x = 5;
    try_double(x);
    printf("%d\n", x);
    return 0;
}
```

**예상 출력**

```text
5
```

**코드 해석**

- `try_double` 안의 `n`은 복사본이라 `10`이 되어도 `main`의 `x`는 `5`입니다.
- 결과를 돌려받으려면 `return`으로 새 값을 반환하는 방식이 안전합니다.

### 10-4 지역 변수와 전역 변수, `static`

**지역 변수**는 함수 안에서 선언된 변수로, 그 함수 블록 안에서만 쓸 수 있습니다. 함수가 끝나면 사라지는 쪽으로 이해하면 됩니다. 서로 다른 함수에서 같은 이름을 써도 **서로 다른 변수**입니다.

**전역 변수**는 함수 밖에서 선언되어 파일 여러 함수에서 접근할 수 있습니다. 편하지만 남용하면 함수끼리 의존이 커져 추적이 어려워집니다.

함수 안 **`static` 지역 변수**는 함수가 끝나도 값이 유지되고, 다음 호출에서 이어서 씁니다. 초기화는 프로그램 실행 중 한 번만 일어납니다.

| 용어 | 의미 |
|---|---|
| 스코프 | 변수를 사용할 수 있는 코드 범위 |
| 생명주기 | 변수가 만들어져 사라질 때까지의 시간 |
| 전역 변수 | 함수 밖에서 선언되어 여러 함수가 공유 |
| `static` 지역 변수 | 함수 안이지만 호출이 끝나도 값 유지 |

아래를 실행해 전역과 `static`이 호출마다 어떻게 쌓이는지 확인해 보세요.

```c
#include <stdio.h>

int g_count = 0;

void increase(void)
{
    static int call_count = 0;
    g_count++;
    call_count++;
    printf("g_count=%d, call_count=%d\n", g_count, call_count);
}

int main(void)
{
    increase();
    increase();
    return 0;
}
```

**예상 출력**

```text
g_count=1, call_count=1
g_count=2, call_count=2
```

**코드 해석**

- `g_count`는 전역이라 `increase`가 호출될 때마다 커집니다.
- `call_count`는 `static`이라 함수가 끝나도 남고, 두 번째 호출에서 `2`가 됩니다.
- 일반 지역 변수였다면 매번 `0`으로 다시 시작했을 것입니다.

### 10-5 재귀 함수

**재귀 함수**는 자기 자신을 다시 호출하는 함수입니다. 반드시 **종료 조건**이 있어야 하며, 없으면 호출이 끝나지 않아 프로그램이 멈추거나 비정상 종료될 수 있습니다. 팩토리얼처럼 문제를 더 작은 같은 모양으로 나눌 수 있을 때 쓰기 좋습니다. 종료 조건을 먼저 적고, 그다음 재귀 호출 식을 적는 습관을 들입니다.

| 유형 | 설명 | 예시 |
|---|---|---|
| 일반 함수 | 인자를 받아 결과 반환 | `add(3, 4)` |
| 재귀 함수 | 자기 자신을 호출 | `factorial(n)` |
| `void` 함수 | 반환값 없음 | `print_done()` |

아래를 실행해 `5!`이 `120`인지 확인해 보세요.

```c
#include <stdio.h>

int factorial(int n)
{
    if (n <= 1)
    {
        return 1;
    }
    return n * factorial(n - 1);
}

int main(void)
{
    printf("%d\n", factorial(5));
    return 0;
}
```

**예상 출력**

```text
120
```

**코드 해석**

- `n <= 1`이면 `1`을 돌려주고 더 이상 호출하지 않습니다. 이것이 종료 조건입니다.
- 그 외에는 `n * factorial(n - 1)`로 한 단계 작은 문제로 줄입니다.
- `factorial(5)` → `5 * 4 * 3 * 2 * 1`로 이어져 `120`입니다.

### 연습문제

**문제 1**
- 문제: 정수 두 개를 받아 큰 값을 반환하는 함수 `max_value`를 작성하세요.
- 입력: 없음. 코드에서 `max_value(4, 9)`를 호출해 출력합니다.
- 출력: `9`
- 조건: 함수 원형을 먼저 선언하고, `if`로 큰 값을 `return`

**문제 2**
- 문제: 반지름을 받아 원의 넓이를 계산하는 함수 `circle_area`를 작성하세요.
- 입력: 없음. 예로 반지름 `2.0`을 넘겨 소수 둘째 자리까지 출력합니다.
- 출력: `12.57` 근처의 값
- 조건: `const double PI = 3.141592;` 사용, 반환형 `double`, 식은 `PI * r * r`

**문제 3**
- 문제: `sum_to_n(n)` 재귀 함수로 1부터 `n`까지의 합을 구하세요.
- 입력: 없음. 예로 `sum_to_n(4)`를 호출합니다.
- 출력: `10`
- 조건: 종료 조건 `n <= 1`을 넣고 `n + sum_to_n(n - 1)` 형태 사용

**문제 4**
- 문제: 정수 하나를 받아 두 배로 만든 값을 **반환**하는 함수 `double_value`를 작성하세요.
- 입력: 없음. 예로 `x = 5`일 때 `x = double_value(x);` 후 `x` 출력
- 출력: `10`
- 조건: 값 전달만 사용. 포인터 사용 금지. `return`으로 결과 전달

### 정답 포인트

- 문제 1: `int max_value(int a, int b);` 선언 후, `if (a > b) return a; else return b;`
- 문제 2: `double circle_area(double r) { return PI * r * r; }` 후 `%.2f`로 출력
- 문제 3: `if (n <= 1) return n;`을 기저 조건으로 두고 `return n + sum_to_n(n - 1);`
- 문제 4: `int double_value(int n) { return n * 2; }` — 호출쪽에서 반환값을 다시 대입
- 공통: 선언·정의·호출의 반환형과 매개변수 타입이 일치하는지 확인
