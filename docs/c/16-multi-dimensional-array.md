# Chapter 16 다차원 배열

## 학습 목표

- 2차원 배열을 행·열로 선언하고 `map[r][c]`로 접근한다.
- 중첩 반복으로 행 우선 순회와 합·개수 집계를 한다.
- 3차원 배열을 층·행·열 그림으로 읽고 짧은 예제로 확인한다.

## 본문

### 16-1 2차원 배열 선언과 접근

**2차원 배열**은 행과 열이 있는 표처럼 값을 둘 때 씁니다. `int map[2][3]`은 행 2개, 각 행에 열 3칸입니다. 접근은 `map[r][c]`입니다. `r`은 행 번호, `c`는 열 번호이며 둘 다 **0부터** 시작합니다. 게임 맵, 좌석표, 과목별 점수표처럼 가로·세로가 함께 의미 있을 때 자주 씁니다.

초기화는 중괄호를 행마다 나누어 적을 수 있습니다.

```c
int map[2][3] = {
    {1, 0, 1},
    {0, 1, 0}
};
```

| 용어 | 의미 |
|---|---|
| 행 | 가로 줄. 첫 인덱스로 고름 |
| 열 | 세로 칸. 둘째 인덱스로 고름 |
| `map[r][c]` | `r`행 `c`열의 값 |

아래를 실행해 표 형태로 출력되는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int map[2][3] = {
        {1, 0, 1},
        {0, 1, 0}
    };
    int r;
    int c;

    for (r = 0; r < 2; r++)
    {
        for (c = 0; c < 3; c++)
        {
            printf("%d ", map[r][c]);
        }
        printf("\n");
    }
    return 0;
}
```

**예상 출력**

```text
1 0 1
0 1 0
```

**코드 해석**

- 바깥 반복은 행, 안쪽 반복은 열입니다.
- 한 행을 다 찍은 뒤 `printf("\n")`으로 줄을 바꿉니다.
- 유효 범위는 행 `0`~`1`, 열 `0`~`2`입니다.

### 16-2 행·열 순회와 집계

전체를 한 번씩 보려면 중첩 `for`가 기본입니다. 합·개수·최댓값은 1차원과 같고, 인덱스만 두 개입니다. 행마다 합을 구하려면 바깥 루프에서 합을 0으로 리셋한 뒤 안쪽 루프에서 더합니다.

아래를 실행해 전체 합이 나오는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int map[2][3] = {
        {1, 0, 1},
        {0, 1, 0}
    };
    int r;
    int c;
    int sum = 0;

    for (r = 0; r < 2; r++)
    {
        for (c = 0; c < 3; c++)
        {
            sum += map[r][c];
        }
    }

    printf("%d\n", sum);
    return 0;
}
```

**예상 출력**

```text
3
```

**코드 해석**

- 모든 `map[r][c]`를 더하면 `1+0+1+0+1+0 = 3`입니다.
- 인덱스가 범위를 넘지 않게 `r < 2`, `c < 3`을 지킵니다.

### 16-3 3차원 배열 개요

**3차원 배열**은 표 위에 층 개념을 하나 더 얹은 구조로 읽을 수 있습니다. `int cube[2][2][2]`처럼 쓰면 층·행·열 각 2칸입니다. 접근은 `cube[z][r][c]` 형태입니다. 입문 단계에서는 선언과 한 값 읽기만 익히고, 복잡한 좌표 계산은 필요할 때 확장합니다.

| 차원 | 형태 | 예시 |
|---|---|---|
| 1차원 | 한 줄 목록 | 점수 목록 |
| 2차원 | 행·열 표 | 게임 맵 |
| 3차원 | 층 + 행·열 | 같은 격자가 층마다 반복 |

아래를 실행해 한 칸 값이 출력되는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int cube[2][2][2] = {
        {
            {1, 2},
            {3, 4}
        },
        {
            {5, 6},
            {7, 8}
        }
    };

    printf("%d\n", cube[0][1][0]);
    printf("%d\n", cube[1][0][1]);
    return 0;
}
```

**예상 출력**

```text
3
6
```

**코드 해석**

- `cube[0][1][0]`은 첫 층, 둘째 행, 첫 열의 `3`입니다.
- `cube[1][0][1]`은 둘째 층, 첫 행, 둘째 열의 `6`입니다.
- 인덱스를 층 → 행 → 열 순으로 읽습니다.

### 연습문제

**문제 1**
- 문제: `3x3` 정수 배열의 모든 원소 합을 구하세요.
- 입력: 정수 9개. 행 단위로 3개씩. 예:
  ```text
  1 2 3
  4 5 6
  7 8 9
  ```
- 출력: `45`
- 조건: 중첩 반복으로 행과 열을 모두 순회

**문제 2**
- 문제: 2차원 배열과 목표값 `target`이 주어질 때, `target`과 같은 값이 몇 개인지 세어 출력하세요.
- 입력: 행 `R`, 열 `C`, 이어 `R*C`개 정수, 마지막에 `target`. 예: `R=2`, `C=3`, 값 `1 0 1 0 1 0`, `target=1`
- 출력: `3`
- 조건: 인덱스 범위를 벗어나지 않게 행·열 반복 조건 작성

**문제 3**
- 문제: `2x3` 배열의 각 행 합을 한 줄씩 출력하세요.
- 입력: 없음. 예로 `{{1,2,3},{4,5,6}}`
- 출력:
  ```text
  6
  15
  ```
- 조건: 바깥 루프에서 행 합을 0으로 리셋한 뒤 안쪽 루프에서 더하기

### 정답 포인트

- 문제 1: `sum += map[r][c];`를 `r`, `c` 이중 루프로
- 문제 2: `map[r][c] == target`일 때 카운트 증가
- 문제 3: 행마다 `row_sum = 0` 후 열 순회, 행 끝에 출력
- 공통: 인덱스는 `0`부터 **크기 - 1**까지. 바깥=행, 안쪽=열
