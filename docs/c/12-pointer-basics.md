# Chapter 12 포인터의 이해

## 학습 목표

- 주소와 포인터가 무엇인지 문장으로 설명할 수 있다.
- `&`로 주소를 얻고 `*`로 가리킨 값을 읽고 바꾼다.
- 포인터 변수 선언·초기화·역참조를 짧은 프로그램으로 실행한다.

## 본문

### 12-1 주소와 포인터

**주소**는 메모리 안에서 데이터가 놓인 칸을 구분하는 위치 번호입니다. **포인터**는 그 주소를 저장하는 변수입니다. `int *p`는 “`int`형 값이 있는 곳의 주소를 담는 포인터”라고 읽습니다. 포인터가 가리키는 대상의 타입과 포인터 선언의 타입은 **맞추는 것**이 원칙입니다.

일반 변수 `num`은 값 자체를 담고, 포인터 `p`는 “그 값이 있는 위치”를 담습니다. 위치를 알면 나중에 그 칸의 값을 읽거나 바꿀 수 있습니다. 배열과 포인터를 깊게 엮는 내용, 함수 인자로 원본을 바꾸는 패턴은 **다음 장들**에서 이어집니다. 이 장에서는 `&`와 `*`의 기본만 확실히 합니다.

| 용어 | 의미 |
|---|---|
| 메모리 | 프로그램 실행 중 데이터가 저장되는 공간 |
| 주소 | 데이터가 저장된 위치 번호 |
| 포인터 | 주소를 저장하는 변수 |

### 12-2 `&`로 주소 얻기

**`&`**는 변수의 주소를 구할 때 씁니다. `p = &num;`은 “`num`이 있는 위치”를 `p`에 넣습니다. 주소를 화면에 확인하려면 `printf`의 `%p`를 쓰고, 인자에는 `(void *)`로 맞춰 주는 습관을 들입니다. 출력되는 숫자 자체는 실행마다 달라질 수 있습니다. 중요한 것은 `p`와 `&num`이 **같은 위치**를 가리킨다는 점입니다.

`%p`에 `(void *)`로 넘기는 이유를 한 줄로 보면, `void *`는 “가리키는 값의 타입을 아직 정하지 않은 **주소 전용 포인터**”입니다. 앞 장의 `void`와 같은 단어이지만, 여기 `*`가 붙으면 “값이 없음”이 아니라 “주소만 담는다”는 뜻입니다.

| 기호 | 역할 | 예시 |
|---|---|---|
| `&` | 변수의 주소 얻기 | `p = &num;` |
| `*` | 선언에서는 포인터 표시, 식에서는 역참조 | `int *p;`, `*p = 20;` |

아래를 실행해 `num`의 주소와 `p`에 담긴 값이 같은지 확인해 보세요. 주소 숫자는 환경마다 다릅니다.

```c
#include <stdio.h>

int main(void)
{
    int num = 10;
    int *p = &num;

    printf("num: %d\n", num);
    printf("&num: %p\n", (void *)&num);
    printf("p   : %p\n", (void *)p);
    printf("같은 주소인가: %d\n", (&num == p));
    return 0;
}
```

**예상 출력** — 주소 부분은 실행마다 다름

```text
num: 10
&num: 0x...
p   : 0x...
같은 주소인가: 1
```

**코드 해석**

- `int *p = &num;`으로 `p`가 `num`의 주소를 갖습니다.
- `%p`로 주소를 출력하면 `p`와 `&num`이 같게 보입니다.
- `&num == p`가 참이면 `1`이 출력됩니다.

### 12-3 `*`로 값 읽기·바꾸기

선언이 아닌 식에서 **`*`**는 **역참조**입니다. 포인터가 가리키는 주소로 가서 실제 값을 읽거나 씁니다. `printf("%d\n", *p);`는 `p`가 가리키는 `int` 값을 출력합니다. `*p = 20;`은 그 칸에 `20`을 넣습니다. `p`가 `&num`이면 `num`의 값이 바뀝니다.

아래를 실행해 `*p`로 바꾼 뒤 `num`이 함께 바뀌는지 확인해 보세요.

```c
#include <stdio.h>

int main(void)
{
    int num = 10;
    int *p = &num;

    printf("바꾸기 전 num: %d\n", num);
    printf("바꾸기 전 *p : %d\n", *p);

    *p = 20;

    printf("바꾼 후 num: %d\n", num);
    printf("바꾼 후 *p : %d\n", *p);
    return 0;
}
```

**예상 출력**

```text
바꾸기 전 num: 10
바꾸기 전 *p : 10
바꾼 후 num: 20
바꾼 후 *p : 20
```

**코드 해석**

- `*p`로 읽으면 `num`과 같은 `10`이 나옵니다.
- `*p = 20;`은 `p`가 가리키는 칸, 즉 `num`에 `20`을 넣습니다.
- 변수 이름 `num`에 직접 대입하지 않아도, 주소를 통해 원본이 바뀝니다.

### 12-4 한곳에 모아 보기

주소를 얻고, 포인터에 담고, 역참조로 읽고 쓰는 흐름을 한 프로그램으로 정리합니다. `p`를 다른 변수의 주소로 바꿔 가리키는 대상을 옮길 수도 있습니다. 지금은 한 변수만 가리키는 경우를 확실히 합니다.

```c
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = 7;
    int *p = &a;

    printf("*p = %d\n", *p);
    *p = *p + 1;
    printf("a = %d\n", a);

    p = &b;
    printf("*p = %d\n", *p);
    return 0;
}
```

**예상 출력**

```text
*p = 3
a = 4
*p = 7
```

**코드 해석**

- 처음 `p`는 `a`를 가리키므로 `*p`는 `3`입니다.
- `*p = *p + 1;` 뒤 `a`는 `4`입니다.
- `p = &b;`로 가리키는 대상을 `b`로 바꾸면 `*p`는 `7`입니다.

### 연습문제

**문제 1**
- 문제: 정수 변수 `num`을 선언하고, 포인터를 이용해 값을 두 배로 바꾸세요.
- 입력: 없음. 예로 `num = 6`으로 시작한 뒤 변경 전·후를 출력합니다.
- 출력:
  ```text
  6
  12
  ```
- 조건: 값 변경은 반드시 `*포인터`를 통해 수행. `num = num * 2;` 직접 대입 금지

**문제 2**
- 문제: 정수 변수 두 개를 선언한 뒤, 포인터만으로 합을 구해 출력하세요.
- 입력: 없음. 예로 `a = 4`, `b = 9`
- 출력: `13`
- 조건: 합식에서 `a`, `b` 이름 직접 더하지 말고 `*p1`, `*p2`만 사용

**문제 3**
- 문제: 포인터 `p`가 가리키는 값을 `0`으로 만든 뒤, `p`를 다른 변수 주소로 바꿔 그 값도 출력하세요.
- 입력: 없음. 예로 `x = 10`, `y = 20`
- 출력:
  ```text
  0
  20
  ```
- 조건: 첫 줄은 `*p = 0;` 이후의 `x`, 둘째 줄은 `p = &y;` 이후의 `*p`

### 정답 포인트

- 문제 1: `int *p = &num;` 후 `*p = *p * 2;`
- 문제 2: `int *p1 = &a; int *p2 = &b;` 후 `printf("%d\n", *p1 + *p2);`
- 문제 3: `p = &x; *p = 0;`으로 `x`를 비운 뒤 `p = &y;`로 대상을 바꿈
- 공통: 선언은 `타입 *이름`, 주소는 `&변수`, 값 접근·변경은 `*포인터`
