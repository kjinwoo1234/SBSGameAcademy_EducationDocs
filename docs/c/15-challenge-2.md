## 본문

### 15-1 이 장의 역할

이 장은 새 문법을 거의 늘리지 않습니다. **Chapter 01~14**까지 배운 도구를 조합해 짧은 프로그램을 완성하는 연습장입니다. 쓸 수 있는 범위는 1차원 배열, 포인터 연산, 함수 인자로 주소·배열 넘기기까지입니다. 다차원 배열, 이중 포인터, 함수 포인터, `void *`, 구조체, 파일 입출력, 동적 할당은 이후 장으로 미룹니다.
문제를 고를 때는 입력과 출력을 먼저 적고, 합·교환·최댓값처럼 반복되는 일은 함수로 빼 둡니다. 구현이 끝나면 정상 값과 **경계값**도 넣어 봅니다.

| 단계 | 할 일 |
|---|---|
| 1 | 입력·출력 형식 확정 |
| 2 | 원본 변경이 필요한지 판단. 필요하면 포인터 인자 |
| 3 | 배열이면 시작 주소와 길이를 함께 전달 |
| 4 | 기본 입력 + 경계값 테스트 |

### 15-2 포인터·배열·함수를 섞을 때

**배열**은 여러 값을 한 묶음으로 둘 때 씁니다. **포인터**는 시작 칸을 가리키거나, 함수에서 원본을 바꿀 때 씁니다. **함수**는 합·교환·출력처럼 같은 일을 이름 붙여 재사용할 때 씁니다. `*(p + i)`와 `p[i]`는 같은 칸을 가리키므로, 연습에서는 한 표기로 통일해도 됩니다.

아래는 연습 전에 흐름만 확인하는 짧은 뼈대입니다. 배열 합을 `const` 포인터로 구하는 예입니다.

```c
#include <stdio.h>

int sum_array(const int *arr, int n)
{
    int i;
    int sum = 0;

    for (i = 0; i < n; i++)
    {
        sum += *(arr + i);
    }
    return sum;
}

int main(void)
{
    int nums[4] = {2, 5, 8, 1};

    printf("%d\n", sum_array(nums, 4));
    return 0;
}
```

**예상 출력**

```text
16
```

**코드 해석**

- `sum_array`는 읽기만 하므로 `const int *arr`를 씁니다.
- `*(arr + i)`로 칸을 읽습니다. `arr[i]`와 같습니다.
- `main`은 배열을 두고 길이와 함께 넘깁니다.

### 연습문제

**문제 1**
- 문제: 정수 `n`과 정수 `n`개를 입력받아, 포인터 연산만으로 합을 출력하세요.
- 입력: 첫 줄 `n`, 둘째 줄 정수 `n`개. 예: `n = 4`, 값 `2 5 8 1`
- 출력: `16`
- 조건: 합 루프에서 `arr[i]` 금지. `*(p + i)`만 사용. `1 <= n <= 100`

**문제 2**
- 문제: 정수 두 개를 입력받아 `swap` 함수로 자리를 바꾼 뒤 출력하세요.
- 입력: 정수 2개. 예: `3 7`
- 출력: `7 3`
- 조건: `void swap(int *a, int *b)` 작성. 호출은 `swap(&x, &y)`

**문제 3**
- 문제: 작은 값이 앞, 큰 값이 뒤에 오도록 두 정수를 맞추는 함수를 만드세요.
- 입력: 정수 2개. 예: `9 4`
- 출력: `4 9`
- 조건: 포인터 인자 사용. 이미 오름차순이면 그대로 출력

**문제 4**
- 문제: 배열과 길이를 받아 최댓값을 반환하는 함수를 작성하세요.
- 입력: `n`과 정수 `n`개. 예: `4` 그리고 `3 9 2 7`
- 출력: `9`
- 조건: `const int *arr`, `int n`. `n >= 1`

**문제 5**
- 문제: 배열과 길이를 받아 평균을 소수 둘째 자리까지 출력하세요.
- 입력: `n`과 정수 `n`개. 예: `4` 그리고 `80 90 70 100`
- 출력: `85.00`
- 조건: 평균 계산 함수는 `double` 반환. `const int *` 사용

**문제 6**
- 문제: 배열을 받아 모든 원소를 두 배로 바꾸는 함수를 작성하세요.
- 입력: 없음. 예로 `{1, 2, 3}`를 두 배로 만든 뒤 출력
- 출력: `2 4 6`
- 조건: `void double_all(int *arr, int n)`. 칸 변경은 `*포인터` 또는 `arr[i]`로 원본 수정

**문제 7**
- 문제: 배열을 제자리에서 역순으로 바꾸는 함수를 작성하세요.
- 입력: 없음. 예로 `{1, 2, 3, 4}`를 뒤집은 뒤 출력
- 출력: `4 3 2 1`
- 조건: 추가 배열 없이 양쪽 끝부터 `swap` 권장. 길이 짝수·홀수 모두 확인

**문제 8**
- 문제: 배열에서 목표값 `target`이 몇 번 나오는지 세는 함수를 작성하세요.
- 입력: `n`, 정수 `n`개, `target`. 예: `n = 5`, 값 `1 4 1 4 1`, `target = 1`
- 출력: `3`
- 조건: `const int *arr`로 읽기만. 없으면 `0`

**문제 9**
- 문제: 문자열 리터럴 세 개를 포인터 배열에 넣고, 사용자에게 인덱스 `0`~`2`를 입력받아 해당 문자열만 출력하세요.
- 입력: 정수 인덱스 1개. 예: `1`
- 출력: 예로 배열이 `"Kim"`, `"Lee"`, `"Park"`이면 `Lee`
- 조건: `const char *names[3]` 사용. 범위 밖이면 `Invalid` 출력

### 정답 포인트

- 문제 1: `int *p = arr;` 후 `sum += *(p + i);`
- 문제 2: `temp = *a; *a = *b; *b = temp;`
- 문제 3: `*a > *b`일 때만 교환
- 문제 4: `max = arr[0]` 후 순회하며 갱신
- 문제 5: `(double)sum / n` 후 `printf("%.2f\n", avg);`
- 문제 6: `for`로 각 칸 `arr[i] = arr[i] * 2;`
- 문제 7: `i`와 `n - 1 - i`를 `swap`으로 교환. `i < n / 2`까지
- 문제 8: `arr[i] == target`일 때 카운트 증가
- 문제 9: `0 <= idx && idx < 3`이면 `printf("%s\n", names[idx]);`
- 공통: 배열 함수는 주소+길이, 원본 변경은 비-`const` 포인터, 읽기만은 `const`
