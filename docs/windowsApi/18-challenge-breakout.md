# Chapter 18 도전! 벽돌깨기

## 학습 목표

- 여러 벽돌 상태를 배열·구조체로 관리할 수 있다.
- 공·패들·벽돌 충돌을 구분해 처리할 수 있다.
- 공 튕기기보다 한 단계 복잡한 2D 게임 루프를 Win32로 구성할 수 있다.

## 본문

### 18-1 목표

```text
배우는 것:
타이머 · 게임 루프 · 입력 · 충돌 · 렌더링 · 여러 객체
```

- 상단: 벽돌 격자. 맞으면 비활성
- 하단: 패들
- 공: 튕기기와 동일 + 벽돌 충돌

### 18-2 데이터 예시

```cpp
struct Brick
{
    int x, y, w, h;
    bool alive;
};

Brick bricks[5][8];
```

`WM_CREATE`에서 격자 좌표를 채웁니다. `WM_TIMER`에서:

1. 공 이동
2. 벽·패들 충돌
3. 살아 있는 벽돌과 겹치면 `alive = false`, 공 속도 반사
4. `InvalidateRect`

`WM_PAINT`에서 `alive`인 벽돌만 `Rectangle`로 그립니다.

### 18-3 확장 아이디어

- 점수 `TextOut`
- 벽돌을 모두 깨면 `"Clear"`
- 공을 놓치면 생명 감소
- 나중에 객체 목록·총알을 더하면 **2D 슈팅**으로 확장 가능

```text
객체 관리 · 키보드 · 충돌 · 게임 상태
```

이 장 이후에는 DirectX로 렌더링만 바꿔도, **갱신·충돌·상태** 코드는 비슷한 형태로 가져갈 수 있습니다.

### 연습문제

**문제 1**

- 문제: 5×8 벽돌과 패들·공이 있는 벽돌깨기를 만드세요.
- 입력: 좌우 키
- 출력: 벽돌을 깨며 진행
- 조건: 타이머 루프

**문제 2**

- 문제: 점수를 표시하고, 벽돌을 모두 깨면 클리어 메시지를 띄우세요.
- 입력: 없음
- 출력: 점수·Clear
- 조건: 상태 변수

**문제 3**

- 문제: 다음 확장 중 하나를 구현하세요. 생명 3 / 스테이지 2 / 총알 발사.
- 입력: 선택 기능에 맞는 입력
- 출력: 확장 동작
- 조건: 기존 루프를 깨지 말 것

### 정답 포인트

- 문제 1: 벽돌 배열 + 충돌 시 alive
- 문제 2: 카운트·플래그
- 문제 3: 상태 추가만으로 확장
