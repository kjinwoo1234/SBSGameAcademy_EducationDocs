# Chapter 13 도전! 공 튕기기

## 학습 목표

- 키보드·타이머·페인트·충돌을 한 프로그램에 연결할 수 있다.
- 공과 패들의 좌표를 갱신하고 벽에 튕기는 처리를 할 수 있다.
- Win32 입문 내용을 “작은 게임”으로 통합할 수 있다.

## 본문

### 13-1 목표 화면

```text
┌──────────────────────────────┐
│                              │
│            ●                 │
│             ↘               │
│                              │
│                              │
│       █████████              │
└──────────────────────────────┘
```

- **공**: 타이머마다 위치 += 속도. 벽에 닿으면 속도 부호 반전
- **패들**: 아래쪽 막대. 좌우 키로 이동
- **그리기**: `WM_PAINT`에서 원·사각형

필요한 연결은 다음과 같습니다.

```text
키보드     → WM_KEYDOWN
게임 갱신  → WM_TIMER
충돌       → 좌표 비교
화면       → WM_PAINT
```

### 13-2 상태 변수 예시

```cpp
int ballX = 200, ballY = 120;
int vx = 3, vy = 2;
int paddleX = 160;
const int paddleW = 80;
const int paddleY = 400;
```

`WM_TIMER`에서:

1. `ballX += vx; ballY += vy;`
2. 왼쪽·오른쪽·위 벽에 닿으면 `vx` 또는 `vy` 부호 변경
3. 패들 사각형과 겹치면 `vy = -abs(vy);`
4. 아래로 빠지면 위치 리셋 또는 게임 오버 문자 표시
5. `InvalidateRect(hwnd, NULL, TRUE);`

`WM_KEYDOWN`에서 `VK_LEFT` / `VK_RIGHT`로 `paddleX`를 움직입니다.

### 13-3 그리기 힌트

```cpp
Ellipse(hdc, ballX - 10, ballY - 10, ballX + 10, ballY + 10);
Rectangle(hdc, paddleX, paddleY, paddleX + paddleW, paddleY + 12);
```

충돌은 입문 수준에서 **AABB**면 됩니다. 공의 중심과 패들 사각형이 겹치는지 비교합니다.

이 장에서 연결하는 것:

```text
키보드 · 타이머 · 충돌 · 렌더링
```

### 연습문제

**문제 1**

- 문제: 공이 네 벽에서 튕기도록 만드세요. 패들은 없어도 됩니다.
- 입력: 없음
- 출력: 공이 창 안에서 계속 튕김
- 조건: `SetTimer` + `WM_PAINT`

**문제 2**

- 문제: 패들을 추가하고 좌우 키로 움직이게 하세요. 공과 패들이 닿으면 위로 튕기게 하세요.
- 입력: 좌우 키
- 출력: 패들로 공을 받아 냄
- 조건: 타이머에서 충돌 검사

**문제 3**

- 문제: 공이 아래로 빠지면 `"Miss"`를 `TextOut`으로 표시하고, 스페이스로 재시작하세요.
- 입력: 스페이스
- 출력: Miss 후 재시작
- 조건: 상태 변수로 플레이/미스 구분

### 정답 포인트

- 문제 1: 경계에서 속도 반전
- 문제 2: 패들 이동 + 겹침 시 `vy` 위로
- 문제 3: 상태 enum/플래그 + `VK_SPACE`
